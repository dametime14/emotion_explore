## 1. 받은 제안에 대한 응답

### 1.1 FA-P8 (frontier-ai): 개념 수준, 모델 내부 기반 주장의 최소 검증 요건 추가 → **수용**

**이유.**
1. **사전 재현성.** 같은 데이터에 같은 구조로 학습한 SAE가 서로 크게 다른 dictionary를 낸다는 불안정성이 보고되어 있다(arXiv:2502.12892, 초록). 비디오 SAE에서는 TopK 선택이 프레임 간 feature 배정을 불안정하게 만든다(arXiv:2604.03919, 초록). 개념 수준 결론이 학습 무작위성에 따라 바뀌면 그 결론은 모델의 성질이 아니라 학습 실행의 성질이다. 같은 논리가 Westlin 2025의 GMM 재초기화 안정성(Rand 0.85)과 Du 2025의 프롬프트 민감성에도 적용된다(arXiv:2507.00320, arXiv:2509.24298). 그래서 SAE에 한정하지 않고 "학습되는 모든 분해 단계"의 안정성 요건으로 일반화한다(2절 V6).
2. **정답 주입 회복.** ground truth를 아는 조건에서 pipeline이 올바른 구조를 찾는지 보는 것은 내 Round 1 I4와 D3의 식별 가능성 시뮬레이션과 같은 원리다(arXiv:2302.06677, 5. Discussion). 받아들이되 한 가지를 보탠다. TRIBE v2 합성 반응(arXiv:2605.04326)에 신호를 심으면 잡음 구조가 실제 fMRI와 다를 수 있다. 실제 데이터의 잔차나 위상 무작위화 잡음에 신호를 심는 판을 함께 두고, 신호가 없는 null 자료에서 거짓 개념이 나오는 비율(위양성률)을 같이 보고한다(2절 V5).
3. **steering, transport의 matched-complexity null.** 같은 노름의 무작위 방향과 내용 방향(객체 범주 등)을 대조로 두는 것은 내 V1(경쟁 모델과 matched null)의 구체화다. Antonello & Huth(doi:10.1162/nol_a_00087, Discussion 1~2째 단락)의 representational generality 논리, Conwell 2024의 모델 간 작은 차이(doi:10.1038/s41467-024-53147-y)가 근거다(2절 V1).
4. **예상 반론(비용)에 대한 대응**도 받아들인다. 탐색 단계에서는 충족 여부만 표시하고 버리지 않는다.

### 1.2 EF-P6 (encoding-foundation): 독립 코호트를 쓴 의사 전향적 검증과 공동 provenance 등록부 → **수정**

**수용하는 부분.**
* Mind captioning(doi:10.1126/sciadv.adw1464, Crossref 확인)은 같은 Cowen & Keltner 비디오를 본 독립 코호트라 D6의 '새 피험자' 검증을 다른 scanner와 프로토콜까지 넓힌다[코호트 구성은 타 에이전트가 본문으로 확인].
* **provenance 등록부(모델 x 데이터셋 x 오염 경로)** 는 그대로 수용한다. 내 D7의 사전학습 오염 항목을 실무 표로 만든 것이다(doi:10.1016/j.patter.2023.100804의 L1.4, L2, L3.2). 2절 V7의 필수 산출물로 넣는다.

**수정하는 부분과 이유.**
1. **자극 보류 없이는 '모델 검증'이 아니다.** 제안대로 Horikawa 5명 전체 클립으로 encoder를 학습한 뒤 같은 클립 중에서 구동 클립을 고르면, 선택은 모델의 일반화가 아니라 Horikawa 코호트가 그 클립에 보인 관찰 반응을 상당 부분 반영한다. 이 경우 Mind captioning 검증은 "관찰 반응으로 고른 클립이 다른 코호트에서도 같은 영역을 구동하는가"라는 **코호트 간 재현** 질문이 된다. 그 자체로 가치가 있지만 다른 질문이다. 두 설계를 나눈다.
   * **D6a 모델 검증:** Horikawa 클립의 일부(예: 80%)로 encoder를 학습하고, 학습에 쓰지 않은 클립 중에서만 선택한다. 검증은 Horikawa 미사용 피험자와 Mind captioning에서 한다. 일반화 수준은 '새 피험자 + 새 자극'(doi:10.7554/eLife.82566, Discussion 'Generalizing...').
   * **D6b 코호트 간 재현:** Horikawa 관찰 반응으로 클립을 고르고 Mind captioning으로 검증한다. 모델이 아니라 '정서 영역 구동 클립'의 재현성을 검정한다.
2. **ceiling 대비 평가의 범위.** 72개 반복 클립에서만 ceiling 대비가 가능하므로, 선택 풀이 72개로 줄어든다. 정서 클립이 반복 간 더 안정적일 수 있다는 지적[vision-decoding round2, Krenz 2025 인용, 나는 미확인]이 맞다면 ceiling 자체가 정서와 공선적이므로, 정서 수준별 ceiling을 따로 보고한다(2절 V2).
3. **블록 구조 차이.** Horikawa는 8 s 미만 클립을 반복 재생해 블록을 채웠다(arXiv:2507.00320 Methods 기술). Mind captioning은 블록 길이가 다르다[타 에이전트 확인: 8 s vs 10 s]. 클립 길이와 반복 재생 횟수를 두 코호트 모두에서 nuisance로 기록한다(내 Round 1 U8).
4. **사용자 결정 선행.** Mind captioning은 보유 4개 데이터셋 밖이다(Axis Encyclopedia 0.1절). D6a의 Horikawa 내부 판(5명 중 1명과 클립 20% 보류)은 지금 진행할 수 있고, Mind captioning 판은 사용자 결정과 피험자 중복 확인 뒤에 둔다.
5. **"선택이 검증보다 먼저라 순환을 피한다"는 전제의 부분 반박.** 선택 목록을 먼저 기록해도, 분석자가 이미 Mind captioning 반응을 본 적이 있으면(예: EmoMind arXiv:2605.16739가 이 코호트를 분석함) 분석 경로 선택에 정보가 새어 들 수 있다. 등록부에 '누가 어떤 검증 데이터를 이미 보았는가'라는 분석자 노출 항목을 추가하고, 선택 목록과 분석 코드를 해시로 봉인한다(2절 V7, V10).

**등록부에 추가할 행(제안 목록에 더해).** MLLM 주석 모델의 사전학습 오염 가능성(Cowen & Keltner 공개 interactive map과 GIF, Horikawa 관련 논문 텍스트, Emo-FilM의 원 CC 영화), Du 2025 embedding을 feature로 재사용할 경우의 생성 모델(Qwen2-VL)과 같은 비디오 사용 여부, 분석자 노출.

### 1.3 SN-P7 (systems-neuro): Horikawa multiverse 통합 사전등록 설계 → **수정**

**수용하는 부분.** ET-P4(emotion-theory), GI-P1(geometry-info), 내 D1, SN Chain 2를 하나의 격자로 합치자는 데 동의한다. 입력 경로 3종, 공간 범위, 전역/세션 성분 처리, chance 보정 NMI(AMI), 군집-세션/run 대응, 피험자 내 재현성은 내 U2 지적(세션 NMI 0.188 대 정서 평정 NMI 0.0141, arXiv:2507.00320 Results)에 직접 답한다. network별 tSNR 공변량도 수용한다. Horikawa EPI의 TE 43 ms는 Stage 1 보고서에서 1차 자료로 확인되어 있다(`outputs/stage1/dataset_Horikawa.md`). 다만 "TE 43 ms 때문에 vmPFC, OFC를 포함한 DMN 부분공간이 더 취약하다"는 추론은 tSNR 지도로 측정해서 확인해야 한다.

**수정 1: 0단계로 두 원 결과의 계산 재현.** 격자를 돌리기 전에 Horikawa의 원 경로(평정 기반 voxel 선택 + k-means K = 27)와 Westlin의 원 경로(전뇌 PCA 95% + GMM + BIC)를 각각 그대로 재현해 원 수치를 회복하는지 확인한다. 회복하지 못하면 이후 격자의 차이를 '분석 선택' 탓으로 돌릴 수 없다(doi:10.1038/s41586-020-2314-9, Discussion 3째 단락; doi:10.1016/j.patter.2023.100804, [D5]). 두 원 경로는 격자 안의 기준점(anchor)으로 남긴다. Horikawa 원 논문 Methods의 voxel 선택 절차는 아직 Westlin의 서술로만 확인되어 있어 이 단계에서 원문 대조가 필요하다(내 Round 1 9절 미확인 항목).

**수정 2: 질문 두 개, 주 경로 두 개.** ET-P4 예상 반론 (4)가 지적했듯 피험자 간 신뢰 부분공간 경로는 정의상 개인 특이 구조를 지운다. 따라서 한 경로로 두 주장을 판정하면 안 된다.
* **H-shared(공유 구조가 범주형인가):** 주 경로 = 라벨 비의존, 피험자 간 신뢰 부분공간(학습은 다른 피험자의 같은 클립 반응으로만).
* **H-idio(개인 특이 구조가 재현되는가):** 주 경로 = 피험자 내 세션 분할 재현성(ET-P4 제안). 재초기화 안정성(Westlin의 Rand 0.85)과 구분한다.
* 나머지 조합은 specification curve로 전부 보고하되 결론은 두 주 경로에서만 낸다(doi:10.1038/s41562-020-0912-z).

**수정 3: 전역/세션 성분 처리를 '잡음 제거'로만 해석하지 않는다.** 전역 fMRI 신호는 자율신경 생리와 결합되어 있다(doi:10.1038/s41593-025-01945-y, Crossref 확인, 제목 수준). 각성 관련 정서 분산이 전역 성분에 실려 있을 수 있으므로, 전역 성분 제거로 정서 대응이 사라지면 "정서 구조가 없다"가 아니라 "정서 대응이 전역/자율신경 성분에 실려 있다"로 해석한다. 이는 내 Round 1 C2(신호 의존 잡음)와 같은 문제다.

**수정 4: null의 구조.** 정서 평정은 비디오에 묶여 있고 5명이 같은 순서로 보았다. 군집-평정 대응의 null은 run 안 순환 이동처럼 시간 자기상관과 세션 구조를 보존해야 한다. 연속 평정에는 군집 지시변수로 평정을 예측하는 교차검증 R²(ET-P4 요인 D)를 병기한다. 피험자별 결과는 모두 보고하고 prevalence로 요약한다(doi:10.7554/eLife.62461).

**수정 5: 단계 분리.** 1단계는 Horikawa 내부(0단계 재현 + 격자)로 사용자 결정 없이 진행한다. 2단계 Mind captioning 교차 재현은 사용자 결정과 피험자 중복 확인 뒤에 둔다. 두 코호트의 TR, 블록 길이, 전처리 차이 때문에 코호트 간 결과는 보수적 하한으로 읽는다(GI-P1 예상 반론 (a)와 같은 입장).

**격자 크기 상한 제안.** 입력 경로 3 x 공간 범위 3 x 전역/세션 처리 3 x 군집 수 선택 3 = 81 명세/피험자를 상한으로 사전 등록하고, 필요하면 guided multiverse로 표집한다(doi:10.1038/s41467-022-31347-8, Discussion 마지막 단락). 단 표집 목적은 성능 최적화가 아니라 결론 변동의 지도화다.

### 1.4 GC-P3 (generative-counterfactual): 통계 통제와 설계 통제의 삼각 검증, affective metamer 통합, PPI manipulation check → **수정**

**(1) 삼각 검증: 수용하되 "실패 방식이 다르다"는 전제는 부분 반박.**
* D2(신뢰도 반영 정서 고유 분산, R0)와 CH1(의미 고정 정서 편집에 대한 encoder 예측, R1)의 일치표를 사전 등록하자는 데 동의한다.
* 그러나 두 검증은 완전히 독립이 아니다. CH1의 encoder는 Horikawa 관찰 데이터로 학습되고, 그 feature 공간(V-JEPA 2, DINOv2/CLIP, VLM 캡션 embedding)은 D2의 내용 지표와 상당 부분 겹친다. encoder가 자연 상관 속에서 정서 방향 가중치에 의미 정보를 실었다면(GC round1 CH1 '경쟁 설명'), D2의 잔여 교란과 같은 원인으로 두 검증이 함께 틀릴 수 있다.
* **수정안.** 판정표에 공유 가정 목록을 명시한다. (a) 같은 관찰 데이터와 같은 분할, (b) 겹치는 feature 공간, (c) 같은 정서 라벨(별도 평정자 규범). 가능하면 CH1 encoder의 feature 공간을 D2 내용 지표와 다르게 고르거나, 겹치는 지표를 쓴 판과 쓰지 않은 판을 함께 보고한다. 둘이 일치해도 결론은 "encoder와 통계 통제가 같은 voxel을 가리킨다"이며 evidence-level은 R1이다(GC 예상 반론 (b)와 같은 입장, Axis Encyclopedia 0.2절 정의). 실제 뇌의 정서 특이 반응 주장은 R3가 필요하다.

**(2) Affective metamer 분업: 수용.** 생성은 generative-counterfactual, 반증 해석 기준과 null은 adversarial-reviewer가 맡는다. 지금 정할 수 있는 기준은 다음과 같다.
* 통과는 충분조건이 아니고, 실패가 표상의 부재를 뜻하지 않는다(doi:10.1038/s41593-023-01442-0, Limitations).
* matched null: 같은 최적화 예산으로 무작위 layer 방향 또는 내용 범주 방향의 activation을 맞춘 '내용 metamer'를 함께 만들고, 정서 metamer와 인간 평정 일치율을 비교한다.
* 대상 모델은 평가 자극으로 학습되지 않은 것이어야 한다. EmoNet은 Horikawa 계열 자극에 쓰지 않는다(위 자기 정정).
* 표집 다양성: 시작점 여러 개, metamer 간 거리 분포 보고(GC 예상 반론 (c) 수용).

**(3) 편집 자극의 PPI와 alt-test: 수용, 조건 보완.**
* 층화 무작위 추출은 PPI 전제(gold가 같은 분포의 무작위 표본, doi:10.1126/science.adi6000, 1.1절)를 지키는 올바른 방향이다. 층별 추출 확률을 기록하고 층 가중치를 반영해 추정한다(arXiv:2306.04746의 설계 확률 원칙).
* alt-test를 쓰려면 사례마다 인간 주석자 3명 이상, 사례 30개 이상(권장 50~100)이 필요하다(arXiv:2501.10970, 1절과 5.1절). 편집 자극 평정 예산을 이 기준으로 잡는다.
* manipulation check의 평정 지시문은 대상(portrayed / perceived / felt)을 명시하고 label-provenance에 기록한다.

### 1.5 LS-P5 (llm-semantics): I2를 관점 조작과 reader/experiencer 구분으로 확장 → **수정**

**수용하는 부분.** 같은 MLLM을 관찰자 모드와 시청자(경험자) 모드로 돌려 Emo-FilM 50개 항목마다 alt-test를 하는 설계는 내 I2와 C4를 측정 가능한 형태로 만든다. LLM 정서 판단이 관찰자 관점에 가깝다는 근거(arXiv:2408.13718, General Discussion 3째, 6째 단락), GPT-4 appraisal 주석의 신뢰도와 타당도 평가(arXiv:2503.16883), MLLM과 인간 정서 구조의 대응 연구(doi:10.1038/s41598-025-14961-6), 접지 없는 LLM이 감각운동 특징을 회복하지 못한다는 결과(doi:10.1038/s41562-025-02203-8)가 성분별 예측을 뒷받침한다. "성분별 대체 가능성 지도"를 이후 AI 라벨 사용의 사전 조건표로 쓰자는 제안도 수용한다(2절 V9).

**수정 1: alt-test 최소 조건.** alt-test는 주석자 3명 이상과 사례 30개 이상을 요구하고, 주석자가 3명이면 winning rate ω는 0, 1/3, 2/3, 1만 가질 수 있다(arXiv:2501.10970, 1절, 3.4절, 5.1절). Emo-FilM은 항목 x 영화당 평정자 3~4명이다(Stage 1). 따라서 항목별로 (a) 평정자 3명 이상이 겹치는 구간만 쓰고, (b) ω와 함께 연속 지표인 advantage probability ρ를 주 지표로 보고한다.

**수정 2: 사례(instance)의 정의.** 1 Hz 평정은 강하게 자기상관되어 있어 1초를 독립 사례로 세면 t 검정 가정이 깨진다. 사례는 자기상관 길이보다 긴 비중첩 구간이나 장면 단위로 정의하고, 항목별 독립 사례가 30개 미만이면 "판단 불가"로 기록한다(LS 예상 반론 (5)와 같은 처리). LS가 제안한 1 s, 5 s, 장면 단위 병렬 보고는 유지하되, 판정은 장면 단위에서 낸다.

**수정 3: 정합된 대상.** Emo-FilM 평정은 별도 평정자의 자기 경험 보고(felt / 별도 평정자)다. 따라서 '시청자 모드'가 인간 기준과 대상이 맞는 조건이고, '관찰자 모드'는 관점 조작 조건이다. 예측은 절대 수준이 아니라 "성분별 관찰자-시청자 모드 차이"로 진술한다. 예: appraisal 항목에서는 두 모드 차이가 작고, feeling과 physiology 항목에서는 시청자 모드가 더 높거나 둘 다 대체 불가.

**수정 4: 대체 불가의 원인 분리.** 인간 평정자 간 일치가 낮으면 alt-test는 통과하기 어렵다(arXiv:2501.10970, 7 Limitations 'High disagreement'). Physiology, Motor expression 항목의 '대체 불가'가 MLLM의 무능력인지 인간 기준의 낮은 일치 때문인지 구분하려면, 성분별 평정자 간 일치도(IAA)를 같이 보고하고 IAA가 비슷한 항목끼리 비교한다. LS의 "정서의 Molyneux 문제" 해석은 IAA 통제 후에만 쓴다.

**수정 5: 오염과 반복 시청.** Emo-FilM 영화는 공개 CC 단편영화(LIRIS-ACCEDE 계열)라 MLLM 사전학습 데이터에 있을 수 있다. 등록부(1.2절)에 기록한다. 평정자가 같은 영화를 최대 6번 본 점(LS 예상 반론 (3))은 '예측 가능성', '갑작스러움' 같은 appraisal 항목에서 인간 쪽에만 학습 효과를 만들 수 있으므로 해당 항목을 별도 표시한다.

**label-provenance 표기 수정 제안.** LS 제안의 "felt, 별도 평정자 규범"은 정확하다. MLLM 쪽은 "AI 추정, 대상 = 모드에 따라 felt(시청자) 또는 perceived(관찰자)"로 대상을 모드별로 적자.

## 2. 최소 검증 요건 갱신판 (minimum-validation, v2)

### 2.1 사용 방법
* Stage 3~4의 모든 후보 질문에 V1~V12를 ○(충족) / △(부분) / ×(미충족) / NA(해당 없음)로 표시한다. 미충족이어도 버리지 않는다(Round 1 7.4절 원칙 유지, FA-P8 예상 반론 대응).
* Axis Encyclopedia 0.2절의 다른 필수 태그(label-provenance, evidence-level, insilico-vs-observed, G1, signal-feasibility)와 중복되지 않게 했다. 해당 태그를 참조하는 항목은 그렇게 적었다.
* S1~S3은 필수가 아니라 **강한 주장 등급**의 조건이다. 충족하지 않으면 결론을 탐색적 증거로 표기한다.

| S2 | 독립 코호트 또는 독립 데이터셋 재현 | EF-P6, SN-P7, GI-P1 | Mind captioning은 사용자 결정 선행. 코호트 간 결과는 보수적 하한으로 해석 |
| S3 | 인과적 표현은 evidence-level R2 이상에서만 | Axis Encyclopedia 0.2절, GC 제안 체계 | R0~R1 결론에는 "공변한다", "encoder가 민감하다"까지만 씀 |

### 2.4 Round 1 대비 변경 기록
* 유지: Round 1의 7항목은 V1, V2, V4, V7, V8, V9, V12로 모두 남았다(일부는 내용 확장).
* 추가: V3(chance 보정과 의존 구조 null), V5(회복 검사), V6(학습 무작위성 안정성), V10(사전 고정), V11(원 결과 재현), 강한 주장 등급 S1~S3.
* 받지 않은 것: 없음. 다만 FA-P8(2)는 합성 뇌에만 심는 판을 실제 잡음 판으로 보완했고, GC-P3(1)의 삼각 검증은 필수가 아닌 강한 주장 조건(S1)으로 두었다. 모든 후보에 요구하면 탐색 단계 비용이 지나치게 커지기 때문이다.
* 이견 기록: GC-P3는 D2와 CH1의 실패 방식이 다르다고 보았고, 나는 부분적으로 겹친다고 본다(1.4절). 합의를 서두르지 않고 판정표에 공유 가정을 명시하는 것으로 처리하자고 제안한다.
