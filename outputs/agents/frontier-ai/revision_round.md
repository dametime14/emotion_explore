## 0. 요약

### 0.1 이번 라운드의 공통 발상

**사람의 정서 표상은 어떤 학습 압력에서 생기는가**는 사람에게서는 물을 수 없다. 한 사람의 학습 경험(무엇을 보고, 어떤 이름을 배우고, 무엇을 목표로 배웠는가)을 바꿀 수 없기 때문이다. 인공 시스템에서는 구조와 데이터를 고정한 채 **학습 목표, 이미지 식단, 언어 내용, 정서 개념의 세밀도**를 하나씩 바꿀 수 있다. 이렇게 키운 모델 중 어느 것이 같은 정서 영상을 본 사람의 뇌 반응과 닮는지를 보면, 정서 이론들이 서로 다르게 예측하는 "정서 표상의 출처"를 가를 수 있다. 이것이 plan.md 2절 기준 (a)("관찰로는 얻을 수 없는 통제된 비교 대상")에 해당한다.

### 0.4 plan.md 4절 함정 대응(모든 질문 공통)

* **EmoNet:** 쓰지 않는다. 정서 지도 학습에는 C&K와 무관한 EmoSet, FindingEmo, Affection, EMOTIC만 쓴다.
* **Mind captioning(MC) 시험 클립 72개:** 학습 자료는 앞 58 run의 2,108클립, 72클립은 평가와 noise ceiling 전용.
* **소리:** C&K 2,185개 모두 무음. 이 라운드의 질문은 모두 시각만 쓴다.
* **MC 보유본 전처리 미확인:** 원 논문은 상수, 추세, 머리 움직임 24개, 전역 신호 12개 회귀, 4 s shift, despike, 블록 안 평균, run 안 z-score. 이 라운드의 분석은 클립 단위(블록 평균) 반응으로 충분하다. 보유본이 다르면 raw(ds005191)에서 같은 절차로 다시 만든다.
* **캡션:** [Human 작성, AI 교정], 정서 표현이 드물다. 이 라운드에서는 "장면 설명 공변량"으로만 쓴다.
* **Westlin 2025:** 개인별 군집 11~14개, 범주 NMI 0.014. 어느 질문도 "범주 구조가 있다"를 전제하지 않는다.
* **라벨 주체:** C&K 34/14는 별도 평정자 규범 평정이다. 뇌 비교의 목표는 뇌 반응이고, C&K 평정은 "정서와 겹치는 설명량" 계산과 해석에만 쓴다.
* **Emo-FilM:** 이 라운드의 주 데이터가 아니다.
* **TRIBE v2:** 쓰지 않는다.
* **VLM/MLLM 오염:** 정서 판단은 우리가 C&K와 무관한 자료로 직접 학습한 head에서만 얻는다. 공개 backbone(YFCC, ImageNet, COCO 등으로 학습)이 C&K 원본 영상의 프레임을 봤을 가능성은 낮지만 배제할 수 없어 위험으로 적는다. C&K 라벨은 어느 학습에도 들어가지 않는다.
* **선행 판정:** 질문마다 직접 검색했고 질의와 날짜를 적었다.

### 0.5 공통 측정: "정서와 겹치는 설명량"

여러 질문이 같은 지표를 쓴다. 모델 feature M과 C&K 규범 평정 R로 각각, 그리고 함께 뇌 반응을 예측한 교차검증 설명량에서 **겹치는 부분(shared variance) = R²(M) + R²(R) - R²(M+R)**를 계산한다. "모델이 뇌에서 설명하는 부분 중 정서 평정도 설명하는 부분"이다. 같은 R을 모든 모델에 쓰므로 R의 측정 오차(비디오당 9~17명 집계)는 모델 간 비교에서 공통으로 작용한다. 절대 크기는 해석하지 않고 모델 간 차이만 해석한다. 평가: Horikawa 2020(5명) 먼저, MC(6명, 학습 2,108 / 평가 72, noise ceiling)로 재현. ROI 묶음은 사전 지정: 후두엽 시각(Kragel 2019가 정서 정보를 보고한 영역), 고차 시각, transmodal(Horikawa 2020의 정서 우세 영역 계열: IPL, vmPFC, TPJ, precuneus), 편도체(신호 약함, 따로 보고).

### 1.1 RQ-55 "어떤 방식으로 학습한 AI가 뇌의 정서 표현과 가장 닮을까?"는 왜 약했는가

| 새 기준 | 진단 |
|---|---|
| AI-enabled Contribution | **방향은 맞았으나 대조가 통제되지 않았다.** 원 설계는 V-JEPA 2, VideoMAE, 언어 정렬 모델처럼 구조, 학습 데이터, 목표가 모두 다른 공개 video 모델을 비교하려 했다. 그러면 "어느 모델이 더 맞다"는 벤치마크가 되고, 학습 목표의 효과를 분리하지 못한다(reviewer_notes 3절: "목표만 다른 공개 checkpoint가 사실상 없다"). 정서 목표 공간도 다른 불확실한 분석(LIT-03 기술 잔차)에 기대고 있었다. 무엇보다 각 목표가 어떤 정서 이론의 예측에 해당하는지가 없어, 결과가 정서에 대해 말해 주는 것이 약했다 |
| 1-month Feasibility | **목표만 바꾼 video 모델을 직접 학습하는 것은 4주, GPU 1~4장으로 어렵다**(평가에서 Feasibility 2). 그러나 정지 이미지 수준에서는 **목표만 다른 공개 checkpoint 세트가 실제로 있다**: SLIP(arXiv:2112.12750, 같은 YFCC15M, 같은 ViT에서 SimCLR, CLIP, SLIP), VISSL model zoo(같은 ImageNet, 같은 ResNet-50에서 지도 학습과 SimCLR, SwAV, MoCo v2, Barlow Twins, DINO 등). 평가의 전제가 일부 틀렸다. 빠진 것은 "정서 이름으로 지도한" 조건뿐이며, 이것은 작게 직접 학습할 수 있다 |

### 1.2 RQ-19 "AI가 매긴 정서 구조는 뇌의 정서 구조를 어느 수준까지 따라갈까?"는 왜 약했는가

| 새 기준 | 진단 |
|---|---|
| AI-enabled Contribution | **AI 라벨의 해상도를 재는 질문이라 기여가 AI 측정 도구 쪽으로 돌아갔다.** 결과는 "MLLM 라벨을 어느 수준까지 믿어도 되는가"이며, 정서와 뇌에 대한 새 지식은 간접적이다(사용자가 K3를 쓸모없다고 본 이유와 같다). Du 2025(arXiv:2509.24298)가 같은 2,180개 비디오에서 MLLM 정서 기하와 뇌의 정렬을 이미 보였고(평가에서 Novelty 2), MLLM은 C&K 공개 지도를 학습했을 수 있어(오염) 어떤 결과도 확증이 되기 어려웠다 |

## 2. [FA-RV-1] AI가 정서를 직접 배워야만 뇌의 정서 반응과 닮아질까, 아니면 세상을 보는 것만으로도 충분할까? (RQ-55 재작성)

* **자세한 질문:** 구조와 학습 이미지를 고정하고 학습 목표만 바꾼 인공 시각 시스템(이미지 자체만 배우기 / 사물 이름 배우기 / 말과 함께 보기 / 정서 이름 배우기 / 정서와 무관한 장면 속성 배우기) 중 어느 쪽이, 같은 정서 영상을 본 사람의 뇌 반응에서 정서 평정과 겹치는 설명량을 더 많이 갖는가? 그 차이는 후두엽 시각 영역과 transmodal 영역에서 같은가?
* **AI가 있어야만 가능한 이유:** 사람의 학습 목표는 바꿀 수 없다. 같은 이미지 경험을 하되 "정서 이름을 배운 사람"과 "사물 이름만 배운 사람"을 만들 수 없다. 인공 시스템에서는 구조와 데이터를 고정하고 목표만 바꿀 수 있어, 정서 표상의 출처를 인과적으로 다른 조건 사이에서 비교할 수 있다(뇌에 대한 결론은 상관 수준, R0).
* **정서와 뇌에 대해 새로 알게 되는 것:**
  * **정서 schema 가설**(Kragel 2019, doi:10.1126/sciadv.aaw4358: 시각계에 정서 schema가 내재): 정서 이름 지도 학습이 같은 이미지의 장면 속성 지도 학습보다 후두엽의 정서 겹침 설명량을 더 크게 만든다고 예측한다. Kragel 2019는 정서 지도 CNN이 후두엽과 맞는다는 것을 보였지만, 같은 이미지로 다른 목표를 학습한 대조가 없었다.
  * **일반 학습 가설**(Konkle & Alvarez 2022, doi:10.1038/s41467-022-28091-4; Prince 2024, doi:10.1126/sciadv.adl1776; Liu 2024, doi:10.1371/journal.pcbi.1011943: 사물 인식 망에서 정서 선택 unit 출현): 라벨 없는 학습이나 사물 학습으로도 충분하다고 예측한다.
  * **언어 구성 가설**(Lindquist 2014, doi:10.1037/a0035293: 의미 기억 손실이 정서 범주 지각을 손상): 언어와 함께 본 모델이 transmodal에서 더 맞는다고 예측한다.
  * 어느 결과든 정서 표상 "출처"에 대한 제약을 준다. 단 모든 목표가 같게 나오면 "이 측정으로는 학습 압력의 차이를 볼 수 없다"는 결론이며, 정서가 일반 학습의 산물이라는 증거로 과장하지 않는다(뇌의 정서 신호 자체가 내용 신호일 가능성과 구분되지 않기 때문).
* **데이터:**
  * 뇌: Horikawa 2020(5명, 2,181클립 1회, 블록 평균 native volume, HCP360 ROI, 보유), MC(6명, 학습 2,108클립, 평가 72클립 x 5회, 보유본 형식 미확인). 클립마다 균등 추출한 프레임 8장의 feature 평균(무음 영상이라 시각만).
  * C&K 34/14 규범 평정(별도 평정자, 집계값): 겹침 설명량 계산에만 사용.
  * 학습용 독립 자료: EmoSet-118K(arXiv:2307.07961, DB 등재; 8개 정서 범주와 밝기, 색, 장면 유형, 사물 범주, 표정, 행동 속성 라벨이 같은 이미지에 있음. 코드 저장소 MIT 직접 확인, 이미지와 라벨 이용 조건 미확인). C&K와 겹치지 않는다.
* **모델과 checkpoint:**
  * 공개 통제 세트 1, 언어 유무: **SLIP** ViT-S/B, YFCC15M에서 SimCLR, CLIP, SLIP 목표(저장소 README의 dl.fbaipublicfiles.com 가중치 링크, 코드 MIT 직접 확인, 가중치 라이선스는 저장소에 별도 기재 없음, 미확인).
  * 공개 통제 세트 2, 사물 라벨 유무: **VISSL** model zoo ResNet-50, ImageNet-1k에서 지도 학습과 SimCLR, SwAV, MoCo v2, Barlow Twins, DINO(코드 MIT 직접 확인, 가중치 다운로드 링크 공개, 가중치별 조건 미확인). 보조: 같은 ResNet-50을 Places205 장면 라벨로 학습한 지도 모델(데이터가 달라 보조 비교만).
  * 직접 학습, 정서 이름 조건: ViT-S/16(또는 ResNet-50)을 EmoSet-118K에서 같은 초기값, 같은 step 수로 (i) 정서 8범주 지도, (ii) 장면 유형과 사물 범주 지도(같은 이미지), (iii) 자기지도(DINO 또는 SimCLR), (iv) 정서 라벨을 섞은 대조(라벨 구조 제거), 각 3 seed.
  * 미세조정 판(더 싸고 1주차 가능): VISSL SimCLR ResNet-50에서 시작해 정서 head 대 장면 속성 head로 끝까지 미세조정(같은 step).
  * GPU(가정, A100급 1~4장, 미확인): 공개 모델 feature 추출 수 GPU 시간. 직접 학습 ViT-S 100 epoch(약 1,180만 장 처리)이 1회 2~4 GPU 시간으로 추정, 12회 약 25~50 GPU 시간. 미세조정 6회 약 6~10 GPU 시간. encoding은 CPU로 충분.
* **핵심 분석, 예측, 반증 조건:**
  * 분석: 모델마다 층별 feature로 피험자별 ridge encoding. ROI 묶음별 (a) noise ceiling 정규화 설명량(MC), (b) C&K 평정과 겹치는 설명량(0.5절). 층 선택은 중첩 교차검증.
  * 사전 지정 대비: C1 언어(CLIP 대 SimCLR, SLIP 세트), C2 사물 라벨(지도 대 자기지도 평균, VISSL 세트), C3 정서 라벨(정서 지도 대 장면 속성 지도, 직접 학습), C4 라벨 구조(정서 지도 대 섞은 라벨).
  * 예측: schema 가설이면 C3 > 0, 특히 후두엽. 언어 구성 가설이면 C1 > 0, 특히 transmodal. 일반 학습 가설이면 모든 대비가 seed 사이(또는 같은 부류 자기지도 방법 사이) 변동 안에 있다.
  * 반증: C3의 차이가 seed 변동의 95% 범위 안이면 "정서 이름 지도가 뇌와 닮은 정서 표상을 만든다"는 주장은 지지되지 않는다. C1이 SLIP 세트의 세 크기(S/B/L)에서 방향이 일관되지 않으면 언어 효과 주장을 철회한다. 겹침 설명량에서 차이가 없고 전체 설명량에서만 차이가 나면, 그 목표 효과는 정서가 아니라 시각 내용 쪽이다.
* **4주 계획:**
  * 1주: Horikawa, MC 클립 단위 반응과 학습/평가 분할(2,108/72) 고정, C&K 평정과 클립 ID 대응표. SLIP, VISSL feature 추출과 C1, C2 결과.
  * 2주: EmoSet 직접 학습 12회와 미세조정 6회. 학습 중 EmoSet held-out 정서 정확도로 학습 성공 확인.
  * 3주: 직접 학습 모델의 encoding과 겹침 설명량, C3, C4. MC로 재현.
  * 4주: 층, 프레임 수, seed 민감도, 결과 정리. FA-RV-5용 층별 지표 추출.
* **가장 가까운 선행과 차이:**
  * 검색: WebSearch "controlled comparison training objective self-supervised supervised CLIP neural networks predict emotion-related fMRI responses emotional videos images"(2026-11-12) → 정서 fMRI에 대한 통제 목표 비교 연구 없음. 비정서 쪽 통제 비교(언어 정렬 효과가 구조와 데이터를 고정하면 사라진다는 ICLR 2023 workshop 논문 [search_index, 식별자 미확인])만 보임. PubMed `(deep neural network OR self-supervised OR contrastive) AND (emotion OR affective OR valence) AND fMRI AND (training objective OR supervised OR "trained to") AND (encoding OR representational similarity)`(2022년 이후, 2026-11-12) → 7건 중 관련 1건.
  * **Schwartz et al. 2023**(doi:10.1523/JNEUROSCI.1277-22.2023, PubMed, 초록): 얼굴 정체성 학습 DCNN과 표정 학습 DCNN을 두개내 기록과 비교했더니 표정 특화로 가정된 영역에서도 정체성 학습 모델이 더 맞았다. **학습 과제를 바꿔 정서 영역의 성격을 판정한 가장 가까운 선행**이다. 차이: 이 질문은 얼굴이 아닌 장면, 영상의 유발 정서, transmodal 영역, 그리고 같은 이미지에서 정서 라벨 대 비정서 라벨을 대조한다.
  * Kragel 2019(정서 지도 CNN과 후두엽, 대조 목표 없음, C&K 프레임 학습이라 Horikawa에 쓰면 누수), Liu 2024(사물 학습 망의 정서 unit, 뇌 비교 없음), Mertens 2025(arXiv:2509.21384, 기성 CNN과 valence 평가 fMRI, 학습 조건 통제 없음), Conwell 2024(doi:10.1038/s41467-024-53147-y, 시각피질에서 목표 차이가 작고 데이터 다양성이 주 결정 요인, 정서 없음), Wang 2023(doi:10.1038/s42256-023-00753-y, 언어 지도와 고차 시각피질, 정서 없음).
  * 정서 학습 비전 모델이 EEG 정서 동역학과 무작위 초기화보다 잘 맞지 않았다는 NeurIPS 2026 포스터가 검색에 보였다 [search_index, 식별자 미확인].
* **주요 위험:** (1) 모든 목표가 비슷하게 나와 판별력이 없을 수 있다(Conwell 2024의 시각피질 결과). 그 경우를 대비해 결론 문장을 사전 등록한다. (2) EmoSet 정지 이미지와 C&K 영상의 도메인 차이. (3) 작은 데이터로 직접 학습한 모델의 표상이 약해 공개 모델과 같은 축에서 비교할 수 없다(직접 학습 모델끼리만 비교). (4) EmoSet 라벨은 평정자가 판단한 이미지 정서라 provenance가 [별도 평정자, perceived/evoked 혼합]이다. (5) overlap: EmoBrain(V-JEPA2 사용)과는 모델이 다르고, 학습 조건 통제라는 핵심이 겹치지 않는다.

## 3. [FA-RV-2] 정서를 몇 가지로만 배운 AI도 뇌가 구분하는 세밀한 정서 차이를 따라갈 수 있을까? (RQ-19 재작성)

* **자세한 질문:** 같은 고정 시각 backbone 위에, C&K와 무관한 같은 이미지들로 배운 정서 개념의 세밀도만 다르게 한 정서 head(좋고 나쁨 2개 / 8개 범주 / 세밀한 범주)를 붙인 AI 관찰자들이 C&K 클립을 판단할 때, 그 판단 구조는 여러 사람이 공유하는 뇌 정서 반응을 큰 성분부터 작은 성분까지 나눈 rank 대역 중 어디까지 따라가는가?
* **AI가 있어야만 가능한 이유:** 사람이 배운 정서 어휘의 수를 실험적으로 바꿀 수 없다. 이미 정서 개념을 가진 사람 평정자는 "좋고 나쁨만 아는 관찰자"가 될 수 없다. 인공 관찰자는 같은 시각 경험에 배운 정서 개념의 세밀도만 다르게 줄 수 있다. 또 이 관찰자는 C&K 라벨을 본 적이 없어 MLLM의 오염 문제를 피한다.
* **정서와 뇌에 대해 새로 알게 되는 것:**
  * 뇌의 세밀한 정서 구분(작은 rank 대역)이 "세밀한 정서 개념 학습"이 있어야 재현되는지, 아니면 좋고 나쁨만 배운 관찰자도 시각 feature를 통해 재현하는지를 보여 준다.
  * semantic space 이론(Cowen & Keltner 2017, doi:10.1073/pnas.1702247114: 고차원 범주 공간)은 세밀한 대역에서 세밀한 개념 학습이 필요하다고 예측하는 쪽이고, 차원 이론(좋고 나쁨과 각성)은 거친 head로도 큰 대역 대부분이 재현된다고 예측하는 쪽이다. 다만 head 출력 차원 수가 결과에 기계적으로 영향을 주므로, 같은 차원 수의 무작위 projection 대조를 넘는 부분만 해석한다. 이 결과는 "뇌의 세밀한 정서 구조 중 시각 정보에서 바로 나오는 부분과 개념 학습이 필요한 부분"의 경계를 그리며, 어느 정서 이론이 옳다고 판정하지는 않는다.
* **데이터:**
  * 뇌: Horikawa 2020 + MC(같은 C&K 클립, 두 코호트 11명, 피험자 비중복은 사용자 확인). rank 대역은 두 코호트 안과 사이의 cross-decomposition 공유 스펙트럼(Gauthaman et al., arXiv:2409.06843, DB; PLoS CB 판 doi:10.1371/journal.pcbi.1013714)으로 만든다. Horikawa 전처리본은 native volume이라 HCP360 parcel 수준이나 기능 정렬 후 비교(geometry-info의 RQ-01 공통 기반과 공유).
  * 정서 head 학습용 독립 자료: **FindingEmo**(arXiv:2402.01355, 장면 전체 단위 정서 범주와 valence, arousal 주석 25k장, 이미지 URL 목록 공개, 범주 수와 이용 조건은 원문 확인 필요) 또는 **EMOTIC**(doi:10.1109/TPAMI.2019.2916866, 인물 귀속 정서 범주와 연속 차원, 세부와 이용 조건 미확인). 같은 이미지에서 세밀 범주 → 묶은 범주 → 좋고 나쁨으로 라벨을 접어 세 head를 만든다. 둘 다 C&K와 겹치지 않는다.
  * C&K 34/14 규범 평정은 사람 쪽 기준선으로만 쓴다.
* **모델과 checkpoint:** backbone은 FA-RV-1의 공개 통제 세트(SLIP, VISSL)와 직접 학습 모델 중 2~3개(코드 MIT 확인, 가중치 조건 미확인). head는 선형 또는 얕은 MLP, 각 세밀도 x 3 seed. GPU: head 학습은 분 단위, feature 추출 포함 10 GPU 시간 미만.
* **핵심 분석, 예측, 반증 조건:**
  * 분석: 각 AI 관찰자가 C&K 클립에 낸 정서 판단 벡터로 클립 간 RDM을 만들고, 뇌 공유 스펙트럼의 rank 대역마다 그 대역의 신경 RDM과 비교한다. 대조 세 가지: 같은 차원 수의 backbone 무작위 projection(차원 대조), 라벨을 섞어 학습한 head(개념 구조 대조), C&K 규범 평정(사람 기준선). 대역별 대응은 RSA와 Gromov-Wasserstein 정렬(세밀 대응, Takahashi et al. 2025, arXiv:2505.16419의 방법)을 함께 쓴다.
  * 예측: 큰 대역(상위 몇 차원)은 세 head 모두 비슷하게 따라가고, 작은 대역에서 세밀 head만 차원 대조를 넘는다면 "세밀한 뇌 정서 구분에는 개념 세밀도가 필요하다". 좋고 나쁨 head도 작은 대역에서 차원 대조를 넘으면 "세밀한 구분의 일부는 시각 정보에서 바로 나온다".
  * 반증: 어떤 head도 어떤 대역에서 차원 대조와 라벨 섞음 대조를 넘지 못하면 이 설계로는 개념 세밀도의 효과를 볼 수 없다. 세밀 head가 좋고 나쁨 head보다 큰 대역에서만 낫고 작은 대역에서 같으면 "세밀 개념은 거친 구조만 바꾼다"로 해석한다.
* **4주 계획:**
  * 1주: 독립 정서 자료 확보와 라벨 접기, backbone feature 추출, head 학습.
  * 2주: 두 코호트 공유 스펙트럼과 rank 대역(RQ-01 공통 기반 재사용 가능).
  * 3주: 대역별 RSA, GW 정렬, 대조 세 가지.
  * 4주: backbone과 자료(FindingEmo 대 EMOTIC) 민감도, 정리.
* **가장 가까운 선행과 차이:**
  * 검색: WebSearch "emotion classifier trained with coarse versus fine-grained emotion categories compared to brain fMRI representational geometry granularity"(2026-11-12) → 학습한 개념 세밀도를 조작해 뇌 기하와 비교한 연구 없음. Du 2025(arXiv:2509.24298)는 MLLM의 odd-one-out 판단으로 만든 기하와 뇌를 비교했고(개념 세밀도 조작 없음, 오염 가능), Asanuma 2025(doi:10.1038/s41598-025-14961-6)는 MLLM과 사람 정서 구조를 RSA와 GW로 비교했다(뇌 없음). Takahashi 2025는 학습 방식별 모델과 사람 물체 판단의 거친/세밀 대응을 비교했다(정서, 뇌 없음).
  * 차이: 관찰자의 학습 경험(배운 정서 개념 수)을 실험 변수로 두고, 뇌 정서 구조를 rank 대역으로 나눠 "어디까지"를 묻는다.
* **주요 위험:** (1) 독립 자료의 라벨은 장면이나 인물에 대한 지각된 정서([별도 평정자, perceived])라 C&K의 유발 정서와 provenance가 다르다. (2) 세밀 범주 집합과 C&K 34범주가 다르므로 "세밀함"의 정의가 자료에 묶인다. (3) Horikawa 공유 스펙트럼은 5명이라 작은 대역의 신뢰도가 낮다(MC 추가로 보완). (4) vision-decoding의 D2(뇌 decoder 표상 + emotion head)와 head를 쓴다는 점은 같지만, 이쪽은 자극 쪽 관찰자의 학습 경험을 조작한다(7절).

## 4. [FA-RV-3] 사람을 한 번도 보지 못하고 자란 AI도 사람이 나오는 장면의 정서를 뇌처럼 구분할까? (새 질문)

* **자세한 질문:** 같은 이미지에서 사람(또는 얼굴만)을 지운 식단으로 키운 인공 시각 시스템은, 지우지 않은 식단으로 키운 시스템에 비해 사람이 나오는 정서 장면에서 뇌의 정서 겹침 설명량을 특별히 잃는가, 아니면 장면 맥락만으로도 그 정서 구조를 얻는가?
* **AI가 있어야만 가능한 이유:** 사람의 시각 경험에서 사람과 얼굴을 빼는 것은 불가능하다. 인공 시스템은 같은 장면 경험에서 사람만 지운 "통제된 성장 환경"으로 키울 수 있다(얼굴 경험 박탈 DCNN 선례: Xu et al. 2021, doi:10.3389/fncom.2021.626259).
* **정서와 뇌에 대해 새로 알게 되는 것:**
  * 얼굴과 몸의 표현을 정서 지각의 중심으로 보는 관점(기본 정서 이론 계열)과, 장면 맥락만으로도 타인의 정서를 상당히 추적한다는 관점(Chen & Whitney 2019, doi:10.1073/pnas.1812250116: 인물을 가린 영상에서도 맥락만으로 valence, arousal 추적)을 뇌 수준에서 가르는 데 쓸 수 있다.
  * 사람이 지워진 시스템이 사람 장면의 정서 겹침 설명량을 그대로 유지하면, 이 뇌 정서 신호의 상당 부분이 사람 특징 없이 장면 맥락에서 계산 가능하다는 뜻이다. 사람 장면에서만 특별히 잃으면, 그 신호가 학습된 사람, 얼굴 특징에 기대고 있다는 뜻이다. 이것은 "뇌가 그렇게 계산한다"가 아니라 "그 정보가 필요하다/충분하다"는 수준의 결론이다.
* **데이터:**
  * 학습용: COCO train2017(약 11.8만 장, 사람 segmentation과 keypoint 주석 공개, 주석 CC BY 4.0, 이미지는 Flickr 약관). 사용자는 NSD 자극(COCO 일부)을 보유하나 학습에는 공개 COCO를 내려받아 쓴다. C&K와 겹치지 않는다. 식단 셋: 그대로, 얼굴만 지움(keypoint의 머리 영역), 사람 전체 지움(segmentation 영역을 주변 평균이나 단순 inpainting으로 채움). 같은 이미지, 같은 step.
  * 뇌: Horikawa 2020 + MC. 클립 유형(사람 있음 / 없음)은 MC의 정서 배제 캡션([Human 작성, AI 교정])에서 사람 지칭어 유무로 사전 정의하고, 프레임 사람 검출(AI)로 교차 확인한다. 정서 유형(사회 정서: adoration, romance, empathic pain 등 / 비사회 정서: 고소 공포, 음식 혐오, 자연 경외 등)은 C&K 범주로 사전 지정.
* **모델과 checkpoint:** ViT-S/16 자기지도(DINO 또는 SimCLR) 3 식단 x 3 seed = 9회. 학습 코드는 공개 구현(VISSL MIT 확인, 또는 DINO 계열 공개 구현, 라이선스 확인 필요). 보조로 같은 식단에 장면 속성 지도 head를 붙인 판. GPU(가정): COCO 200 epoch(약 2,360만 장 처리) 1회 4~8 GPU 시간 추정, 9회 약 36~72 GPU 시간.
* **핵심 분석, 예측, 반증 조건:**
  * 분석: 식단(그대로 / 얼굴 지움 / 사람 지움) x 클립 유형(사람 있음 / 없음) x ROI 묶음에서 (a) 전체 설명량, (b) 정서 겹침 설명량. 핵심 지표는 "사람 장면에서 정서 겹침 설명량이 줄어든 정도"를 "사람 장면에서 전체 설명량이 줄어든 정도"와 "사람 없는 장면에서 줄어든 정도"에 대고 본 상호작용.
  * 예측: 맥락 충분 가설이면 사람 지움 모델의 정서 겹침 손실이 전체 설명량 손실과 비례하거나 그보다 작다. 사람 특징 필요 가설이면 사람 장면의 정서 겹침 손실이 전체 손실보다 크고, 특히 사회 정서 클립과 transmodal 영역에서 크다. 얼굴만 지움과 사람 전체 지움의 차이는 "얼굴" 대 "몸과 행동"의 기여를 나눈다.
  * 반증: 세 식단의 차이가 seed 변동 안이면 "사람 경험이 이 정서 신호에 필요하다"는 주장은 지지되지 않는다. 사람 지움 모델이 사람 없는 장면에서도 같은 정도로 나빠지면, 효과는 사람이 아니라 "지운 흔적"이나 학습 데이터 감소 때문이다.
* **4주 계획:**
  * 1주: COCO 식단 셋 생성(마스크 기반, 지운 자리 채우기 방식 두 가지), 클립 유형 사전 정의, 뇌 반응 준비(FA-RV-1과 공유).
  * 2주: 9회 학습(병렬), 학습 성공 확인(선형 probe로 장면 범주 정확도).
  * 3주: encoding, 정서 겹침 설명량, 상호작용 분석.
  * 4주: 채우기 방식 민감도, MC 재현, 정리.
* **가장 가까운 선행과 차이:**
  * 검색: WebSearch "neural network trained without faces or people deprivation emotion recognition representation brain alignment"(2026-11-12) → 사람이나 얼굴을 박탈한 모델로 정서 표상과 뇌 정렬을 본 연구 없음. Xu et al. 2021은 얼굴 박탈 DCNN의 얼굴 모듈 출현(정서 아님), Prince et al. 2024는 대조 학습에서 범주 선택성 출현(정서 아님), Liu 2024는 사물 학습 망의 정서 unit(박탈 없음, 뇌 없음), Chen & Whitney 2019는 사람에서 인물 가림의 행동 효과(학습 조작 아님). 얼굴 표정 학습 모델과 EEG 정렬에 관한 NeurIPS 2026 포스터는 [search_index].
  * 차이: 통제된 성장 환경(경험 박탈)을 정서 표상과 뇌 정서 신호의 관계로 옮긴 첫 설계다(이 검색 경로 안에서).
* **주요 위험:** (1) 지운 자리 자체가 "여기 사람이 있었다"는 단서가 되어 박탈이 불완전하다(채우기 방식 두 가지로 민감도). (2) C&K 클립 대부분에 사람이 나와 "사람 없는 장면" 수가 적을 수 있다(1주차에 개수 확인, 적으면 클립 유형 대신 장면 안 사람 면적 비율을 연속 변수로). (3) COCO 11.8만 장은 작아 표상이 약하다(식단끼리만 비교). (4) 정서 겹침 설명량은 C&K 규범 평정에 기대며 평정의 측정 오차가 공통으로 작용한다.

## 5. [FA-RV-4] 정서 단어를 배우지 못한 AI는 장면의 정서를 뇌와 다르게 볼까? (새 질문)

* **자세한 질문:** 같은 이미지와 같은 정서 설명문으로 언어와 함께 학습하되, 설명문에서 정서 단어만 지운 조건(이유와 상황 서술은 남음)과 정서 단어를 남긴 조건, 같은 수의 비정서 단어를 지운 조건으로 키운 인공 시각 시스템 중, 어느 쪽이 사람 뇌의 정서 겹침 설명량과 정서 범주 구조를 더 잘 갖는가? 그 차이는 valence 같은 거친 구조와 범주 같은 세밀한 구조에서 다른가?
* **AI가 있어야만 가능한 이유:** 사람에게서 정서 어휘 학습만 빼고 나머지 경험을 똑같이 하는 것은 불가능하다(의미 치매 환자 연구가 가장 가까운 자연 실험이다: Lindquist et al. 2014). 인공 시스템에서는 같은 이미지, 같은 설명문, 같은 학습량에서 정서 단어만 지울 수 있다.
* **정서와 뇌에 대해 새로 알게 되는 것:**
  * 구성주의의 "언어(정서 개념어)가 정서 범주 지각을 구성한다"는 주장은 의미 기억 손실이 정서 범주 지각은 손상시키지만 affect(좋고 나쁨) 지각은 보존한다는 결과로 지지되었다(Lindquist 2014). 인공 학습자에서 같은 해리가 나오는지, 그리고 그 해리가 뇌의 정서 신호와의 정렬에도 나타나는지를 본다.
  * 예측된 해리(정서 단어를 지우면 범주 구조와 transmodal 정렬은 떨어지고 valence 구조는 유지)가 나오면 언어 구성 가설과 정합적인 계산적 증거가 된다. 해리가 없으면, 이 뇌 정서 신호의 범주 구조는 상황과 이유 서술만으로도 학습된다는 뜻이다. 어느 쪽도 사람의 발달 기제를 직접 증명하지 않는다.
* **데이터:**
  * 학습용: **Affection**(arXiv:2210.01946: 공개 이미지 85,007장, 정서 반응과 자유 서술 설명 526,749건). 이미지 출처와 이용 조건은 미확인(저장소 clone 실패, 1주차 확인 사항). 정서 단어 목록은 공개 정서 어휘 사전과 C&K, Affection의 범주명으로 사전 정의한다.
  * 뇌: Horikawa 2020 + MC. C&K 평정은 겹침 설명량과 범주 구조 비교에만 사용.
* **모델과 checkpoint:** 공통 시작점은 언어 없이 학습된 공개 시각 encoder(SLIP 세트의 SimCLR ViT-S/B, 코드 MIT 확인). 여기에 작은 텍스트 encoder를 붙여 CLIP 방식 대조 학습으로 미세조정(OpenCLIP 코드 사용, 저장소 LICENSE 확인). 3 조건 x 3 seed = 9회. GPU(가정): 52만 쌍 x 5 epoch 미세조정 1회 1~3 GPU 시간 추정, 합계 약 10~30 GPU 시간.
* **핵심 분석, 예측, 반증 조건:**
  * 분석: 세 조건의 이미지 encoder로 (a) 뇌 정서 겹침 설명량(ROI 묶음별), (b) C&K 클립에 대한 표상 RDM의 범주성(같은 C&K 범주 안 거리 대 범주 간 거리)과 valence 축 정렬. 학습 성공 확인은 Affection held-out 검색 정확도.
  * 예측(언어 구성 가설): 정서 단어 남김 > 정서 단어 지움 ≈ 비정서 단어 지움 대조보다 낮음(정서 단어 지움의 손실이 비정서 단어 지움의 손실보다 크다), 손실은 범주 구조와 transmodal에서 크고 valence 구조에서는 작다.
  * 반증: 정서 단어 지움의 손실이 같은 수의 비정서 단어 지움 손실과 seed 변동 안에서 같으면 "정서 단어 특유의 효과"는 지지되지 않는다. 범주 구조와 valence 구조의 손실이 같으면 Lindquist식 해리는 이 인공 학습자에서 재현되지 않는다.
* **4주 계획:**
  * 1주: Affection 이미지와 설명 확보, 이용 조건 확인, 정서 단어 목록과 지움 규칙 사전 등록, 비정서 단어 대조 목록(빈도 맞춤).
  * 2주: 9회 미세조정.
  * 3주: 뇌 분석과 범주성, valence 분석.
  * 4주: 지움 규칙 민감도(정서 단어의 형태 변화, 부정어), MC 재현, 정리.
* **가장 가까운 선행과 차이:**
  * 검색: WebSearch "CLIP trained with emotion words removed from captions effect on emotion representation language shapes visual emotion"(2026-11-12) → 정서 단어를 지운 언어 지도 학습 연구 없음. 정서가 풍부한 설명문으로 CLIP을 학습하는 연구(Affection 자체, 정서 캡션 기반 CLIP 계열 [search_index])는 있으나 지움 조작과 뇌 비교는 없다. Wang 2023(doi:10.1038/s42256-023-00753-y)은 언어 지도와 고차 시각피질(정서 아님).
  * 차이: 언어 지도의 "유무"(FA-RV-1의 C1)가 아니라 "정서 어휘 내용"을 조작하고, 사람 연구의 해리(범주 대 affect)를 인공 학습자와 뇌 정렬에서 시험한다.
* **주요 위험:** (1) 정서 단어를 지워도 이유 서술("아이가 혼자 울고 있어서")이 정서를 함축해 조작이 약할 수 있다. 이것 자체가 결과의 일부(이유 서술만으로 충분한가)지만 해석을 사전 등록해야 한다. (2) Affection 이미지 출처와 이용 조건이 미확인이다. (3) 작은 텍스트 encoder와 짧은 미세조정으로는 조건 차이가 표상에 충분히 반영되지 않을 수 있다(학습 성공 지표로 확인).

## 6. [FA-RV-5] 정서를 배우면 AI의 '보는 방식' 자체가 바뀌고, 그 변화가 뇌의 시각 영역과 닮을까? (새 질문, FA-RV-1과 학습 자원 공유)

* **자세한 질문:** 같은 시작점에서 정서 head로 끝까지 미세조정한 시스템, 장면 속성 head로 끝까지 미세조정한 시스템, 시작점을 고정하고 정서 head만 붙인 시스템(읽어 내기만 함)을 비교할 때, 정서 학습이 바꾼 층은 어디이며(초기 지각 층인가 마지막 층인가), 그 변화가 사람 후두엽 시각 영역의 정서 겹침 설명량을 늘리는가?
* **AI가 있어야만 가능한 이유:** 사람에게서 "정서를 배웠기 때문에 시각 표상이 바뀌었다"를 직접 비교할 수 없다. 인공 시스템에서는 같은 시작점에서 정서 학습의 유무와 학습이 닿는 깊이(읽어 내기만 함 대 끝까지 미세조정)를 바꿀 수 있다.
* **정서와 뇌에 대해 새로 알게 되는 것:**
  * affective realism(Siegel et al. 2018, doi:10.1177/0956797617741718: affect가 시각 지각 자체를 바꾼다)과 시각계 정서 schema(Kragel 2019)는 정서 정보가 지각 단계에 들어 있다고 본다. 반대로 정서는 일반 시각 표상을 나중에 읽어 내는 것이라는 관점도 있다.
  * 정서 학습이 초기, 중간 층을 바꾸고 그 변화가 후두엽의 정서 겹침 설명량을 늘리면, "정서 학습만으로도 시각 영역 같은 정서 정보가 지각 층에 생길 수 있다"는 충분성 증거가 된다. 변화가 마지막 층에만 있고 후두엽 정렬이 그대로면, 후두엽의 정서 정보는 정서 학습이 아닌 다른 경로(시각 통계 자체나 feedback)를 가정해야 한다. 모델은 feedforward이므로 뇌의 feedback 기제에 대해서는 말하지 못한다.
* **데이터:** FA-RV-1과 같다(Horikawa 2020 + MC, EmoSet-118K).
* **모델과 checkpoint:** FA-RV-1의 미세조정 판(VISSL SimCLR ResNet-50 시작점, 정서 head 대 장면 속성 head, 끝까지 미세조정)과 고정 backbone + 정서 head. 추가 학습 없음. GPU: 층별 feature 추출 약 5 GPU 시간.
* **핵심 분석, 예측, 반증 조건:**
  * 분석: (a) 층별 표상 변화량(시작점 대비 CKA), (b) 층별 encoding에서 후두엽, 고차 시각, transmodal 묶음의 정서 겹침 설명량 변화, 정서 미세조정 대 속성 미세조정 대비.
  * 예측(지각 변화 가설): 정서 미세조정이 속성 미세조정보다 초기, 중간 층을 더 바꾸고, 그 층의 후두엽 정서 겹침 설명량이 늘어난다.
  * 반증: 정서와 속성 미세조정의 층별 변화 양상이 seed 변동 안에서 같거나, 후두엽 정서 겹침 설명량 변화가 없으면 지각 변화 가설은 이 설계에서 지지되지 않는다.
* **4주 계획:** FA-RV-1의 2주차 학습 결과를 받아 3주차에 층별 분석, 4주차에 seed와 학습량 민감도. 단독으로 진행하면 1주차에 미세조정 6회부터 시작한다.
* **가장 가까운 선행과 차이:**
  * 검색: WebSearch "fine-tuning network for emotion recognition changes early visual layers alignment with visual cortex fMRI affective realism"(2026-11-12) → 정서 미세조정이 바꾸는 층과 시각피질 정렬을 함께 본 연구 없음. Liu 2024(사물 학습 망의 초기 층 정서 unit, 미세조정 비교 없음, 뇌 없음), 합성 fMRI encoding으로 초기 시각피질의 정서 특이 패턴을 본 VSS 포스터 [search_index].
  * 차이: 같은 시작점에서 정서 학습의 유무와 깊이를 조작하고, 층별 변화를 뇌의 시각 영역 정서 신호와 연결한다.
* **주요 위험:** (1) 미세조정량이 작으면 초기 층이 거의 변하지 않아 "변화 없음"이 학습량 부족과 구분되지 않는다(학습률과 step을 두 수준으로). (2) 정서 겹침 설명량이 작아 층별 차이가 잡음에 묻힐 수 있다. (3) FA-RV-1과 학습 자원을 공유하므로 평가에서 하나로 묶일 수 있다. 질문(어느 목표가 이기는가 대 정서 학습이 어디를 바꾸는가)은 다르다.

## 7. 다른 에이전트와의 관계

* **vision-decoding(D2 주담당)과의 차이:** D2는 MindEye2, Brain-IT 같은 **뇌 decoder의 표상**(뇌 → latent)에 emotion head를 붙여 뇌에서 정서를 읽는다. 이쪽(FA-RV-2, FA-RV-5)은 **자극을 보는 인공 시스템**에 emotion head를 붙이거나 정서 학습을 시키고, 그 학습 경험을 조작한 뒤 뇌는 평가 기준으로만 쓴다. 공유 가능한 것: emotion head의 학습 자료(C&K와 무관한 정서 이미지 자료)와 오염 회피 원칙.
* **brain-inspired(D1 주담당):** 그쪽은 뇌를 닮은 구조와 제약, 이쪽은 학습 목표, 식단, 언어 내용 같은 학습 조건이다. FA-RV-3(경험 박탈)은 D1의 "발달 제약" 쪽과 맞닿는다. RQ-56(뇌 반응에 맞춘 학습, brain-tuning)은 brain-inspired 담당이며 여기서 다루지 않는다.
* **geometry-info(RQ-04, 공유 스펙트럼):** FA-RV-2의 rank 대역은 RQ-01의 두 코호트 공유 스펙트럼 파이프라인을 재사용한다.
* **emotion-theory:** FA-RV-1, 3, 4가 각각 정서 schema 대 일반 학습, 얼굴 중심 대 맥락, 언어 구성 가설에 어떤 결과를 줄 수 있고 없는지 비판을 요청한다.
* **겹침(기존 프로젝트):** EmoBrain(구 EmoViS 범위 포함)은 V-JEPA2와 teacher-student distillation으로 34차원 정서 profile을 decoding한다. FA-RV-1~5는 학습 조건을 통제한 인공 시스템을 비교한다는 점에서 핵심이 겹치지 않는다. Horikawa 자료와 시각-의미 통제를 쓰는 부분만 부분 겹침 가능. Emo-FilM 연구와는 겹치지 않는다.
