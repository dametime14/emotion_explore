## 1. Core Research Question

* **(a) 한 줄 질문:** AI가 영상의 정서를 판단할 때, AI 속 상태를 읽은 값과 AI가 말한 답 중 어느 쪽이 사람 뇌 반응과 더 잘 맞을까?
* **(b) 검증 가능한 세부 질문:** 같은 공개 VLM이 같은 정서 영상을 처리할 때, "속 상태 읽기(답 직전 hidden state를 방향에 투영) 대 답 묻기(생성한 평정)"의 차이가 사람 뇌 반응을 고유하게 설명하는 정도에서, 정서 내용이 정서와 무관한 내용(장면, 사물 속성)보다 더 큰가, 즉 측정 방식 x 내용의 2x2 상호작용이 0과 다른가?

## 2. Scientific Motivation

* **AI 정서 라벨이 신경 분석에 빠르게 들어오고 있다.** MLLM(멀티모달 대형 언어 모델)의 답으로 만든 정서 공간이 Horikawa 데이터의 뇌 반응을 사람 평정보다 잘 예측했다는 보고(Du 2025), MLLM 연속 평정을 encoding 회귀자로 쓴 연구(Huang 2026), GPT-4V 평정으로 만든 뇌 지도가 사람 평정 지도와 비슷하다는 보고(Santavirta 2025)가 있다. 이 연구들은 모두 **모델에게 물어본 답**만 썼다.
* **모델 속에는 답보다 많은 정서 정보가 있을 수 있다.** LLM에서는 hidden state로 읽은 정서가 zero-shot으로 물어본 답보다 정확했다(Zhang 2025, 초록). 모델의 답은 사람보다 "너무 범주적"이라는 보고도 있다(Bhattacharyya 2025, 텍스트 시나리오 15범주 기준). 그렇다면 답만 쓰는 지금의 관행은 모델 정서 정보의 일부만 뇌와 비교하는 셈일 수 있다.
* **비어 있는 지식:** 같은 모델에서 두 측정 방식 중 무엇이 사람 뇌와 더 맞는지 비교한 연구가 없다(감사 판정 not found). 이 결과는 Axis U(라벨 출처)에서 "AI 추정"을 하나의 출처로 볼지, 답과 속 상태로 나눠야 할지 정하는 근거가 된다.
* **왜 2x2인가:** 속 상태는 답보다 원래 정보가 많고(차원이 크고 잡음이 적다) 답은 표집 잡음이 있다. 이런 일반적 차이는 어떤 내용을 물어도 생긴다. 그래서 정서 질문에서의 "속 대 답" 차이를 정서와 무관한 질문에서의 "속 대 답" 차이와 비교해야, 측정 방식 차이가 정서에 특별한지 알 수 있다(검토 필수 1).
* **이론과의 연결(가설로만):** 말로 답하기 전 상태와 말로 낸 답의 구분은 정서의 1차 상태와 보고를 나누는 higher-order theory(HOT, LeDoux & Brown 2017)의 구분과 모양이 닮았다. 그러나 정서 질문을 받은 상태에서 읽은 값은 답을 계산하는 중간 단계라 "보고 이전"이 아니다(검토 전제 2). 그래서 HOT 비유는 **과제와 무관한 프롬프트("영상을 설명하라") 아래의 속 상태** 조건에만 쓰고, 어느 결과도 HOT를 검정한다고 주장하지 않는다.

## 3. Origin of the Idea

* **조합 ID:** LIT-13 (Axis R+U+C+F+Q).
* **기원 제안:** frontier-ai **FA-P6**(Round 2, llm-semantics에게 보낸 "내부 표상 읽기 vs 출력 묻기"). 보조 기원: FA-P5(관점 무차별 모델 기준선, 일부), GC-P9(일부).
* **결합된 결과:**
  * frontier-ai Round 1: 모델 내부 정서 vector 문헌(Sofroniew 2026, Xing 2026, Tak 2025)과 "AI 정서 표상과 뇌 정서 표상의 비교" 방향(U1, T8).
  * llm-semantics Round 1: 세 층 분해(L1 장면 기술, L2 귀속된 정서 의미, L3 경험)와 Chain 1(정서 배제 캡션의 잔차). 이 카드는 L2 층을 두 방식으로 재는 설계다.
  * Round 3 검토 두 건: generative-counterfactual(같은 모델 안 대조, steering 점검, 오염 점검, HOT로 재구성), vision-decoding(같은 forward pass, 차원과 신뢰도 정합, 시각 통제 두 겹, 회상 일반화). `round3_summary.md`에 하나로 정리되었다.
  * Stage 4 평가와 카드 검토: adversarial-reviewer가 C&K 공개 지도에 의한 사전학습 오염(RQ-19 조정 근거와 같은 이유), Δ 기준선 불일치, 오염 대조 자극의 부적절함, 시험 클립 누수를 지적했다.
* **가져온 분야:** mechanistic interpretability(representation reading, steering), LLM probing 연구, 사전학습 데이터 탐지(contamination detection).

## 5. Novelty

* **이미 된 것(새로움으로 주장하지 않음):**
  * MLLM 답으로 만든 정서 표상과 뇌의 비교: Du 2025(같은 Horikawa 비디오), Huang 2026, Santavirta 2025, Asanuma 2025(행동 수준).
  * hidden state probe와 prompting의 비교: Zhang 2025(LLM, 뇌 없음).
  * hidden state를 뇌 encoding 회귀자로 쓰는 것 자체: 언어, 시각 encoding에서 표준이다.
  * VLM 정서 vector의 추출과 steering: Sofroniew 2026(텍스트 모델), Xing 2026(VLM, Ekman 6개 정서).
* **남는 새 부분(감사의 "남는 새 부분"):** **같은 모델, 같은 forward pass**에서 얻은 속 상태와 답을, 차원, 신뢰도, 형식을 맞추고, **정서 내용과 정서 무관 내용의 2x2 상호작용**으로 "측정 방식 차이가 정서에 특별한가"를 사람 뇌의 고유 설명량으로 직접 비교하는 것. 여기에 (i) 기억과 정상 판단을 가르도록 설계한 오염 점검, (ii) 지각에서 학습한 대응이 Mind captioning 회상 조건으로 일반화되는지를 두 측정에서 비교하는 것을 더한다.
* **가장 가까운 선행과의 차이:** Du 2025는 답(odd-one-out)만, 다른 모델 계열로, 비정서 대조 없이 했다. 이 카드는 같은 모델의 두 측정을 정서와 비정서 내용에서 쌍으로 비교하므로 "모델 차이"나 "측정 방식의 일반적 차이"가 아니라 "정서에 특유한 측정 방식 차이"를 분리한다. Du 2025 결과는 다른 모델이라 기준선으로 재사용하지 않는다.

| Mind captioning fMRI | **있음(전처리 완료, 보유본 형식 미확인)** | 6명, TR 1 s, 2 mm, 3T Prisma. 지각 학습 60 run에서 2,180클립을 1회씩(6명 같은 의사 무작위 순서) 제시했고, **시험 72클립은 그 마지막 두 run에도 들어 있다**. 그래서 이 카드는 **학습 자료를 앞 58 run(2,108클립)으로 고정**하고, 72클립(시험 세션 5회 반복)은 평가, noise ceiling, 신뢰도 계산에만 쓴다(원 분석과 같음, 검토 X1). 회상 72클립 x 5회 |
| Mind captioning 전처리 | **원 논문은 확인, 보유본은 미확인** | 원 논문: 상수, 선형 추세, 머리 움직임 24개, 전역 신호 12개 회귀 → 4 s shift → despike → 블록 안 평균 → run 안 z-score. 사용자 보유본이 이 파이프라인을 따랐는지는 미확인. 이 카드의 지각 분석은 블록 평균 반응으로 충분하다. 회상 분석에서 cue 읽기 구간과 심상 구간을 나누려면 **블록 평균 이전의 연속 시계열**이 필요하며, 보유본에 없으면 raw(OpenNeuro ds005191)에서 다시 처리한다 |
| 두 코호트의 피험자 독립 | **있음(사용자 확인)** | 원문에는 언급 없음. 장소, 스캐너, 윤리위원회는 다름 |
| 정서 라벨(C&K 34범주 선택 비율, 14차원 평균) | **있음** | 별도 평정자(MTurk) 규범 평정, 비디오당 집계값. 평정자 개인 자료 없음. 이 카드에서 라벨은 (i) 해석, (ii) 두 측정에 똑같이 적용하는 "C&K 평정 너머" 분석, (iii) 오염 점검에만 쓴다. 뇌 비교의 목표는 뇌 반응 자체다 |
| fMRI 참가자 본인의 정서 보고 | **없음** | 두 코호트 모두 없다. 그래서 "참가자가 느낀 정서"에 대한 결론은 내지 않는다 |
| 정서 배제 캡션 | **있음** | Mind captioning, 클립당 20개(사용자 확인). 출처: MTurk 작업자가 시각 내용을 적은 뒤 GPT-3.5로 오탈자 교정과 부적절 문장 제거 **[Human 작성, AI 교정]**(검토 X3) |
| 회상 조건과 vividness | **있음(논문 기준, 보유본 파일 세부 미확인)** | cue는 20개 캡션 중 하나로 고정, 별도 준비 block 후 눈 감고 심상, 원 영상 재시청 후 vividness 5점(reviewer_notes 4.4) |
| VLM 속 상태와 답 | **새로 만든다** | 공개 VLM 추론으로 생성(7절) |
| 정서 방향과 비정서 방향을 구할 독립 자료 | **새로 만든다** | C&K 클립을 쓰지 않는다. 정서: 범주명마다 LLM으로 만든 짧은 정서 이야기와 대조 이야기, 이미지 점검은 EmoSet(arXiv:2307.07961, DB 등재, 8개 범주)과 겹치는 범주만 가능. 비정서: 같은 수의 장면, 사물 속성(사람 수, 실내/실외, 동물, 탈것, 물, 음식, 밤/낮, 움직임 양 등) 방향을 C&K와 무관한 공개 이미지 묶음에서 구한다 |
| 오염 대조 자극 | **없음(새로 만들어야 함)** | 처음 판의 Spacetop alignvideo는 상업 영화와 다큐 발췌(파일명 harrymetsally, freesolo, planetearth 등)라 웹 노출이 C&K보다 클 수 있어 **대조로 쓰지 않는다**(검토 필수 2c, Gross & Levenson 1995). NSD 이미지(COCO)도 대형 VLM 학습 분포 안에 흔해 쓰지 않는다. 대신 모델 학습 이후에 만든 새 영상(직접 촬영 또는 생성)과 그 영상의 새 인간 규범 평정(R2)이 필요하다. 마련하지 못하면 "오염 통제 불가"로 둔다(8절 판정 규칙) |

**재현과 확장(선택):** Emo-FilM(1 Hz 연속 평정, 시청각, 30명)에서 시간 창 단위로 같은 2x2 비교. Emo-FilM 영화는 LIRIS-ACCEDE 공개 주석이 있어 오염 점검을 따로 해야 한다. Emo-FilM 참가자 사후 클립 평정에는 Agent(#9) 항목이 있지만(Stage 1 dataset_EmoFilM.md 2.2절) 이 카드의 주 분석에는 쓰지 않는다.

## 7. Proposed Computational Framework

* **Pretrained model (공개 모델 우선):**
  * 주 모델: **Qwen3-VL-8B**(arXiv:2511.21631). Xing 2026이 같은 모델에서 Ekman 6개 정서 vector를 추출했다.
  * 재현 모델(다른 계열): **InternVL3.5-8B**(arXiv:2508.18265).
  * 대안: Qwen2.5-VL-7B(arXiv:2502.13923, Du 2025가 쓴 Qwen2-VL의 후속), LLaVA-OneVision-7B(arXiv:2408.03326).
  * 라이선스: 코드 저장소는 Qwen3-VL, Qwen2.5-VL Apache-2.0, InternVL MIT(일부 구성 요소는 원 라이선스), LLaVA-NeXT Apache-2.0(체크포인트는 원 라이선스를 따른다는 고지)로 **LICENSE 파일을 직접 확인했다.** **가중치 라이선스는 huggingface.co 모델 카드에 있어 확인하지 못했다(미확인).** pilot 전에 연구 목적 사용 가능 여부를 확인한다.
  * 시각 특징용: V-JEPA 2(arXiv:2506.09985, 코드 MIT, 가중치 라이선스는 저장소 MIT와 MIRAGE 표 3의 CC-BY-NC 4.0이 엇갈림) 또는 CLIP image encoder. 장면 설명용: 문장 encoder 2종 이상.
* **Input representation:**
  * 클립마다 고정 개수 프레임(예: 16장, 짧은 클립은 반복, 긴 클립은 균등 추출).
  * 프롬프트 세 종류, 각각 표현을 바꾼 3개 판:
    * **정서 질문:** "이 영상을 보는 사람이 느낄 정서를 k개 범주 각각 0~100으로 답하라."
    * **비정서 질문:** "이 영상의 k개 장면, 사물 속성이 있는 정도를 0~100으로 답하라." 속성은 비정서 방향과 같은 목록.
    * **과제 무관 프롬프트:** "이 영상을 설명하라." (보조 조건)
  * 오염 점검용 추가 입력: 같은 클립을 영상 대신 정서 배제 캡션 한 개(고정)로만 준 텍스트 판.
* **Output / target representation:**
  * 모델 쪽 특징 네 칸(주 분석), 모두 k차원:
    * (속, 정서): 정서 질문 프롬프트의 마지막 입력 token hidden state를 k개 정서 방향에 투영.
    * (속, 비정서): 비정서 질문 프롬프트의 마지막 입력 token hidden state를 k개 비정서 방향에 투영.
    * (답, 정서): 정서 질문에 대해 생성한 k개 숫자.
    * (답, 비정서): 비정서 질문에 대해 생성한 k개 숫자.
    * 답은 반복 표집(예: 5회) 평균과 숫자 token 확률로 계산한 기댓값 두 판을 만든다.
  * 보조 특징: (과제 무관 속, 정서) = "영상을 설명하라" 아래 hidden state를 같은 정서 방향에 투영. 같은 층의 무작위 방향 k개 투영.
  * k: 주 분석은 0단계 방향 점검을 통과한 정서 범주 수로 두 측정을 똑같이 제한한다(EmoSet과 겹치는 범주가 상한이 될 가능성이 크다). 34범주 판은 탐색 분석이다(검토 권장 4).
  * 뇌 쪽 목표: Horikawa 2020은 비디오별 voxel 반응(블록 평균), Mind captioning은 학습 58 run(2,108클립)의 클립별 반응으로 학습하고 시험 72클립의 5회 평균으로 평가, 회상 72클립 반응.
* **Training or adaptation strategy:**
  * VLM은 미세조정하지 않는다.
  * 방향은 **우리 데이터와 독립인 자료**로만 구한다: 개념이 분명한 예시와 대조 예시의 평균 차이(Representation Engineering 방식, arXiv:2310.01405). 정서 방향이 비디오 입력에서도 같은 뜻인지는 C&K가 아닌 이미지(EmoSet 일부 범주)의 held-out 대응으로 점검한다.
  * 뇌 encoding은 피험자별 voxel ridge(banded ridge, 특징 묶음마다 다른 규제). 층 선택은 중첩 교차검증 안에서 하며 네 칸에 같은 층 규칙을 적용한다.
* **Relevant brain regions / networks:**
  * 전뇌(volume 또는 HCP360 parcel). 사전 지정 ROI 묶음 세 개: transmodal(TPJ, IPL, vmPFC, precuneus, 측두극), 고차 시각(LOC, MT/MST, FFA 주변), 피질하(편도체, 해마).
  * 고차 시각 묶음은 "정서가 아니라 시각 내용을 설명하는가"를 보는 대조 영역이다(Du 2025의 우세 영역에 고위 시각피질과 MST가 포함).
  * 피질하는 3T, 2 mm에서 신호가 약해 결과를 따로 보고한다(signal-feasibility).
* **Loss function or statistical objective:**
  * 교차검증 예측 상관(또는 R²). 모든 encoding 모델에 공통 특징 묶음 B = [시각 특징 + 장면 설명(인간 캡션 embedding)]을 넣는다. U(칸) = B 위에 그 칸을 더했을 때 늘어나는 교차검증 설명량.
  * **주 통계량(2x2 상호작용, 검토 필수 1):**
    * Δ = [U(속, 정서) - U(속, 비정서)] - [U(답, 정서) - U(답, 비정서)]
    * Δ > 0이면 "속 상태 읽기의 이점이 정서 내용에서 특히 크다", Δ < 0이면 "답 묻기의 이점이 정서 내용에서 특히 크다".
  * 보조 통계량: 무작위 방향 null 대비 U(속, 정서)의 초과분, 두 정서 칸의 공유 설명량, 과제 무관 속 조건의 U.
  * 검정: 피험자별 Δ와 클립 묶음 bootstrap 신뢰구간(같은 원본에서 나온 클립은 같은 묶음), 피험자별 검정 + Bayesian prevalence(doi:10.7554/eLife.62461, DB)로 11명 중 몇 명에서 나타나는지 추정. 사전 지정 ROI 묶음 세 개와 층에 대해 FDR 보정.
* **Interpretability method:**
  * Representation reading(방향 투영)과 그 방향이 답에 실제로 쓰이는지 보는 **steering 점검**(방향을 더하면 해당 평정이 오르는가, R1 모델 내부 개입).
  * 구조 비교: 속, 답, 뇌 RDM(자극 간 유사도 행렬) 사이의 RSA와 범주성 지표(Bhattacharyya 2025 방식으로 범주 안 다양성과 범주 간 거리).
  * 칸별 고유 설명량 지도와 Δ 지도.

## 8. Proposed Analyses

**0단계: 측정 준비와 점검 (뇌 분석 전)**
1. **방향 타당성:** 독립 자료에서 구한 정서 방향과 비정서 방향이 held-out 이미지에서 해당 개념을 구분하는가. 통과한 정서 범주 수로 k를 정하고, 비정서 속성도 같은 k개로 맞춘다.
2. **steering 점검(R1):** 각 방향을 hidden state에 더했을 때 답의 해당 항목이 오르는가. 읽히지만 답에 쓰이지 않는 방향은 "답과 연결되지 않은 속 상태"로 따로 표기한다.
3. **차원과 신뢰도 맞추기:** 네 칸 모두 k차원. 신뢰도는 프롬프트 판(3개) 사이, 프레임 표집 사이, 답 반복 표집 사이의 split-half로 잰다. 답은 (a) 반복 평균, (b) token 확률 기댓값, (c) 감쇠 보정 결과를 함께 보고한다. 2x2 설계는 측정 방식의 일반적 신뢰도 차이를 비정서 칸으로 빼 주지만, 정서와 비정서 칸의 신뢰도가 다를 수 있어 신뢰도 보정 판도 함께 보고한다.
4. **사전학습 오염 점검**(아래 별도 절차).

**1단계: 핵심 비교 (R0)**
* 공통 특징 B(시각 특징과 장면 설명 두 가지로 먼저 빼기) 위에서 네 칸의 U를 각각 구하고 주 통계량 Δ를 계산한다.
* **C&K 평정 너머:** C&K 34/14 규범 평정을 B에 더한 판에서 네 칸의 U와 Δ를 다시 구한다. 이 분석은 **두 측정에 똑같이** 적용하며 오염 판정에는 쓰지 않는다(검토 필수 2a). 답이 사람 평정을 잘 따르는 정상적인 경우에도 답의 고유 설명량은 줄어들 수 있기 때문이다.
* Mind captioning 시험 72클립 x 5회로 noise ceiling을 구해 정규화한다. Horikawa 2020은 반복이 없으므로 피험자 간 예측 상한으로 대신한다.

**2단계: 구조, 일반화, 보조 조건**
* RSA와 범주성: 속, 답, 뇌 RDM의 범주성 지표를 같은 방법으로 비교한다.
* 코호트 간 재현: Horikawa 2020에서 얻은 Δ의 방향이 Mind captioning에서 다시 나오는가(같은 클립, 다른 사람).
* **과제 무관 속 조건:** "영상을 설명하라" 아래 속 상태의 정서 투영이 정서 질문 아래 속 상태와 같은 결과를 내는가. HOT 비유는 이 조건의 결과에만 붙인다(검토 권장 5).
* **회상 일반화:** 지각 학습 자료(2,108클립)로 학습한 encoding 가중치로 회상 72클립의 뇌 반응을 예측할 때, Δ가 유지되는가. cue가 회상 직전에 읽히는 고정 캡션이므로 (i) cue 캡션의 문장 embedding과 함께 (ii) **cue 텍스트만 VLM에 넣어 얻은 정서 답과 속 투영**을 공변량으로 넣는다(검토 권장 8). cue 읽기 구간을 따로 빼야 하면 연속 시계열이 필요하다(6절).

**ablation:** 층별(초기, 중간, 후기), 프레임 수(1장 대 16장), 프롬프트 판별, 모델별(Qwen3-VL 대 InternVL3.5), 답 판(표집 평균 대 token 확률 기댓값), k(점검 통과 범주 대 34범주 탐색판).

**사전학습 오염 점검 절차 (개정, 검토 필수 2)**

C&K 클립과 범주 라벨은 공개 웹 interactive map에 있어 모델이 학습 중에 봤을 수 있다(평가자 지적, RQ-19 조정 근거와 같은 이유). 처음 판의 "변형 안정성"과 "C&K 공변량으로 답만 판정"은 기억과 정상 판단을 가르지 못해 뺐다.

1. **기억 탐침(클립별 점수):** 클립만 주고 "이 영상은 어떤 연구 데이터셋에서 왔나", "이 영상의 공식 정서 범주 이름은 무엇인가"를 묻는다. 클립마다 정답 여부를 기록한다. 범주 이름 정답률이 우연 수준(1/34)을 넘는지 이항 검정으로 본다.
2. **영상 대 캡션 텍스트 비교:** 같은 클립을 (a) 영상으로, (b) 정서 배제 캡션 한 개(텍스트)로만 주고 정서 답과 정서 속 투영을 얻는다. 클립별로 "C&K 평정과의 일치도(영상) - 일치도(텍스트)"를 계산한다. 정상적인 시각 판단이면 이 이득이 시각 정서 단서가 많은 클립에 퍼져 나타나고, 기억이면 기억 탐침에 정답을 낸 클립에 몰린다.
3. **기억 탐침과 일치도의 연결:** 클립별로 기억 탐침 정답 여부가 답과 C&K 평정의 일치도를 예측하는지 본다. 쉬운 클립일수록 탐침도 맞히고 일치도도 높을 수 있으므로, C&K 범주 선택 비율 분포의 엔트로피(사람끼리 얼마나 의견이 모였는가)와 캡션 텍스트 판의 일치도를 공변량으로 넣는다. 속 투영에도 같은 분석을 한다.
4. **새로 만든 대조 자극(가능할 때):** 모델 학습 이후에 만든 새 영상(직접 촬영하거나 텍스트-비디오 생성 모델로 만든 영상, 예: Wan, arXiv:2503.20314, DB 등재)에 대해 새 인간 규범 평정(R2, IRB 필요)을 모으고, 같은 일치도 분석과 2, 3번을 반복한다. 생성 영상은 AI 생성 영상 특유의 분포 차이가 있어 C&K와 직접 비교할 때 이 차이를 표기한다. 유명 영화 발췌(Spacetop alignvideo)와 COCO 이미지(NSD)는 웹 노출이 커서 대조로 쓰지 않는다.
5. **언어 쪽 보조 점검:** 범주명과 클립 서술 조합 텍스트에 대한 Min-K% Prob(arXiv:2310.16789). 텍스트만 다루며 영상 포함 여부는 알려 주지 않으므로 판정에는 보조로만 쓴다.
6. **판정 규칙:**
   * **오염 신호 있음:** 1번 정답률이 우연을 넘고, 2번 또는 3번에서 이득이나 일치도가 탐침 정답 클립에 몰린다(공변량 통제 후).
   * 오염 신호가 있으면 탐침 정답 클립을 뺀 민감도 분석을 주 결과와 나란히 보고하고, 답 쪽 결과에 "오염 가능"을 표시한다.
   * **4번 대조 자극을 마련하지 못하면 "오염 통제 불가"로 둔다.** 이 경우 Δ < 0(답 쪽 우세) 결과는 확증으로 쓰지 않는다. Δ > 0(속 쪽 우세) 결과는 오염이 답을 유리하게 하는 방향의 편향이므로 보수적인 결과로 해석할 수 있으나, 오염이 속 상태에도 작용할 수 있으므로 역시 "오염 통제 불가" 표시를 단다.
   * 오염 점검은 오염이 없음을 증명하지 못한다(한계).

**반증 조건 (Falsifiability, 2x2 상호작용 기준으로 개정)**
* **H-read(속 상태 읽기의 이점이 정서에서 특히 크다)가 지지되지 않는 경우:** 신뢰도 보정 판을 포함해 Δ의 신뢰구간이 0을 포함하거나 0보다 작다. 또는 두 모델 계열 중 한 계열에서만, 혹은 한 코호트에서만 Δ > 0이다.
* **H-ask(답 묻기의 이점이 정서에서 특히 크다)가 지지되지 않는 경우:** Δ의 신뢰구간이 0을 포함하거나 0보다 크다. 또는 오염 신호가 있는 클립을 빼면 Δ < 0이 사라진다. "오염 통제 불가" 상태에서는 Δ < 0을 확증으로 쓰지 않는다.
* **"측정 방식 차이가 정서에 특별하다"는 주장 전체가 지지되지 않는 경우:** 두 코호트, 두 모델 모두에서 Δ의 신뢰구간이 0을 포함한다. 이 경우 Axis U의 "AI 추정"을 두 하위 출처로 나눌 근거가 없다.
* **정서 신호 자체가 없는 경우:** 공통 특징 B 위에서 U(속, 정서)와 U(답, 정서)가 모두 무작위 방향 null과 구분되지 않는다. 이 경우 Du 2025류 결과의 정서 해석이 약해진다(RQ-08과 함께 읽는다).

## 9. Competing Explanations

| 대안 해석 | 가르는 분석 |
|---|---|
| 속 상태 읽기가 이기는 것은 hidden state가 원래 정보가 많고 답은 표집 잡음이 있기 때문이다(측정 방식의 일반적 차이) | 2x2 상호작용. 같은 일반적 차이는 비정서 칸에도 생기므로 Δ에서 빠진다. 신뢰도 보정 판도 함께 보고 |
| 정서 속 투영이 이기는 것은 정서 방향이 시각, 장면 정보와 얽혀 있기 때문이다 | 공통 특징 B(시각 특징과 장면 설명)를 먼저 넣고, 비정서 방향 칸을 대조로 둔다. 고차 시각 ROI와 transmodal ROI 결과를 나눠 본다. Xing 2026은 모델 간 정렬에 관한 결과라 이 위험의 직접 증거가 아니며, 이 카드에서 처음 직접 점검한다 |
| 답이 이기는 것은 모델이 C&K 공개 지도의 평정을 기억하기 때문이다 | 개정된 오염 점검 1~6. 기억 탐침 정답 클립을 뺀 민감도 분석. 새 대조 자극이 없으면 Δ < 0을 확증으로 쓰지 않음 |
| 차이는 프롬프트 표현 때문이다 | 프롬프트 3개 판의 결과 범위를 보고. Δ의 부호가 판에 따라 뒤집히면 결론을 내지 않는다 |
| 독립 자료로 구한 정서 방향이 비디오 입력에서 같은 뜻이 아니다 | 0단계 방향 타당성 점검, steering 점검. 실패한 범주는 두 측정에서 똑같이 뺀다 |
| 차이는 특정 모델의 성질이다 | 다른 계열 모델(InternVL3.5)에서 재현 |
| 차이는 C&K 영상 분포(범주가 잘 유발되도록 모은 군집 표본)의 특성이다 | 회상 일반화. 새 대조 자극이 마련되면 그 자극에서의 2x2 |
| 회상에서의 결과는 cue 텍스트가 정서를 전달했기 때문이다 | cue 캡션 embedding과 cue 텍스트만 넣은 VLM 정서 답, 속 투영을 공변량으로 |
| 정서 질문 아래의 속 상태가 "보고 이전의 1차 정서"에 해당한다 | 해당하지 않는다(답을 계산하는 중간 단계). 과제 무관 속 조건을 따로 두고 HOT 비유는 그 조건에만 쓴다. 어느 조건도 HOT를 검정하지 않는다 |

## 10. Potential Findings

* **Δ > 0 (신뢰도 보정, 두 모델, 두 코호트에서):** 정서 내용에서는 모델의 답이 속 상태에 담긴, 뇌와 관련된 정보를 비정서 내용에서보다 더 많이 잃는다. AI 정서 라벨을 신경 분석에 쓸 때 답만 쓰는 관행을 다시 봐야 한다는 측정 방법상의 결론이다. 이 결과가 정서 이론(범주 대 연속, HOT)을 가르지는 못한다(검토 X6).
* **Δ < 0 (오염 점검 통과 시에만):** 정서 내용에서는 규범 평정형 측정(답)이 이 뇌 분산과 더 잘 맞는다. "뇌 분산이 언어화된 판단과 같은 성격"이라는 해석은 하지 않는다(검토 권장 7). 오염 통제 불가 상태면 결론을 보류한다.
* **Δ ≈ 0:** 측정 방식 차이는 정서에 특별하지 않다. Axis U에서 AI 추정 라벨을 나눌 필요가 없다는 실용적 결론.
* **두 정서 칸 모두 null과 구분되지 않음:** 시각 특징과 장면 설명을 넘는 정서 정보가 이 모델들의 어느 측정에도 없다. Du 2025류 결과의 정서 해석을 약화시킨다.
* **과제 무관 속 조건이 정서 질문 속 조건과 다름:** 정서 정보가 질문을 받았을 때만 속 상태에 생기는지(과제 의존), 질문 없이도 있는지(과제 무관)를 구분한다. 모델에 관한 사실이며 뇌의 처리 단계에 대한 결론은 아니다.
* **ROI 묶음별로 Δ가 갈림:** 측정 방식 차이가 어느 영역의 분산에서 생기는지 보여 주는 지도. 영역의 기능 해석은 탐색적이다.

## 11. Scientific Contribution

* **측정 방법(Axis U, Q):** AI 추정 정서 라벨을 신경 분석에 쓸 때 "어떻게 읽었는가"가 결과를 바꾸는지, 그리고 그 차이가 정서에 특별한지를 처음으로 직접 판정한다. 결과에 따라 label-provenance 태그의 "AI 추정"을 [AI 추정, 출력]과 [AI 추정, 내부 표상]으로 나누는 근거가 된다(frontier-ai Round 2 제안).
* **AI 해석(Axis R, Machine Affect Representations Sub-axis):** 모델 속 정서 방향을 사람 뇌라는 외부 기준으로 평가한다. 지금까지 모델 정서 vector의 타당성은 합성 자극과 모델 행동으로만 검증되었다(Sofroniew 2026, Xing 2026).
* **정서 이론에 대해서는 이 결과로 가를 수 없는 것을 명시한다(검토 X6):**
  * 범주 대 연속 논쟁: 답이 범주적이라는 모델의 성질을 뇌로 옮길 수 없으므로, 이 카드의 결과는 Horikawa 2020의 범주 결론과 Westlin 2025 재분석(arXiv:2507.00320)의 엇갈림을 판정하지 않는다.
  * HOT: 과제 무관 속 조건에 비유로만 연결한다. 모델의 두 측정이 사람의 1차 상태와 보고에 대응한다는 주장은 하지 않는다.
  * 모델 속 상태를 주관 경험으로 해석하지 않는다(Axis R Sub-axis 정의의 단서).

## 12. Limitations & Risks

* **데이터:** fMRI 참가자 본인 정서 보고가 없다. 라벨은 별도 평정자 규범이다. Horikawa 2020은 5명, 반복 없음, 블록 평균. Mind captioning은 6명이고 지각 학습 순서가 6명 모두 같다. 학습 자료는 2,108클립으로 줄어든다. 클립 ID 대응표가 필요하다. 영상이 무음이라 소리 관련 정서 정보는 없다. 보유본 전처리 형식이 미확인이다.
* **모델:** 방향은 연구자가 정한 추출 절차에 의존한다. 점검을 통과하는 정서 범주가 적으면 k가 작아져(EmoSet 겹침 범주 수준) 34범주 질문에서 멀어진다. 비정서 속성 선택이 Δ의 기준을 정하므로 속성 목록을 사전 등록하고 다른 목록으로 민감도를 본다. 내용 필터로 일부 클립(성적, 혈액 장면)에서 답이 거부되거나 왜곡될 수 있다(Santavirta 2025 Limitations). 가중치 라이선스 미확인.
* **오염:** 새 대조 자극(R2)을 마련하지 못하면 "오염 통제 불가"이며 답 쪽 우세 결과는 확증이 될 수 없다. 오염 점검은 오염이 없음을 증명하지 못한다. 시각 입력의 사전학습 포함 여부는 알 수 없다.
* **통계:** 11명은 집단 일반화에 작다. 피험자별 검정과 prevalence 추정으로 보완하지만 효과 크기 추정 중심이다. 상호작용 Δ는 네 칸의 추정 오차가 더해져 주효과보다 불확실하다(검정력 사전 계산 필요). 특징 묶음 사이 공선성이 높아 고유 설명량 추정이 불안정할 수 있다.
* **해석:** 결과는 "어느 측정이 뇌와 더 맞는가"이며, 뇌가 무엇을 "표상한다"는 결론이 아니다(decodability, representation, causality 구분).

## 13. Pilot Experiment

가장 작은 비용으로 핵심 전제(정서와 비정서에서 두 측정의 차이가 다르고, 그 차이가 null을 넘어 뇌와 관련되는가)를 먼저 본다.

1. **모델 하나:** Qwen3-VL-8B(가중치 라이선스 확인 후). 대안 Qwen2.5-VL-7B.
2. **오염 탐침 먼저(약 1일):** 무작위 100클립에 오염 점검 1, 2를 적용. 범주 이름 정답률이 우연을 크게 넘으면 모델을 바꾸거나, 탐침 정답 클립을 뺀 분석을 주 분석으로 바꾼다. Pilot에는 새 대조 자극(4번)이 없으므로 pilot 결과는 "오염 통제 불가" 상태로 해석한다.
3. **방향:** 정서는 EmoSet과 겹치는 범주로 시작(k는 점검 결과로 결정), 비정서는 같은 k개 속성.
4. **특징 추출:** 2,180클립 x 정서 질문과 비정서 질문 각 1판 x 답 표집 3회, 중간층 3개. 과제 무관 프롬프트 1판.
5. **뇌 분석:** Mind captioning에서 **학습 58 run(2,108클립)으로 피험자별 encoding을 학습하고, 시험 72클립(5회 평균, noise ceiling 있음)으로 평가한다.** 72클립은 학습에 넣지 않는다(검토 필수 3). 사전 지정 ROI 묶음 세 개에서 네 칸의 U와 Δ, 무작위 방향 null.
6. **계속, 수정, 중단 기준(사전 지정 ROI 묶음 단위, 검토 선택 9):**
   * 계속: transmodal 묶음에서 두 정서 칸 중 하나 이상이 무작위 방향 null을 넘는 U를 6명 중 4명 이상에서 보이고, (속, 정서)와 (답, 정서)의 상관이 0.9 미만(두 측정이 실제로 다름).
   * 수정: 두 정서 칸의 상관이 0.9 이상이면 답 판(token 확률 기댓값)과 층을 바꿔 다시 본다.
   * 중단: 세 묶음 모두에서 두 정서 칸이 공통 특징 B 위에서 null과 구분되지 않으면 본 연구를 RQ-08(캡션 잔차)의 하위 분석으로 축소한다.

## Safeguards 점검

| 항목 (CLAUDE.md 6절, 필수 태그) | 이 카드의 처리 |
|---|---|
| 참가자가 경험한 정서 vs 자극에 묘사된 정서 | 참가자 본인 보고가 없어 경험에 대한 결론은 내지 않는다. 모델 측정은 "보는 사람이 느낄 정서"를 묻지만 관찰자 관점(perceived) 추정으로 표기 |
| 인간 정서 주석 vs 모델 생성 주석 | 모델 측정은 모두 AI 추정. C&K 평정은 인간 규범. 캡션은 [Human 작성, AI 교정]. 같은 표에 섞지 않고 변수명으로 구분 |
| 참가자 본인 보고 vs 별도 평정자 규범 | C&K는 별도 평정자 규범(집계값). 본인 보고 없음 |
| 정서 표상 vs 시각/의미 내용 표상 | 공통 특징 B(시각 특징과 장면 설명), 2x2의 비정서 칸, 무작위 방향 null, 고차 시각 ROI 대조 |
| encoding 정확도 vs 설명적 적절성 | 결과는 "어느 측정과 더 맞는가"로만 쓴다. 높은 설명량을 정서 표상의 증거로 쓰지 않는다 |
| decodability vs representation vs causality | 뇌 쪽은 R0 상관. steering은 모델 내부의 인과(R1)이며 뇌의 인과가 아님 |
| in-silico 예측 vs 관찰 fMRI | 모델 특징은 자극 기술자이고 뇌 반응은 실측. in-silico 뇌는 쓰지 않음 |
| 공유 표상 vs 데이터셋 특이 교란 | 두 코호트 재현, 두 모델 계열 재현, 새 대조 자극(마련 시) |
| 탐색적 결과 vs 확증적 증거 | Pilot은 탐색이며 "오염 통제 불가" 상태. 본 분석의 Δ 정의, 비정서 속성 목록, 층 선택 규칙, 판정 규칙을 pilot 뒤 사전 등록 |
| HRF 지연과 시간 자기상관 | Horikawa는 블록 평균 1 sample. Mind captioning은 블록 단위 추정(원 논문 4 s shift, 보유본 미확인). 회상의 cue 읽기 혼입은 cue 공변량으로 통제하고, 구간 분리가 필요하면 연속 시계열에서 재처리 |
| stimulus, movie, subject 수준 leakage | **Mind captioning 학습은 58 run(2,108클립), 시험 72클립은 평가 전용.** 같은 원본에서 나온 클립은 같은 교차검증 묶음. 방향은 C&K와 독립인 자료로 추출. 층 선택은 중첩 교차검증 안에서 |

| 평정자 간 일치와 라벨 잡음 | C&K 평정자 개인 자료가 없어 라벨 신뢰도를 직접 잴 수 없음. 라벨은 공변량, 해석, 오염 점검에만 사용 |
