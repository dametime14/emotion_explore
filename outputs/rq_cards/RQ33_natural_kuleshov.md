## 1. Core Research Question

* **(a) 한 줄 질문:** 같은 장면도 앞에 무엇을 봤느냐에 따라 뇌가 그 장면의 정서를 다르게 표현할까?
  * rq_landscape의 원래 문장은 "다르게 느껴질까"였다. 이 데이터에는 참가자가 느낀 정서를 묻는 평정이 없으므로, 측정할 수 있는 대상(뇌 속 정서 표현)으로 고쳤다.
* **(b) 검증 가능한 세부 질문:** 같은 클립이 의사 무작위 순서로 서로 다른 클립 뒤에 제시될 때, 현재 클립의 뇌 반응에서 읽어 낸 정서는 직전 클립의 정서 쪽으로 끌려가는가(동화), 반대로 밀려나는가(대비)? 그리고 그 이동은 영역별 HRF(혈류 반응이 몇 초 늦게 오르내리는 모양)로 예측되는 앞 블록 신호의 섞임과, 시각 내용 쪽에서 생기는 같은 종류의 이동을 넘어서는가?

## 2. Scientific Motivation

1. **맥락은 정서 판단을 바꾼다. 다만 대부분 통제된 설계에서다.**
   * 영화 편집의 쿨레쇼프 효과: 같은 중립 얼굴도 앞 장면에 따라 다르게 읽힌다. fMRI(Mobbs 2006, Cao 2024)와 EEG(Calbi 2019)가 통제된 얼굴-장면 설계로 이를 다뤘다.
   * 행동 연구는 무작위 순서의 정서 자극에서도 평정이 직전 자극 쪽으로 끌린다고 보고했다(Van der Burg 2021). 이것을 serial dependence(직전 자극에 끌리는 지각 편향)라고 부른다. 자연 영화의 정서 지각은 약 12 s에 걸쳐 평활된다(Ortega 2023).
2. **분 단위의 정서 '관성'은 이미 있다. 수 초 단위의 자연 클립 연쇄는 비어 있다.**
   * 정서 영화 뒤 다른 과제나 휴지기 반응이 바뀐다(Pichon 2015, Gaviria 2021, Qiao-Tasserit 2017). 정서 뇌 상태가 이후 부호화로 이월된다(Tambini 2017).
   * 짧은 자연 클립이 연달아 나오는 상황에서, 뇌의 정서 표현이 앞 클립 쪽으로 이동하는지는 검정되지 않았다(감사 판정 partially).
3. **방법론적으로도 중요하다.** Horikawa 2020과 Mind captioning 학습 세션은 짧은 블록을 휴지 2 s만 두고 연달아 보여 주며, 순서가 피험자마다 같다. 앞 클립의 정서가 다음 블록 반응에 섞인다면, 이 데이터에서 나온 정서 decoding과 기하 결론의 해석 기준선이 바뀐다(Saarimäki 2025도 클립 간 이월을 한계로 적었다).
4. **이론 쪽 의미:** "정서 표현이 현재 자극만으로 정해지는가, 직전 맥락과 함께 만들어지는가"라는 물음은 정서를 맥락 속에서 구성되는 것으로 보는 입장과 자극에 고정된 반응으로 보는 입장 사이의 경험적 쟁점이다. 이 카드는 어느 입장도 미리 택하지 않고, 동화, 대비, 무효과 세 결과를 모두 해석 가능하게 설계한다.

## 3. Origin of the Idea

* **조합:** STR-G1. Strategy G(Counterfactual Neuroscience): 데이터셋 안에 이미 있는 실제 순서 변이를 반사실 조작처럼 쓴다. Coordinator가 전략 경로로 조합했다.
* **가장 가까운 문헌 기원:** multimodal-dynamics Round 1 Chain 1(Horikawa 연속 블록의 정서 이월)과 Round 2 MD-P1(클립 사이 이월). Mind captioning 테스트 세트가 "같은 클립을 다른 선행 클립 뒤에" 두는 조건이라는 점은 multimodal-dynamics가 Round 2에서 원 논문 Methods로 확인했다.
* **결합된 다른 에이전트 결과:**
  * geometry-info GI-P3: 같은 영역 안에서 정서 정렬 부분공간과 시각 정렬 부분공간을 대조한다.
  * systems-neuro SN-P2: 자율신경(몸의 각성) 이월을 따로 기술한다.
  * encoding-foundation과 generative-counterfactual의 Round 3 MD-P1 검토: TRIBE v2로 "자극으로 계산 가능한 이월"을 예측해 기준선으로 쓴다. 순서 무작위화가 확인되면 결론 수준을 데이터셋 안의 실제 조작(R3-internal)으로 올린다.
  * frontier-ai(Sofroniew 2026, arXiv:2604.07729): LLM 정서 표상은 국소적이라는 보고. 뇌의 맥락 의존성과 대비할 거리.
  * adversarial-reviewer 감사: 동화 방향은 HRF 섞임과 같은 방향이므로 HRF 예측을 넘는 초과분을 주 검정으로 둔다.
* **외부 분야:** 시각 과학의 serial dependence(Fischer & Whitney 2014), 영화 편집 이론의 쿨레쇼프 효과.

## 5. Novelty

* **이미 된 것(새로움으로 주장하지 않는다):**
  * 직전 정서 맥락이 현재 자극의 정서 판단을 끌어당긴다(행동, Van der Burg 2021, Ortega 2023).
  * 통제된 얼굴-장면 설계에서 맥락이 뇌 반응을 바꾼다(Mobbs 2006, Cao 2024, Calbi 2019).
  * 정서 상태가 분에서 수십 분 단위로 남는다(Pichon 2015, Gaviria 2021, Tambini 2017).
* **남는 새 부분(감사의 좁힌 범위):** 자연 정서 클립이 데이터셋 안에서 무작위로 이어질 때, **뇌의 정서 표현이 직전 클립 쪽으로 이동하는 부호(동화 또는 대비)와 크기**를 다음 두 기준을 넘는 초과분으로 잰다.
  1. 영역별(가능하면 voxel별) HRF로 예측한 앞 블록 신호의 섞임.
  2. 같은 영역에서 시각 내용 표현이 이동하는 정도.
* **부가적 새 부분:** 두 클립을 이어 넣은 in-silico 뇌(TRIBE v2) 예측이 관찰된 맥락 효과를 재현하는지(RQ-51 관문 통과 시에만).

## 6. Proposed Dataset

**주 데이터: Mind captioning (Horikawa 2025, OpenNeuro ds005191).** 사용자가 보유하고 전처리를 마쳤다(전처리 파이프라인 세부는 미확인).

| 필요한 것 | 있는가 | 근거와 메모 |
|---|---|---|
| 같은 클립의 서로 다른 선행 클립 | **있음** | 테스트 세션 10 run. 72개 클립을 두 run으로 나누어 각 클립을 5회 제시하고, run 안 순서는 의사 무작위[본문 Methods]. 피험자마다 테스트 순서가 같은지는 **미확인**(0단계에서 events로 확인) |
| 블록 구조 | 있음 | 10 s 미만 클립은 10 s를 넘을 때까지 반복 재생, 10 s 이상은 1회 후 1 s 미만 휴지로 TR 맞춤. 모든 블록 뒤 휴지 2 s, run 시작 32 s, 끝 8 s 휴지[본문]. 테스트 클립 평균 3.94 s라 블록 안에서 2~3회 반복된다[본문] |
| 평가 블록 | 있음(교란) | run마다 3~4개가 무작위 삽입. 직전 블록 내용에 대한 캡션 일치도 평정(문장 읽기 + 버튼)[본문, reviewer_notes 4.4] |
| 노출 횟수 | 계산 필요 | 테스트 클립은 학습 세션 마지막 두 run에서 1회 + 테스트 5회 + 회상 실험의 재시청 5회 = **최대 11회**. 회상 실험 전 '설명문과 영상 짝 연습' 노출이 더 있을 수 있다(본문 "viewing the pairs", 정확한 횟수 미확인). 세션 시간 순서는 events와 세션 정보로 확인 필요 |
| 학습 세션(decoder 학습용) | 있음 | 2,180개 클립 각 1회, 60 run. 순서는 6명 모두 같다[본문] |
| TR, 공간 해상도 | 있음 | 3T Prisma, TR 1 s, 2 mm[본문, vision-decoding 기록] |
| 정서 라벨 | 있음(규범) | Horikawa 2020 figshare의 34 범주 선택 비율, 14 차원 평균. **별도 MTurk 평정자의 규범 평정**이며 fMRI 참가자 본인 보고가 아니다[Stage 1]. Mind captioning 영상 ID와 Horikawa 2020 라벨 ID의 대응은 확인 필요(제시 ID 2,196개, 중복 처리 개수가 15 대 16으로 다름) |
| 참가자가 느낀 정서 | **없음** | Mind captioning 참가자는 캡션 일치도와 회상 vividness만 평정했다. 그래서 질문은 '느낌'이 아니라 '뇌 속 정서 표현'으로 한정한다 |
| 원본 자극 | 있음(무음) | Cowen & Keltner 클립 2,185개 모두 무음(사용자 확인). 시각 feature 추출에 사용 |
| 인간 캡션 | 있음 | 클립별 정서 배제 캡션 20개(사용자 확인). 의미 내용 통제에 사용 |
| 생리 신호 | **없음** | 자율신경 이월은 전역 신호로만 간접 점검(Mind captioning 전처리본은 회백질 전역 신호를 회귀했으므로 raw에서 다시 계산) |
| 피험자 수 | 6명 | 두 코호트 피험자는 겹치지 않음(사용자 확인) |

**보조 데이터: Horikawa 2020 (ds002425).** 5명, 2,181개 고유 클립 각 1회, TR 2 s. 순서가 5명 모두 같아 같은 클립의 선행 클립을 바꿀 수 없다. 대신 클립마다 선행 클립이 다르므로 클립 사이 회귀(R0)로 방향만 확인한다. 공개 전처리본은 4 s shift 후 블록 평균이라 raw 시계열로 다시 추정한다[Stage 1].

## 7. Proposed Computational Framework

| 항목 | 내용 |
|---|---|
| **Pretrained model** | 새 모델을 훈련하지 않는다. (1) **시각 내용 표현:** V-JEPA 2(arXiv:2506.09985, 영상 모델)와 CLIP(arXiv:2103.00020, 이미지-문장 모델)의 공개 checkpoint. 라이선스: V-JEPA 2는 TRIBE 논문 부록에 Apache로 기재(직접 미확인), CLIP은 미확인. (2) **캡션 의미 표현:** Mind captioning 논문이 쓴 DeBERTa-large 문장 feature 파이프라인(라이선스 미확인). (3) **in-silico 팔:** TRIBE v2(공개 checkpoint, encoding-foundation 기록상 CC BY-NC 4.0, 직접 미확인). (4) **HRF 추정:** GLMsingle(10.7554/eLife.77599, 코드 라이선스 미확인) |
| **Input representation** | 블록마다 (a) 단일 시행 반응: voxel별 HRF를 고른 GLM으로 추정한 블록 반응(앞뒤 블록을 동시에 모형화). (b) 직전 클립 변수: 규범 정서 벡터(34 + 14차원), 시각 feature(V-JEPA 2, CLIP의 상위 주성분), 저수준 feature(휘도, 움직임 에너지, 컷 수), 직전 블록이 평가 블록인지 여부, 직전 클립의 노출 횟수. (c) 현재 블록 변수: 클립 정체성, 노출 횟수, 블록 안 반복 재생 횟수, 블록 길이 |
| **Output / target representation** | (a) **정서 이동 지수:** 현재 블록 반응을 정서 decoder에 넣어 얻은 정서 벡터에서 같은 클립의 평균을 뺀 값을, (직전 클립 정서 - 현재 클립 정서) 방향에 투영한 크기. 양수 = 동화, 음수 = 대비. (b) **시각 이동 지수:** 같은 계산을 시각 feature decoder로. (c) **HRF 예측 이동 지수:** 추정 HRF와 실제 블록 시점으로 만든 시뮬레이션에서 나오는 이동 |
| **Training or adaptation strategy** | 정서 decoder와 시각 decoder는 학습 세션 58 run(테스트 클립이 나온 마지막 2 run 제외)으로 피험자별 ridge 회귀를 학습한다. 정서 부분공간은 시각, 캡션 feature로 설명되는 성분을 회귀로 뺀 정서 라벨로 학습해 시각 부분공간과 겹침을 줄인다(직교화 전후 모두 보고). 학습 세션은 순서가 고정이라 decoder가 앞 클립 정보를 배울 수 있으므로, 학습 시 직전 클립 라벨을 공변량으로 넣은 판본도 만든다. 사전학습 모델은 동결(fine-tuning 없음) |
| **Relevant brain regions / networks** | 정서 관련: vmPFC, OFC, ACC, 앞쪽 insula, TPJ와 STS, PCC와 precuneus(Horikawa 2020이 정서 정보를 보고한 transmodal 영역). 편도체는 signal-feasibility(신호 품질) 점검 후에만. 대조: 초기 시각(V1~V3), hMT+, 얼굴과 장면 선택 영역(Mind captioning의 retinotopy, fLoc, MT+ localizer로 개인별 정의). 아틀라스는 HCP-MMP(HCP360) |
| **Loss function or statistical objective** | decoder: L2 정규화 회귀(ridge). 주 검정: 혼합효과 회귀 `정서 이동 = β × (직전-현재 정서 차이) + nuisance + (피험자, 클립 무작위 효과)`. **주 통계량은 β_관찰 - β_HRF예측**(동화 초과분)과 β_정서 - β_시각. 모양 검정: 차이 크기에 대한 선형 함수 대 DoG(차이가 작을 때 끌리고 클 때 약해지거나 반대로 가는 모양) 함수의 모형 비교. 추론: run 안에서 선행 클립 배정을 섞는 순열 검정(실제 의사 무작위 제약을 지킨 재배열), 6명에 대한 Bayesian prevalence(모집단에서 효과를 가진 사람의 비율 추정, 10.7554/eLife.62461) |
| **Interpretability method** | 정서 범주별 동화, 대비 부호표. 이동이 큰 클립 쌍을 캡션과 함께 확인. decoder 가중치 지도. 영역별 HRF 모양과 이동 크기의 관계 그림. in-silico 예측 이동과 관찰 이동의 영역별 산점도 |

## 8. Proposed Analyses

**0단계: 데이터 확인 (모든 것보다 먼저)**
1. events 파일로 테스트 10 run의 실제 순서, 피험자 간 순서 동일 여부, 평가 블록 위치, run 첫 블록(선행 클립 없음) 수를 센다.
2. **선행 정서 범위 점검:** 클립마다 5번의 선행 클립 정서 벡터가 얼마나 다른지 계산한다. 지표는 클립 안 선행 정서 분산과 전체 클립 정서 분산의 비율, 그리고 (직전-현재 정서 차이)의 분포. 선행 클립이 같은 run 절반(36개 안팎)에서만 나오므로 범위가 좁을 수 있다. 범위가 충분하지 않은 정서 차원은 주 분석에서 뺀다(사전 등록).
3. 노출 횟수 계산: 학습 1회, 테스트 회차, 회상 실험 재시청 회차, 세션 날짜 순서. 짝 연습 노출 횟수가 기록에 없으면 "최소 노출 횟수"로 표시한다.
4. Mind captioning 영상 ID와 Horikawa 2020 라벨 ID의 대응표를 만들고 중복 클립 처리를 맞춘다.
5. 반복 기반 신뢰도: 테스트 5회 반복으로 영역별 신뢰도(같은 클립 반응의 반복 간 상관)를 구한다. 신뢰도가 낮은 영역은 해석하지 않는다.

**1단계: HRF 추정 (RQ-26과 공유)**
* 학습 세션 60 run(블록 길이가 다양함)과 테스트 run으로 voxel별 HRF를 고르고(GLMsingle의 HRF 묶음에서 선택), 영역별 HRF 지연과 꼬리 길이를 보고한다.
* 같은 HRF로 단일 시행 반응을 다시 추정한다. 앞뒤 블록을 함께 모형화해도 HRF가 틀리면 섞임이 남으므로, HRF 불확실성 범위(부트스트랩)를 저장한다.

**2단계: 정서, 시각 decoder와 부분공간**
* 7절대로 학습. 테스트 클립 반응에서 정서 decoding이 우연 수준을 넘는 영역만 3단계로 넘긴다.

**3단계: 주 검정 (동화 초과분과 대비)**
* (a) **HRF 예측 이동:** 1단계 HRF(불확실성 범위 포함)와 실제 블록 시점으로, 신경 반응이 현재 클립 정서만 담는다는 가정의 시뮬레이션을 만들고 같은 분석을 해 β_HRF 분포를 얻는다.
* (b) **β_관찰 - β_HRF:** 0보다 크면 HRF로 설명되지 않는 동화, 0보다 작으면 대비. 대비는 HRF 섞임이 만들 수 없는 방향이라 그 자체로 진단력이 있다.
* (c) **β_정서 - β_시각:** 같은 영역에서 정서 표현이 시각 표현보다 더 끌리면 정서 특이적 맥락 효과.
* (d) **대비 예측 조건(사전 등록):** 직전-현재 정서 차이가 상위 25%인 쌍(예: 매우 부정 뒤 긍정)을 따로 본다. serial dependence 문헌은 차이가 크면 끌림이 약해지거나 반대가 된다고 본다(Fischer & Whitney 2014).

**4단계: HRF 섞임과 구분하는 추가 지문**
* **모양:** HRF 섞임은 앞 블록 반응이 일정 비율로 더해지는 것이라 정서 차이 크기에 대해 선형이다. DoG 모양이 선형보다 확실히 나으면(교차검증 우도 비교) HRF만으로는 설명되지 않는다.
* **t-2 블록:** 두 블록 전 클립은 끝난 뒤 최소 14 s(휴지 2 s + 블록 10 s 이상 + 휴지 2 s)가 지나야 현재 블록이 시작되므로 HRF 섞임이 작다. 다만 HRF의 늦은 하강(undershoot)은 남을 수 있어 같은 시뮬레이션으로 t-2의 HRF 예측값도 구한다. 예측을 넘는 t-2 효과가 남으면 HRF 밖의 지속 성분 후보다(RQ-26과 연결).
* **현재 블록 길이 상호작용:** 현재 블록이 길수록(10 s 이상 클립) 블록 평균 안 HRF 섞임 비율이 줄어든다. 맥락 효과가 블록 길이에 따라 같은 비율로 줄면 HRF 쪽, 그렇지 않으면 신경 쪽.

**5단계: 교란 통제**
* 반복 억제: 노출 횟수와 블록 안 반복 재생 횟수를 공변량으로 넣고, 노출 1~3회 대 4회 이상으로 나눠 효과를 비교한다. 직전 클립의 노출 횟수도 넣는다(많이 본 클립은 반응이 작아 섞임도 작다).
* 평가 블록 뒤 블록은 주 분석에서 빼고, 따로 '정서 중립 선행'의 참고 조건으로만 본다(읽기와 버튼 반응이 섞이므로 기준선으로 쓰지는 않는다).
* 전역 신호와 느린 drift: run 단위 detrending, raw에서 다시 계산한 전역 신호를 공변량으로 넣은 판과 뺀 판을 모두 보고.

**6단계: in-silico 팔 (RQ-51 관문 통과 시에만)**
* 전제: TRIBE v2는 소리와 대사가 있는 영화로 학습되었으므로 **무음 클립 입력은 학습 분포 밖**이다(reviewer_notes 5절 RQ-51 전제 "약화"). RQ-51이 무음 입력에서도 해당 parcel의 정서 구조를 신뢰할 만큼 재현한다고 판정한 영역에서만 진행한다.
* 방법: 실제 제시 순서대로 [직전 클립 + 휴지 2 s + 현재 클립]을 이어 넣은 예측과 현재 클립만 넣은 예측의 차이로 '모델이 예측하는 맥락 효과'를 얻고, 관찰 맥락 효과와 부호, 크기를 비교한다. 공개판은 피질 평균 피험자 예측이라 피질 parcel, 관계 지표로만 비교한다.

**7단계: 보조 데이터 (Horikawa 2020, R0)**
* 고정 순서라 같은 클립의 선행 클립을 바꿀 수 없다. 클립 사이 회귀로 방향만 본다. Mind captioning 결과와 부호가 같은지 확인하는 수준이다.

**Baseline, ablation, validation**
* Baseline: (1) 선행 정서를 넣지 않은 모형, (2) 직전 클립 시각 feature만 넣은 모형, (3) HRF 섞임만 있는 시뮬레이션.
* Ablation: 정서 부분공간 직교화 전후, 전역 신호 회귀 전후, 노출 층화 전후.
* Validation: **주입 시뮬레이션**(실제 잡음 위에 알려진 크기의 동화나 대비를 심고 회복되는지)으로 검출 가능한 최소 효과를 먼저 계산한다. 회복이 안 되는 크기의 결과는 보고하지 않는다. 피험자별 결과와 Bayesian prevalence를 함께 보고한다.

## 9. Competing Explanations

| 대안 해석 | 무엇을 예측하나 | 가르는 분석 |
|---|---|---|
| **HRF 섞임(앞 블록 혈류 반응의 꼬리)** | 동화 방향, 차이 크기에 선형, t-2에서는 HRF 시뮬레이션이 예측하는 작은 값 이내, 현재 블록이 길수록 감소, 정서와 시각 부분공간에 비슷하게 | 3단계 (a)(b), 4단계 세 지문. 대비가 나오면 이 해석은 배제된다 |
| **시각 적응이나 시각 serial dependence** | 시각 부분공간에서도 같은 크기의 이동 | β_정서 - β_시각, 직전 클립 시각 feature 공변량 |
| **의미 맥락 이월(무엇을 봤는지)** | 캡션 의미 공간에서도 이동 | 캡션 feature를 뺀 정서 부분공간에서도 남는지 |
| **반복 억제와 친숙도** | 노출이 많을수록 효과 변화, 많이 본 직전 클립에서 효과 감소 | 노출 층화, 직전 클립 노출 공변량 |
| **반복으로 생긴 예측(다음 클립 기대)** | 같은 순서 쌍이 반복될수록 효과 증가 | 테스트 순서가 회차마다 바뀌는지 확인, 같은 쌍 반복 횟수 공변량 |
| **몸의 각성 이월(자율신경)** | 정서 범주와 무관하게 arousal 차원만 이동 | 이동을 arousal과 범주 성분으로 나눔, 전역 신호 판 비교. 생리 없음은 한계로 명시 |
| **decoder가 학습 세션의 고정 순서를 배움** | 학습 세션에서 직전 라벨이 decoder에 새어 들어감 | 직전 라벨 공변량을 넣어 학습한 decoder로 재분석 |
| **평가 블록(문장 읽기) 효과** | 평가 블록 뒤 블록에서만 이상 | 평가 블록 뒤 블록 제외 |

## 10. Potential Findings

| 결과 | 의미 |
|---|---|
| **HRF 예측을 넘는 동화, 시각보다 정서에서 큼** | 뇌의 정서 표현이 직전 정서 쪽으로 끌린다. 자연 영상에서의 신경 수준 쿨레쇼프 효과. 짧은 블록을 연달아 쓰는 정서 fMRI 설계(Horikawa 2020 포함)의 decoding 결과에 맥락 성분이 섞여 있다는 뜻 |
| **대비(특히 정서 차이가 큰 쌍)** | 직전 맥락이 현재 정서 표현을 반대로 밀어낸다. HRF로 만들 수 없는 방향이라 가장 강한 증거. 행동 serial dependence(동화)와 신경 표현의 방향이 다를 수 있음을 시사(Calbi 2019 같은 어긋남의 자연 영상판) |
| **동화가 HRF 예측 범위 안** | 관찰된 끌림은 혈류 반응 섞임으로 충분히 설명된다. 정서 특이적 맥락 효과의 증거는 없다. 기존 블록 decoding 결과는 HRF를 제대로 모형화하면 맥락에 오염되지 않았다는 방법론적 근거 |
| **정서와 시각에서 같은 크기** | 맥락 효과는 정서 고유가 아니라 일반 감각 순서 효과다 |
| **in-silico가 관찰을 재현** | 맥락 효과는 자극으로 계산 가능한 성분(자극 열의 특징)으로 설명된다. 재현하지 못하면 관찰 효과에 모델 밖 성분(내생 상태)이 있다는 후보 증거 |

## 11. Scientific Contribution

* **정서 표현의 맥락 의존성:** "자극 하나에 정서 표현 하나"라는 가정이 자연 클립 연쇄에서 얼마나 맞는지를 신경 수준에서 처음 직접 잰다. 정서를 맥락 속에서 구성되는 것으로 보는 입장은 맥락 효과를, 자극에 고정된 반응으로 보는 입장은 무효과(HRF 이내)를 예측한다. 어느 결과든 이 쟁점에 직접 자료를 준다.
* **행동과 신경의 대응:** 행동 serial dependence의 동화가 신경 정서 표현에서도 동화로 나타나는지, 대비로 나타나는지(또는 없는지)를 보인다.
* **방법론:** 정서 decoding 연구의 해석 기준선(맥락 성분의 크기)을 제공한다. HRF를 영역별로 추정하지 않으면 무엇이 잘못 보이는지를 이 데이터에서 정량화한다.
* **AI 비교:** in-silico 팔이 통과하면, 자극 계산 모델이 정서 맥락 효과를 재현하는지에 대한 첫 비교가 된다.

## 12. Limitations & Risks

* **데이터:** 참가자 본인의 정서 보고가 없다. 결론은 '느낌'이 아니라 '뇌 속 정서 표현의 이동'으로 한정된다. 라벨은 별도 평정자의 규범 평정이다. 6명. 생리 신호 없음.
* **선행 범위:** 선행 클립이 같은 run 절반에서만 나오므로 정서 차이의 범위가 좁을 수 있다(0단계가 판정).
* **반복:** 테스트 클립은 최대 11회(또는 그 이상) 노출되어 첫 시청과 다른 상태다. 결과를 '반복 시청 맥락'으로 한정해 보고한다.
* **HRF:** 휴지 2 s와 짧은 블록 때문에 HRF 추정이 틀리면 섞임이 남는다. 그래서 주 통계량을 HRF 불확실성 범위와 비교한다.
* **통계:** 효과가 작을 가능성(분 단위 효과도 작다, Pichon 2015). 주입 시뮬레이션으로 검출 한계를 먼저 정한다. 다중 비교는 사전 등록 ROI와 FDR로 제한.
* **in-silico:** TRIBE v2는 무음 입력이 분포 밖이고 피질 전용이다. RQ-51이 막으면 이 팔은 하지 않는다.
* **해석:** decodability(읽어 낼 수 있음)는 신경 표상의 직접 증거가 아니며 인과도 아니다. 정서 부분공간의 이동은 '정서 정보를 담은 반응 성분의 이동'으로만 서술한다.

## 13. Pilot Experiment

* **대상:** Mind captioning 피험자 2명, 테스트 10 run.
* **순서:**
  1. 0단계 1~4(순서, 선행 정서 범위, 노출 횟수, ID 대응). 반나절.
  2. 1단계를 3개 ROI(V1, vmPFC, 오른쪽 TPJ)에서만: voxel별 HRF 선택과 단일 시행 반응.
  3. 주입 시뮬레이션으로 검출 가능한 최소 β를 계산.
  4. V1에서 시각 이동 지수, vmPFC와 TPJ에서 정서 이동 지수를 계산해 β_HRF와 비교.
* **진행 기준:** (a) 선행 정서 범위가 충분한 차원이 3개 이상, (b) 검출 가능한 최소 β가 행동 serial dependence 크기에서 기대되는 수준 이하, (c) 정서 decoding이 vmPFC나 TPJ에서 우연 수준을 넘음. 셋 중 하나라도 실패하면 본 분석 전에 설계를 고친다.
* **계산 자원:** GPU 불필요(HRF와 회귀는 CPU). 시각 feature 추출에 GPU 1장 수 시간 가정(미확인).

## 반영하지 않은 지적

1. **geometry-info의 2성분 이완 모형(Round 3, discussion_record D4):** 짧은 이월과 영화 후 washout을 한 τ로 적합하면 잘못 지정된다는 지적이다. 이 카드는 washout과 이완 시간상수를 다루지 않고 이동의 부호와 크기만 묻는다. 2성분 모형은 RQ-26에 채택되었다. multimodal-dynamics는 이 지적에 동의한다(Round 3 이후 기록으로 남긴다).
2. **encoding-foundation의 "TRIBE 이월 예측을 1차 통제로"(Round 3 MD-P1 검토):** 원 제안은 in-silico 예측을 1차 기준선으로 쓰자는 것이었다. 이 카드는 무음 입력이 TRIBE 학습 분포 밖이라는 RQ-51 전제 때문에 in-silico를 **관문 뒤 부가 팔**로 내렸고, 1차 기준선은 관찰 데이터로 추정한 영역별 HRF 예측으로 두었다. 이유: 관문 통과 전에는 in-silico 기준선 자체의 타당성을 모른다.
3. **Emo-FilM washout을 함께 쓰자는 제안(MD-P1 원안, SN-P2):** 이 카드의 질문(같은 클립, 다른 선행)은 Emo-FilM에서 만들 수 없다(영화당 1회, 고정 순서). RQ-26의 범위로 남긴다.
4. **두 코호트 학습 세션 순서 대조로 2,180개 전체에서 선행을 바꾼 비교(encoding-foundation Round 3):** Horikawa 2020과 Mind captioning의 학습 순서가 다르면 가능하지만 아직 확인하지 않았다. 순서가 다르다고 확인되면 7단계를 이 비교로 확장한다. 지금은 확인 전이라 설계에 넣지 않았다.
5. **새 행동 평정(R2)으로 같은 순서의 serial dependence를 확인하자는 방향(검토 중 나온 확장 아이디어):** 비용이 낮고 의미가 크지만 새 데이터 수집이라 이 카드의 범위(기존 데이터) 밖이다. 후속 연구로 남긴다.

## Safeguards 점검

| 항목 | 이 카드의 처리 |
|---|---|
| 참가자가 경험한 정서 vs 자극에 그려진 정서 | 참가자 보고 없음. 라벨은 평정자가 '느꼈다'고 보고한 규범 평정. 결론은 '자극 정서 정보의 신경 표현 이동' |
| 인간 정서 평정 vs 모델 생성 정서 평정 | 정서 라벨은 인간(MTurk) 평정만. 모델 feature는 시각, 의미 통제와 in-silico 비교에만 |
| 본인 보고 vs 규범 평정 | 규범 평정만 있음. 명시 |
| 정서 표상 vs 시각, 의미 내용 표상 | 정서 부분공간 직교화, 시각 부분공간 대조, 캡션 feature 통제 |
| encoding 정확도 vs 설명 적절성 | decoder 성능을 목적으로 하지 않음. 이동의 부호와 모양으로 대안 설명을 가름 |
| decodability vs 신경 표상 vs 인과 | '정서 정보를 담은 반응 성분'으로 서술. 순서 무작위화는 데이터셋 안의 조작이지만 정서를 직접 조작한 것은 아님 |
| in-silico 예측 vs 관찰 fMRI | 6단계를 별도 보고. RQ-51 관문 |
| 공유 표상 vs 데이터셋 특이 교란 | 반복 노출, 평가 블록, 블록 구조는 Mind captioning 특이 교란으로 명시하고 통제 |
| 탐색적 결과 vs 확인적 증거 | 주 통계량, ROI, 대비 조건, 제외 기준을 사전 등록. 나머지는 탐색적 |
| HRF 지연과 시간 자기상관 | 영역별 HRF 추정(1단계), HRF 예측 이동을 기준선으로, 순열 검정 |
| 자극, 영화, 피험자 수준 누수 | decoder는 테스트 클립이 나온 학습 run 제외. 클립 무작위 효과 |
| 반복 자극 교란 | 노출 횟수(최대 11회 이상), 블록 안 반복 재생, 직전 클립 노출 횟수 |
| 평정자 일치와 라벨 잡음 | 비디오당 평정자 수가 적다(범주 9~17명, Stage 1). 정서 차원은 0단계 범위 점검 후 선택 |
| 시각-의미-정서 feature 공선성 | 직교화와 시각, 캡션 공변량 |
| 시간, 공간 해상도 한계 | TR 1 s, 휴지 2 s. 수 초 이하 동역학은 해석하지 않음 |
| ROI 선택과 순환 추론 | 아틀라스와 독립 localizer로 ROI 정의. 같은 데이터로 ROI를 고르지 않음 |
| 다중 비교 | 사전 ROI, FDR |
| 데이터 접근, checkpoint, 라이선스 | 데이터 보유. checkpoint 라이선스 일부 미확인(14절) |
| 사전학습 데이터 오염 | V-JEPA 2, CLIP이 Cowen & Keltner 클립을 학습했을 가능성 미확인. 시각 통제 feature로만 쓰므로 영향은 통제 강도에 한정 |
| 데이터셋 간 라벨 비호환 | 주 분석은 한 데이터셋. Horikawa 2020 보조는 같은 라벨 |
| **label-provenance** | 대상 felt(평정자 자기 경험 보고) / 주체 별도 평정자 규범(MTurk) |
| **evidence-level** | R0. 테스트 순서 무작위화가 확인되면 선행 클립 효과에 한해 R3-internal(데이터셋 안 실제 조작). 정서 자체를 조작하지는 않음 |
| **insilico-vs-observed** | 관찰(주). in-silico 팔은 혼합으로 분리 보고 |
| **G1** | 주 분석은 라벨과 뇌만으로 가능하나 시각 통제 feature에 원본 자극 필요(보유) |
| **signal-feasibility** | 편도체는 개인별 dropout, tSNR 점검 후에만. 반복 신뢰도로 ROI 선별(0단계 5) |
| **minimum-validation** | 경쟁 모형과 matched null(HRF 시뮬레이션, 시각 부분공간): 충족 예정. 상한: 반복 신뢰도 병기. 신뢰도 민감도: 노출 층화. leakage: run 제외. 일반화 수준: 6명, 반복 시청 상태로 명시. 라벨 출처: 표시. 반증 해석 사전 기술: 10절과 아래 Falsifiability |

### Falsifiability (반증 조건)
* 다음이 모두 성립하면 "HRF를 넘는 신경 정서 맥락 효과" 가설은 지지되지 않는다.
  1. 정서 이동 지수가 HRF 예측 범위(부트스트랩 95% 구간) 안에 있다.
  2. 정서 이동이 같은 영역의 시각 이동보다 크지 않다.
  3. 차이 크기에 대한 함수가 선형 모형보다 DoG 모형에서 낫지 않다.
  4. 대비 예측 조건에서 대비가 나타나지 않는다.
  5. 주입 시뮬레이션상 행동 serial dependence 수준의 효과를 검출할 검정력이 있었다.
* 5번이 성립하지 않으면(검정력 부족) 결과는 "판정 불가"로 보고한다.
