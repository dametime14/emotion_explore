## 1. Core Research Question

* **(a) 한 줄 질문:** 소리 없는 영상을 볼 때 뇌는 '들릴 법한 소리'를 떠올리고, 그 소리가 정서를 실을까?
* **(b) 검증 가능한 세부 질문:** 무음 정서 클립을 볼 때 청각피질 반응은, 영상에서 소리를 만들어 내는 생성 모델(video-to-audio, V2A)이 만든 소리의 오디오 표현으로, 그 모델이 소리를 만들 때 쓴 시각 정보와 독립 시각, 캡션 정보를 넘어 더 잘 설명되는가, 그리고 그렇게 더 설명되는 성분이 클립의 정서를 읽어 낼 수 있게 하는가?

---

## 2. Scientific Motivation

1. **무음 영상도 청각피질을 움직인다. 이것은 이미 알려져 있다.** 소리를 암시하는 무음 영상(동물, 악기, 물건)을 볼 때 초기 청각피질 활동이 소리 종류를 구분했다(Meyer 2010). 후측 STS는 보기와 듣기에 걸쳐 같은 내용을 표현했다(Man 2012). 반대 방향으로, 소리와 심상의 범주 정보가 초기 시각피질에서 읽혔다(Vetter 2014).
2. **비어 있는 것은 두 가지다.**
   * 무음 영상이 청각피질에 남기는 신호가 **소리 형식**(실제로 들었다면 날 법한 소리의 음향 구조)으로 정리되어 있는지, 아니면 '개', '폭발' 같은 **의미 범주**나 시각 움직임 정보의 재표현인지 모른다. Vetter 2014는 감각 간 정보가 정밀한 감각 형식이 아니라 추상 범주일 수 있다고 보았다.
   * 그 신호가 **정서**를 싣는지 모른다. 같은 영화를 시청각, 시각 전용, 청각 전용으로 보여 준 연구는 정서 정보가 제시 모달리티의 감각 피질에 더 잘 맞는다고 보고했고(Lettieri 2024), 시각 전용(자막 포함 무음) 판본에서는 시각 영역 쪽이 강했다. 무음 영상의 정서가 청각피질을 거치는지는 검정되지 않았다.
3. **지금 이 질문을 할 수 있는 이유:** V2A 생성 모델(MMAudio 등)은 영상만 보고 그럴듯한 소리를 계산한다. 이 모델이 만든 소리를 '뇌가 떠올렸을 법한 소리'의 계산 가설로 쓸 수 있다.
4. **Horikawa 데이터의 제약을 질문으로 바꾼다.** Horikawa 2020과 Mind captioning의 Cowen & Keltner 클립은 모두 무음이다(사용자 확인). 그래서 청각, 음악 질문에는 못 쓴다고 보았지만(Stage 1), 바로 그 무음 조건이 '암시된 소리'를 묻는 자연 실험이 된다.
5. **중요한 개념적 단서(reviewer_notes 5절):** 생성 소리는 영상의 함수다. 영상에 없는 정보를 더할 수 없다. 그래서 이 질문은 "정보가 더 있는가"가 아니라 "청각피질 반응이 **소리 형식으로 바꿔 쓴 표현**과 더 잘 맞는가"를 묻는다. 그 판정에는 V2A 모델 자신이 쓴 시각 조건 표현이 핵심 null이다.

## 3. Origin of the Idea

* **조합:** RND-30. 무작위 경로에서 B(지각 표현) + F(뇌 표상) + M(멀티모달) + R(설명 가능성) + T(평가)가 뽑혔고, Coordinator가 L(생성 방법)을 더했다.
* **연결된 에이전트 결과:**
  * multimodal-dynamics Round 1 U3(정서는 어느 감각 채널에 의존하는가), Chain 3(소리가 만드는 정서), Round 2 MD-P3와 encoding-foundation EF-P7(in-silico 감각 박탈과 관찰된 무음 조건의 대조).
  * Round 3 EF-P7 검토(llm-semantics, brain-inspired): 같은 자극의 관찰 대 in-silico 비교를 1차로, 정서 기하는 의미를 제거한 뒤 정의.
  * adversarial-reviewer 평가: 합계 2위(34점), "V2A 시각 조건 embedding 대조가 필수".
* **외부 분야:** 생성 AI의 video-to-audio 합성(MMAudio), 청각 신경과학의 DNN encoding(Tuckute 2023), 다감각 통합 연구(Meyer 2010, Vetter 2014).

## 5. Novelty

* **이미 된 것(새로움으로 주장하지 않는다):** 무음 영상이 청각피질에 소리 종류 정보를 남긴다(Meyer 2010). 보기와 듣기의 내용이 STS에서 수렴한다(Man 2012).
* **남는 새 부분(감사의 좁힌 범위):**
  1. V2A 생성 모델이 계산한 '암시된 소리' 표현이 자연 무음 정서 클립의 청각피질 반응을, **그 모델 자신의 시각 조건 표현**(그리고 독립 시각 모델, 인간 캡션 의미) **이상으로** 설명하는가.
  2. 그 추가 성분이 **정서 정보를 싣는가**.
* **부가적 새 부분:** 정서 유발 클립 2,180개라는 규모와 두 코호트(11명) 재현. Meyer 2010은 소리 종류가 뚜렷한 소수 자극이었다.

## 7. Proposed Computational Framework

| 항목 | 내용 |
|---|---|
| **Pretrained model** | 새 모델을 훈련하지 않는다. (1) **V2A 생성:** MMAudio(arXiv:2412.15322, CVPR 2025). 시각 조건은 CLIP 1024차원(8 fps)과 Synchformer 시각 feature(24 fps, 768차원), 텍스트 조건은 선택. 기본 모델은 16 kHz 소리를 20차원 VAE 잠재(31.25 fps)로 생성. **라이선스 미확인**(코드와 가중치 모두). (2) **생성 소리 표현 encoder:** LAION-CLAP 오디오 encoder(arXiv:2211.06687, 라이선스 미확인), Tuckute 2023이 비교한 공개 오디오 모델 중 청각피질 예측이 좋은 계열(구체 checkpoint는 0단계에서 선택), 저수준 기준선으로 스펙트로-시간 변조 필터. (3) **시각 대조:** MMAudio 자신의 CLIP, Synchformer 조건 feature(핵심 null), 독립 시각 모델 V-JEPA 2(arXiv:2506.09985). (4) **의미 대조:** Mind captioning 캡션의 DeBERTa-large 문장 feature(원 논문 파이프라인). (5) 선택적 in-silico 팔: TRIBE v2(CC BY-NC 4.0, encoding-foundation 기록, 직접 미확인) |
| **Input representation** | 클립마다: (a) 생성 소리 표현: seed 5개 이상으로 생성한 소리를 오디오 encoder 층별 embedding으로 바꾸고 seed 평균. 10 s 미만 클립은 제시와 같게 생성 소리도 반복 재생 길이로 맞춘다. (b) MMAudio 시각 조건 feature(같은 클립, 시간 평균과 시간 통계). (c) V-JEPA 2 feature. (d) 캡션 문장 feature. (e) 움직임 에너지, 컷 수(청각피질이 시각 움직임에 반응할 가능성 통제) |
| **Output / target representation** | 블록 단위 voxel 반응(청각 ROI, 대조 ROI). 정서 단계의 목표는 규범 정서 벡터(34 + 14차원) |
| **Training or adaptation strategy** | 사전학습 모델은 동결. 피험자별 banded ridge encoding(feature 묶음마다 다른 정규화)을 클립 묶음 단위 교차검증으로 학습. 같은 원본에서 나온 클립과 내용 중복 쌍은 같은 fold. MMAudio는 텍스트 없이 영상만으로 생성하는 것이 기본 조건이고, 캡션을 텍스트로 넣은 조건은 대조로만 쓴다 |
| **Relevant brain regions / networks** | 주: 초기 청각피질(A1, LBelt, MBelt, PBelt, RI), 청각 연합(A4, A5, STGa, TA2), 후측 STS(다감각 수렴). 대조: V1~V3(생성 소리가 시각 영역에서도 이득을 주면 '더 나은 시각 feature' 해석), 정서 관련 transmodal 영역(vmPFC, insula, TPJ)은 정서 단계에서 비교용 |
| **Loss function or statistical objective** | encoding: L2 정규화 회귀. 주 통계량: 청각 ROI에서 생성 소리 묶음의 **고유 설명량**(시각 조건 + V-JEPA 2 + 캡션 + 움직임 묶음 위에 더한 증가분)과 그것의 V1 대비 차이. 정서 단계: 생성 소리 고유 성분으로 예측한 반응에서 규범 정서를 decoding한 정확도와, 시각 묶음만의 성분에서 decoding한 정확도의 차이. 추론: 클립 단위 순열(생성 소리를 같은 정서 범주의 다른 클립 것과 바꿈), 피험자별 검정과 Bayesian prevalence(10.7554/eLife.62461) |
| **Interpretability method** | 고유 설명량이 큰 클립을 골라 생성 소리를 실제로 듣고 캡션과 대조(소리를 내는 사건인지). 오디오 encoder 층별 청각 ROI 대응(1차 대 비1차). 정서 범주별 decoding 이득 표. 생성 소리의 정서 방향(CLAP 정서 텍스트 프롬프트 유사도, AI 추정)과 규범 정서의 관계 |

## 8. Proposed Analyses

**0단계: 전제 확인**
1. **청각피질이 무음 시청에서 재현 가능한 반응을 내는가:** Mind captioning 테스트 72개 x 5회로 청각 ROI의 반복 간 신뢰도를 구한다. 신뢰도가 우연 수준이면 이 질문은 이 데이터로 답할 수 없다(중단 기준).
2. **소리를 내는 사건의 비율:** 캡션에서 소리를 내는 사건(웃음, 비명, 동물, 악기, 폭발, 물 등)을 세어 클립별 '소리 암시 정도'를 만든다. 비율이 낮으면 검정력이 낮다.
3. **생성 품질과 의미 일치:** 생성 소리와 캡션의 CLAP 오디오-텍스트 유사도를 구해 터무니없는 생성을 걸러낸다. 말소리 장면은 MMAudio가 웅얼거림을 만든다는 한계(4.4 Limitations)가 있으므로 따로 표시한다.
4. **seed 신뢰도:** 같은 클립의 seed 간 embedding 일치도. 낮으면 seed 평균 수를 늘린다.

**1단계: 주 검정 (소리 형식의 고유 설명량)**
* 청각 ROI에서 [MMAudio 시각 조건 + V-JEPA 2 + 캡션 + 움직임] 모형과 여기에 [생성 소리]를 더한 모형의 교차검증 예측 정확도 차이(고유 설명량)를 구한다.
* **이중 해리 검정:** 생성 소리의 고유 설명량이 청각 ROI에서 크고 V1~V3에서 작아야 '소리 형식' 해석이 선다. 시각 영역에서도 비슷하게 크면 생성 소리는 단지 '더 나은 비선형 시각 feature' 역할을 한 것이다.

**2단계: 특이성 대조**
* **불일치 소리:** 같은 정서 범주의 다른 클립에서 생성한 소리로 바꿨을 때 고유 설명량이 사라져야 한다.
* **텍스트만으로 만든 소리:** 캡션만 MMAudio 텍스트 조건으로 넣어 만든 소리(영상 정보 없음). 이것으로도 같은 이득이 나면 청각피질 신호는 '의미 범주' 수준이다(Vetter 2014 해석). 영상 조건 소리가 더 나으면 시간 구조나 장면 세부까지 담긴 '소리 형식' 쪽.
* **시간 섞은 영상으로 만든 소리:** 프레임 순서를 섞어 생성한 소리. 동기화 시간 정보가 이득의 출처인지 본다.
* **저수준 음향 기준선:** 생성 소리의 스펙트로-시간 변조 feature만으로 얼마나 설명되는가(1차 청각피질 쪽 예측).

**3단계: 정서 검정**
* (a) 1단계 모형에서 생성 소리 묶음으로 예측한 반응 성분만 써서 규범 정서 34 + 14차원을 decoding한다. 시각 묶음 성분만 쓴 decoding과 비교하고, 둘을 합쳤을 때 늘어나는 몫을 본다.
* (b) 정서 범주별로 어느 정서가 소리 성분에서 더 읽히는지 본다. 사전 가설은 두지 않되, Lettieri 2024가 모달리티에 따라 유발 정서가 다르다고 보고한 점(공포는 청각만으로 덜, 경멸은 더)을 해석 참고로 둔다.
* (c) 생성 소리의 정서 방향(CLAP 정서 프롬프트 유사도, AI 추정)이 규범 정서와 일치하는 클립에서 청각 ROI 정서 decoding이 더 좋은지 본다.

**4단계: 코호트 재현**
* Horikawa 2020(5명, TR 2 s)과 Mind captioning(6명, TR 1 s)에서 따로 분석하고 효과 방향과 prevalence를 비교한다. 두 코호트 피험자는 겹치지 않는다(사용자 확인).

**5단계 (선택): in-silico 팔**
* TRIBE v2에 [영상만] 과 [영상 + 생성 소리]를 넣어 청각 parcel 예측을 만들고, 어느 쪽이 관찰된 무음 시청 반응과 더 닮았는지 본다. TRIBE v2는 시청각 영화로 학습되어 영상만 넣으면 학습 분포 밖이므로 **RQ-51 관문**을 통과한 parcel에서만 한다. 공개판은 피질 전용, 평균 피험자.

**Baseline, ablation, validation**
* Baseline: 시각 조건 + V-JEPA 2 + 캡션 + 움직임 모형(주 null), 무작위 오디오 feature(같은 차원 무작위 투영).
* Ablation: 오디오 encoder 종류와 층, seed 수, 텍스트 조건 유무, 반복 재생 길이 맞춤 유무.
* Validation: 클립 묶음 교차검증, 두 코호트 재현, 주입 시뮬레이션(알려진 크기의 소리 성분을 심어 검출 한계 계산).

## 9. Competing Explanations

| 대안 해석 | 무엇을 예측하나 | 가르는 분석 |
|---|---|---|
| **생성 소리는 더 나은 시각 feature일 뿐** | 고유 설명량이 시각 영역에서도 비슷하게 큼 | 청각 대 V1~V3 이중 해리(1단계) |
| **청각피질 신호는 의미 범주(무엇이 나오는가)** | 캡션 묶음과 텍스트만으로 만든 소리로 충분히 설명 | 캡션 묶음 통제, 텍스트 전용 생성 소리 대조(2단계) |
| **청각피질이 시각 움직임, 입 움직임에 반응** | 움직임 에너지, Synchformer 동기화 feature로 설명 | 움직임 묶음과 시각 조건 feature 통제, 시간 섞은 영상 대조 |
| **주의나 각성이 청각피질 전체를 올림** | 정서 각성과 함께 청각 ROI 평균 반응 증가, 내용 특이성 없음 | 불일치 소리 대조(같은 범주 다른 클립), 전역 신호 공변량 |
| **속말(inner speech)이나 문장 읽기** | 말소리 장면, 평가 블록 직후 블록에서 효과 | 말소리 장면 표시와 분리, Mind captioning 평가 블록 직후 블록 제외 |
| **생성 모델의 학습 분포 편향(VGGSound 위주)** | 특정 소리 종류에서만 효과 | 클립별 생성 품질 점수와 효과의 관계, seed 신뢰도 |
| **정서 decoding 이득이 시각 정서 정보의 재포장** | 소리 성분의 정서 decoding이 시각 성분 위에 아무것도 더하지 않음 | 3단계 (a)의 증분 비교 |

## 10. Potential Findings

| 결과 | 의미 |
|---|---|
| **청각 ROI에서만 생성 소리의 고유 설명량이 있고, 정서 decoding도 늘어남** | 무음 정서 영상을 볼 때 청각피질이 '들릴 법한 소리'를 소리 형식에 가깝게 표현하고, 그 성분이 정서 정보를 싣는다. 무음 영상의 정서 처리에 다감각 예측이 관여한다는 증거(R0 상관 수준, 생성 소리는 R1 장치) |
| **고유 설명량은 있으나 정서 이득 없음** | 암시된 소리 표현은 있지만 정서는 시각, transmodal 경로로 처리된다. Lettieri 2024의 "시각 전용 판본에서는 시각 영역" 결과와 맞는다 |
| **텍스트 전용 생성 소리로도 같은 이득** | 청각피질의 무음 시청 신호는 소리 형식이 아니라 의미 범주 수준(Vetter 2014 해석 지지) |
| **시각 영역에서도 같은 이득** | V2A 소리는 비선형 시각 feature로 작동했을 뿐이다. 소리 형식 가설은 지지되지 않는다 |
| **청각피질의 반복 신뢰도 자체가 낮음(0단계 중단)** | 이 데이터의 무음 시청에서는 청각피질 반응을 분석할 수 없다. 짧은 정서 클립에서 Meyer 2010 수준의 효과가 재현되지 않는다는 것 자체가 정보다 |

## 11. Scientific Contribution

* **감각 간 정서 처리:** 정서를 담은 장면을 보기만 해도 청각 쪽 표현이 정서를 함께 실어 나르는지 처음 묻는다. 정서를 감각 독립적인 추상 코드로 보는 입장(Lettieri 2024의 vmPFC 결과)과, 감각마다의 예측 표현이 정서에 기여한다고 보는 입장 사이에 자료를 준다.
* **Horikawa 결과의 재해석 단서:** Horikawa 2020은 무음 시청에서 정서 정보가 여러 영역에 분산되어 있다고 보고했다. 그 분산 표현의 일부가 '암시된 소리' 성분인지 알 수 있다.
* **AI 모델의 새 쓰임:** 생성 모델을 뇌가 계산했을 법한 표현의 가설 장치로 쓰는 방법을 감각 간 문제에 적용하고, 그 해석을 모델 자신의 입력 표현으로 통제하는 null 설계를 제시한다.
* **Axis M 연결:** 무음 데이터셋(Horikawa, Mind captioning)과 소리 있는 데이터셋(Emo-FilM, Spacetop)을 대비하는 질문들의 기준점이 된다(무음에서 소리 성분이 이미 있다면 '소리 유무' 대비의 해석이 바뀐다).

## 12. Limitations & Risks

* **데이터:** 원래 소리가 없어 생성 소리가 맞는 소리인지 확인할 수 없다. 참가자에게 소리 심상을 묻지 않았다. 청각 localizer가 없다. 라벨은 규범 평정.
* **신호:** 무음 시청의 청각피질 반응은 약할 가능성이 크다(0단계가 판정). 3T, TR 2 s(Horikawa 2020)는 약한 감각 간 신호에 불리하다.
* **모델:** MMAudio는 VGGSound 같은 일상 소리 위주로 학습되어 정서 장면(울음, 비명, 음악적 분위기)에서 품질이 낮을 수 있다. 말소리는 웅얼거림을 낸다(4.4 Limitations). 라이선스 미확인. 생성은 확률적이라 seed 평균이 필요하다. 사전학습 데이터에 Cowen & Keltner 클립이 들어 있는지 미확인.
* **해석:** 생성 소리는 영상의 함수라 '새 정보'를 줄 수 없다. 결과는 표현 형식에 관한 것이다. 고유 설명량이 있어도 '참가자가 소리를 떠올렸다'는 직접 증거는 아니다(관찰 상관, R0). 정서 decoding 이득은 decodability이지 정서 경험의 판독이 아니다.
* **통계:** feature 묶음들이 강하게 공선적이라 고유 설명량이 작게 나올 수 있다. banded ridge와 교차검증, 주입 시뮬레이션으로 검출 한계를 먼저 계산한다.

## 13. Pilot Experiment

* **대상:** Mind captioning 6명의 테스트 72개 클립(반복 5회).
* **순서:**
  1. 청각 ROI(A1, belt, STG, 후측 STS)와 V1의 반복 간 신뢰도 계산. 청각 ROI 신뢰도가 우연 수준이면 중단.
  2. 72개 클립에 MMAudio로 seed 5개씩 소리 생성(360개, 8 s 생성에 1.23 s라는 논문 수치 기준 GPU 1장 수 분, 하드웨어 차이 미확인).
  3. 캡션 기반 소리 암시 점수와 생성 품질 점수 계산.
  4. 72개만으로 1단계 주 검정의 축소판(클립 묶음 교차검증)을 해 효과 크기를 추정하고, 본 분석(2,180개 x 11명)의 검정력을 계산.
* **진행 기준:** 청각 ROI 신뢰도가 유의하고, 축소판에서 생성 소리의 고유 설명량이 V1보다 청각 ROI에서 큰 방향이면 본 분석으로 간다.
* **계산 자원:** 미확인. GPU 1장 가정(생성과 embedding). 본 분석 생성은 2,180개 x seed 5개 = 10,900개로 수 시간 규모 추정(미검증).

## 반영하지 않은 지적

1. **Round 3 EF-P7 검토(llm-semantics, brain-inspired)의 "Emo-FilM과 Horikawa 대조는 자극이 달라 교란이 크다":** 이 카드는 처음부터 무음 두 코호트만 쓴다. 소리 있는 데이터셋과의 대비는 넣지 않았다. 지적과 같은 방향이라 별도 반영이 필요 없다.
2. **새 행동 평정(R2)으로 생성 소리의 정서를 인간이 평정하는 단계:** 생성 소리의 정서 방향을 AI(CLAP 프롬프트)가 아닌 인간 평정으로 확인하면 3단계 (c)가 강해진다. 새 데이터 수집이라 이 카드 범위 밖으로 두고 후속 확장으로 남긴다.
3. **실제 원래 소리와 생성 소리의 비교:** 원래 소리가 없어(사용자 확인, 2차 출처 엇갈림) 반영할 수 없다. 원 영상의 소리 판본을 따로 구할 수 있다면 가장 강한 검증이 되지만 현재 경로가 없다.

## Safeguards 점검

| 항목 | 이 카드의 처리 |
|---|---|
| 참가자가 경험한 정서 vs 자극에 그려진 정서 | 참가자 보고 없음. 정서 라벨은 평정자가 '느꼈다'고 보고한 규범 평정. 결론은 '정서 정보를 담은 청각피질 성분'까지 |
| 인간 정서 평정 vs 모델 생성 정서 평정 | 정서 기준은 인간 규범 평정. 생성 소리의 정서 방향(CLAP)은 AI 추정으로 따로 표시 |
| 본인 보고 vs 규범 평정 | 규범 평정만 있음 |
| 정서 표상 vs 시각, 의미 내용 표상 | 시각 조건 feature, V-JEPA 2, 캡션 묶음을 null로. 정서 이득은 시각 성분 대비 증분으로만 |
| encoding 정확도 vs 설명 적절성 | 고유 설명량과 이중 해리, 특이성 대조로 해석. 정확도 자체를 목표로 하지 않음 |

### Falsifiability (반증 조건)
* 다음 중 하나라도 성립하면 "청각피질이 암시된 소리를 소리 형식으로 표현한다" 가설은 지지되지 않는다.
  1. 청각 ROI에서 생성 소리의 고유 설명량이 시각 조건 + V-JEPA 2 + 캡션 + 움직임 모형 위에서 0과 구분되지 않는다.
  2. 같은 크기의 고유 설명량이 V1~V3에서도 나온다(이중 해리 실패).
  3. 텍스트 전용 생성 소리나 불일치 소리로도 같은 이득이 나온다.
* "그 소리가 정서를 싣는다" 가설은 생성 소리 성분의 정서 decoding이 시각 성분 위에 증분을 주지 않으면 지지되지 않는다.
* 0단계에서 청각 ROI 반복 신뢰도가 우연 수준이면 결과는 "판정 불가"로 보고한다.
