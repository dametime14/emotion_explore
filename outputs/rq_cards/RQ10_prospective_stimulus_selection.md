## 1. Core Research Question

* **(a) 한 줄 질문:** 정서를 기준으로 고른 영상과 장면 내용을 기준으로 고른 영상 중 어느 쪽이 처음 보는 사람의 정서 관련 뇌 영역을 더 잘 움직일까?
* **(b) 검증 가능한 세부 질문:** Horikawa 2020 피험자 일부와 클립 일부로만 학습한 정서 encoder와 시각-의미 encoder가 정서 관련 영역(amygdala, 앞쪽 insula, vmPFC/OFC, TPJ)에 대해 서로 다른 클립을 "가장 강하게 움직일 것"으로 고를 때, 선택 목록과 분석 코드를 봉인한 뒤 측정한 학습 미사용 Horikawa 피험자와 Mind captioning 6명의 실제 반응은 어느 encoder의 예측에 더 가까운가?

## 2. Scientific Motivation

**왜 중요한가**
* Horikawa 2020은 정서 평정 모델이 시각 객체 모델과 의미 모델보다 여러 transmodal 영역을 더 잘 설명한다고 보고했다(doi:10.1016/j.isci.2020.101060).
* 그러나 이 비교는 세 모델을 따로 맞춘 뒤 성능을 비교한 것이다. 의미 공변량에 측정 오차가 있으면 정서 고유 기여가 실제보다 크게 보일 수 있다(doi:10.1371/journal.pone.0152719).
* 구조가 크게 다른 모델들도 자연 자극 전체에 대한 예측력은 거의 같게 나온다. 그래서 전체 예측 정확도만으로는 어느 모델이 맞는지 가리기 어렵다(doi:10.1038/s41467-024-53147-y Discussion, arXiv:2302.06677).

**어떤 공백이 있는가**
* 두 모델이 서로 다른 예측을 하는 자극을 골라 보는 방법(controversial stimuli, 두 모델이 엇갈리게 고른 자극, doi:10.1073/pnas.1912334117)이 모델을 가리는 가장 강한 방법이다. 정서 영역에서 정서 모델과 시각-의미 모델을 이렇게 맞붙인 연구는 감사 범위에서 없었다.
* "모델이 고른 자극이 새 사람에게서 그 영역을 실제로 움직이는가"라는 검증은 언어망(Tuckute 2024), 범주 선택 영역(Ratan Murty 2021), amygdala 생성 이미지(NeuroVolve)에서 이미 새 fMRI로 수행되었다. 이 부분은 새롭지 않다.
* 남는 공백은 하나다. 같은 자극을 본 두 독립 코호트(Horikawa 2020 5명, MC 6명)가 있으므로, 새 촬영 없이 "정서 모델과 시각-의미 모델이 엇갈리게 고른 영상"을 코호트를 건너 시험할 수 있다.

## 3. Origin of the Idea

* **조합 ID:** LIT-30 (문헌 경로).
* **결합된 결과:**
  * encoding-foundation EF-P6(Round 2): 독립 코호트로 하는 검증, 즉 이미 모은 자료로 흉내 낸 "미리 맞히기" 검증과 provenance(출처) 등록부.

  * adversarial-reviewer Round 1 D6(의사 전향 검증), encoding-foundation Round 1 I2와 I6(엇갈림 선택, 고처리량 선택성 검정).
* **가져온 분야:**
  * 시각과 언어 NeuroAI의 neural control과 controversial stimuli(Golan 2020, Ratan Murty 2021, Tuckute 2024, Gifford 2025).
  * 메타과학의 분석 유연성(forking paths)과 사전 등록(Botvinik-Nezer 2020, doi:10.1038/s41586-020-2314-9; Simonsohn 2020, doi:10.1038/s41562-020-0912-z, DB 초록 수준).
  * ML 평가의 누수(leakage) 분류(Kapoor & Narayanan 2023).

## 5. Novelty

**이미 수행된 부분(새로움으로 주장하지 않음)**
* encoder가 고른 자극이 새 사람에게서 그 영역을 움직이거나 누르는지 보는 검증. 언어망(Tuckute 2024), 범주 영역(Ratan Murty 2021), amygdala 생성 자극(NeuroVolve)에서 새 fMRI로 이미 수행되었다.
* 단순 구동/억제 성공률은 보조 결과로만 보고한다.

**남는 새 부분(감사 판정의 범위)**
* **정서 encoder와 시각-의미 encoder가 엇갈리게 고른 영상에서, 정서 관련 영역의 실제 반응이 어느 encoder의 예측에 가까운지를, 코호트를 건너 봉인된 상태로 시험한다.** 주 산출물은 이것 하나다.

**가장 가까운 선행과의 차이**
* Tuckute 2024: 한 모델의 구동/억제 선택. 영역은 언어망, 검증은 새 fMRI.
* 이 카드: 두 모델의 경쟁. 영역은 정서 관련 영역, 검증은 이미 수집된 독립 코호트.

**RQ-08 2단계와의 경계** (검토 권장 3)
* RQ-08 2단계는 "정서 모형 대 캡션 모형이 엇갈리는 클립에서의 판별"을 **탐색**으로 둔다(RQ-08 카드 8절 2단계).
* 두 질문의 역할은 아래처럼 나눈다.

| | RQ-08 2단계 | RQ-10 |
|---|---|---|
| 성격 | 코호트 안 탐색 | 코호트를 건넌 봉인 확증 |
| 영역 | RQ-08 1단계가 고른 정서 잔차 voxel | 해부학 기준으로 미리 정한 정서 관련 영역 |
| 비교 모델 | 정서 대 캡션 | 정서 대 영상 + 캡션 + 저수준 feature |
| 선택 모델이 검증 클립을 학습에서 보았는가 | 제한 없음 | 보지 않음(클립 cross-fitting) |

* 같은 대비를 두 번의 독립 확증으로 세지 않는다.
* RQ-08 2단계를 MC 데이터로 돌리면 RQ-10의 분석자 노출이 된다. 그래서 RQ-08 2단계의 MC 판은 RQ-10 봉인 뒤에 돌린다.
* 판 C(0절)이면 둘을 하나의 탐색 분석으로 합친다.

**이 카드가 Tuckute 2024보다 약한 점(명시)**
* 검증 데이터가 새로 수집된 것이 아니라 이미 전처리된 자료다. 그래서 분석자 노출을 봉인으로 막아야 한다(8.5절).
* 증거 수준은 R3가 아니라 사전 등록된 R0다.

## 7. Proposed Computational Framework

### Pretrained model
공개 모델을 먼저 쓴다. 정서 encoder와 시각-의미 encoder는 이 feature 위에 선형 회귀(ridge)만 학습한다.
* **V-JEPA 2** (arXiv:2506.09985): 영상 feature. 코드 라이선스 MIT(frontier-ai 확인). 가중치는 CC-BY-NC 4.0으로 기재한 출처가 있다(arXiv:2605.29850 표 3). 본 에이전트는 가중치 라이선스를 직접 확인하지 못했다(**미확인**).
* **문장 embedding 모델:** 캡션 embedding용. 허용 라이선스 공개 모델 중 사전 등록 때 하나를 고정한다(후보와 라이선스 **미확인**).
* **TRIBE v2** (arXiv:2605.04326): zero-shot 선택 팔. CC BY-NC 4.0(저장소 LICENSE 확인). 가중치는 Hugging Face(README 링크, 직접 열람 못함). 연구 목적 사용은 가능하다.
* **보조 선택 팔(FA-P2):** 공개 가중치 VLM의 내부 정서 vector 투영. 모델 선택과 라이선스는 **미확인**이고 AI 추정으로 표기한다.
* **사용 금지:** EmoNet(Cowen & Keltner 프레임으로 학습, doi:10.1126/sciadv.aaw4358).
* **계산 자원:** **미확인.** GPU 1~4장을 가정한다. V-JEPA 2 feature 추출(약 2,180개 짧은 클립)과 TRIBE v2 추론은 GPU 수 시간 규모, ridge와 통계는 CPU로 충분하다고 추정한다.

### Input representation
* **정서 encoder(E):** 클립별 규범 정서 평정 48차원(34범주 선택 비율 + 14차원 평균).
* **시각-의미 encoder(V):**
  * V-JEPA 2 embedding(클립 프레임 평균, 층은 학습 fold 안에서 선택)
  * 캡션 20개의 문장 embedding 평균([Human 작성, AI 교정])
  * 저수준 feature(움직임 에너지, 밝기, 대비, 시각 현저성)
  * 차원은 PCA로 줄인다.
* **TRIBE v2 팔(T):** 무음 영상만 입력한다. 실험의 클립 반복 재생과 블록 구조를 그대로 재현한 시퀀스를 넣는다.
* **nuisance 공변량(모든 팔):** 클립 원래 길이, 코호트별 반복 재생 횟수, 블록 길이, run 안 위치, 직전 블록이 평가 블록인지(MC만).

### Output / target representation
* 영역별 블록 반응(HCP360 parcel 평균, 피질하 ROI 평균). 두 코호트에서 같은 규칙(4 s 이동, 블록 평균 창, run 안 z-score)으로 다시 계산한다(6절 연속 시계열 행).
* 미리 정한 표적 영역(해부학 기준, Horikawa 결과로 고르지 않음):
  * amygdala
  * 앞쪽 insula(HCP360 AAIC, AVI)
  * vmPFC/OFC(10r, 10v, 25, s32, OFC, pOFC)
  * TPJ/IPL(PGi, PGs, TPOJ1)
  * 대조 시각 영역(V1, FFC, PHA1)

### Training or adaptation strategy
* **D6a 모델 검증(주 분석):**
  * 클립을 5-fold로 나눈다. 같은 원본으로 의심되는 클립(embedding 유사도 기준)과 내용 중복 쌍은 같은 fold에 둔다.
  * fold마다 나머지 4개 fold 클립으로만 E, V를 학습하고, 보류 fold 클립 안에서만 고른다(cross-fitting).
  * 피험자는 Horikawa 4명으로 학습하고 1명을 보류한다(5회 순환).
  * 선택 풀에서 MC 시험 72개는 뺀다.
  * 검증은 보류 Horikawa 피험자와 MC 6명(학습 세션 2,108개 클립 반응)으로 한다.
  * 결과적으로 모든 선택 클립은 그 선택을 한 모델이 학습에서 본 적 없는 클립이다.
* **D6b 관찰 기반 참조값(보조):**
  * Horikawa 5명의 실제 관찰 반응 평균으로 영역별 상위/하위 클립을 고르고 MC에서 검증한다.
  * 모델이 아니라 "정서 영역을 움직이는 클립"이 코호트를 건너 재현되는지 본다.
  * **상한이 아니라 참조값이다.** 단일 제시 5명 평균은 잡음이 커서, encoder 예측(잡음을 평균으로 줄인 예측)이 D6b보다 잘 고를 수 있다. 해석은 10절 7번.
* **TRIBE v2 팔:**
  * 학습하지 않는다(zero-shot). 선택은 두 코호트 모든 피험자에게 검증할 수 있다.
  * **RQ-51 관문**(in-silico 충실도 지도)을 통과한 피질 parcel에서만 쓴다. 무음 짧은 클립 시퀀스는 TRIBE v2 학습 분포(연속 영화, 소리 있는 3 s 클립, 무음 연속 영상) 밖이다.
  * 공개 checkpoint는 피질만 예측하므로 amygdala에는 쓰지 않는다.
* **복잡도를 맞춘 비교(matched-complexity):**
  * E와 V의 학습 fold 안 교차검증 정확도를 함께 보고한다.
  * V를 더 크게 만든 판(층 추가, 차원 증가)과 E+V 결합 판도 둔다.

### Relevant brain regions / networks
* 정서 관련: amygdala, 앞쪽 insula, vmPFC/OFC, TPJ/IPL. Horikawa 2020의 transmodal 쪽 결과와 겹치는 망(DMN 일부, salience)에 해당한다.
* 대조: V1, FFC, PHA1.
* signal-feasibility: MC 시험 72개 반복의 영역별 반복 간 신뢰도가 사전 하한(예: split-half r 0.1 이상, 사전 등록 때 확정)보다 낮은 영역은 확증 분석에서 뺀다.

### Loss function or statistical objective
* 학습: 영역별 ridge 회귀. 목적은 평균제곱오차, 정규화 강도는 학습 fold 안 교차검증으로 고른다.
* **엇갈림 집합:** 영역 r마다 보류 클립에서 두 집합을 만든다. 두 집합은 클립 길이와 반복 재생 횟수 구간으로 짝을 맞춘다.
  * E 단독 선택: E 예측 상위 q%이면서 V 예측 중앙값 이하
  * V 단독 선택: V 예측 상위 q%이면서 E 예측 중앙값 이하
* **주 통계량(검토 권장 5 반영):** 같은 두 집합에 대해 세 값을 구한다.
  * 관측 Δ_obs = (E 단독 선택 클립의 관찰 반응 평균) - (V 단독 선택 클립의 관찰 반응 평균). 단위는 z, 피험자별로 계산
  * E가 예측한 Δ_E: E 예측값으로 같은 차이를 계산
  * V가 예측한 Δ_V: V 예측값으로 같은 차이를 계산. 정의상 Δ_E > 0, Δ_V < 0이다
  * 판정은 Δ_obs가 Δ_E와 Δ_V 중 어느 쪽에 가까운가로 한다. 예측 크기는 각 모델의 held-out 정확도로 줄여(shrink) 극단 예측의 평균 회귀 차이를 보정한 값을 쓴다. Golan 2020의 "적어도 하나는 틀린다" 논리다.
* **검정:**
  * 피험자별로 E/V 표지를 짝 안에서 섞는 순열 검정
  * MC 6명에 대한 Bayesian prevalence(doi:10.7554/eLife.62461)
  * 피험자와 클립을 함께 일반화하는 2-factor bootstrap 신뢰구간(doi:10.7554/eLife.82566)
  * 영역 수에 대한 Holm 보정
* **귀무를 주장할 때(동등성 검정):** SESOI(가장 작은 의미 있는 효과)는 Pilot의 D6a 효과로 정하지 않는다(검토 권장 6). 대신 **Horikawa 내부 관찰 기반 참조값**의 절반으로 정한다. 참조값은 4명 관찰 평균으로 고른 클립을 보류 피험자 1명에서 검증한 Δ다. 하한은 0.05 z이고, 봉인 전에 고정한다.

### Interpretability method
* 엇갈림 클립 목록 자체를 공개한다. 영역별로 E 단독 선택 클립과 V 단독 선택 클립의 캡션, 규범 정서 profile, 저수준 속성 분포를 나란히 보여 준다.
* 영역 x 선택 표적 특이성 행렬을 만든다. vmPFC용으로 고른 클립이 insula보다 vmPFC를 더 움직이는지 본다.
* E가 고른 클립의 정서 범주 분포가 한두 범주(예: 공포, 혐오)에 몰리는지 확인한다(범주 군집 효과, doi:10.1016/j.neunet.2025.107515).

## 8. Proposed Analyses

### 8.0 0단계 (봉인 전, MC 반응을 보지 않고 할 일)
1. **0절 사용자 확인**을 받고 진행 판(A, B, C)을 정한다.
2. 두 코호트 클립 ID 대응표를 만든다(영상 파일 해시, embedding 일치).
3. 클립 원래 길이와 코호트별 반복 재생 횟수를 계산한다.
4. 표적 영역 정의와 MC의 HCP360 투영 절차를 고정한다.
5. 연속 시계열이 있는지 확인한다. 없으면 raw에서 다시 처리하는 경로를 고정한다(6절).
6. **RQ-51 관문 결과**를 가져와 TRIBE 팔을 쓸 parcel 목록을 정한다.

### 8.1 signal-feasibility 점검과 검출력 시뮬레이션 (검토 권장 7)
* MC 시험 72개 반복으로 영역별 반복 간 신뢰도를 계산한다. 이것은 클립 정체와 무관한 품질 지표라 봉인 전에 계산해도 선택에 정보가 새지 않는다. 반복 클립의 정서 내용별 신뢰도는 보지 않는다.
* **검출력 시뮬레이션:**
  * 그 신뢰도에서 추정한 영역별 SNR로 가짜 반응을 만든다. 가짜 반응에는 SESOI 크기의 E 신호를 심는다.
  * 6명, 실제 엇갈림 집합 크기에서 이 신호를 회복할 확률(검출력)을 계산한다.
  * 검출력이 사전 기준(예: 0.8)에 못 미치는 영역은 확증 대상에서 빼거나 탐색으로 표시한다.
* 시각 대조 영역에서 V가 이기는 것은 거의 확실하므로(규범 평정에는 저수준 정보가 적다), 대조만으로는 정서 영역의 검출력을 보장하지 않는다. 그래서 시뮬레이션을 대조와 함께 둔다.
* 정서 수준별 신뢰도는 봉인 뒤 결과 표에만 함께 보고한다.

### 8.2 D6a 모델 검증 (주 분석)
* 5-fold 클립 cross-fitting과 Horikawa 피험자 1명 보류 순환으로 E, V, (T), (VLM 팔) 선택 목록을 만든다.
* **주 산출물:** 영역별 Δ_obs를 Δ_E, Δ_V와 비교한 판정(7절).
* **보조 산출물:** 모델별 구동 대 억제 선택 차이(Tuckute식 성공률)를 무작위 클립 기준선과 비교한다. 선행이 있으므로 보조로만 보고한다.

### 8.3 D6b 관찰 기반 참조값 (보조)
* Horikawa 관찰 반응으로 고른 영역별 상위/하위 클립을 MC에서 검증한다.
* D6a 선택의 성공률을 D6b 참조값과 무작위 선택(하한) 옆에 나란히 보고한다.

### 8.4 비교 조건, baseline, ablation
* baseline:
  * 무작위 클립 선택(seed 봉인)
  * 저수준 feature만 쓴 선택기
  * E+V 결합 선택기
* ablation:
  * V에서 캡션 embedding 제거(영상 feature만)
  * V에서 V-JEPA 2 제거(캡션만)
  * E에서 14차원만 또는 34범주만 사용
* MC 시험 72개는 선택과 검증에서 빼고 신뢰도 계산에만 쓴다. 검증은 MC 학습 세션 2,108개 반응(1회 노출)만 쓰므로 Horikawa의 1회 노출과 조건이 맞다.

### 8.5 분석자 노출 차단과 봉인 절차 (필수)
**배경**
* 사용자가 MC를 이미 전처리했다.
* EmoMind(arXiv:2605.16739)가 같은 코호트의 정서 decoding 결과를 공개했다.
* 이 프로젝트의 다른 Pilot(P1 RQ-08, P2 RQ-01)도 MC 반응을 분석할 예정이다(`selection.md` 6절).
* 봉인이 없으면 이 질문은 R0 상관 분석과 다르지 않다(`reviewer_notes.md` 4.3절).

**절차**
1. **노출 기록부(봉인 전).**
   * MC의 영역 수준 반응이나 그 분석 결과를 본 사람을 모두 적는다. 날짜, 본 내용, 본 영역을 적는다.
   * 사용자(전처리 수행), EmoMind 공개 결과를 읽은 사람, P1/P2 담당자를 포함한다.
   * 0절 확인 결과로 진행 판을 정한다.
2. **금지 입력 목록.** 선택 단계에서 다음을 쓰지 않는다.
   * MC 반응
   * EmoMind의 decoding 결과나 그림
   * P1/P2와 RQ-08 2단계의 MC 결과
   * 선택은 Horikawa 2020 데이터, 규범 평정, 캡션, 영상 feature만으로 한다.
3. **봉인 대상 파일:**
   * `rq10_selection.csv`(영역, 선택기, 방향, fold, clip_id, 예측값, Δ_E, Δ_V)
   * `rq10_analysis.py`(MC 반응을 읽어 사전 등록 통계만 출력하는 검증 스크립트)
   * `rq10_config.yaml`(영역 정의, nuisance, q%, SESOI, 신뢰도 하한, 검출력 기준, 통계 검정, 다중비교)
   * 환경 고정 파일(패키지 버전)
   * 무작위 기준선 seed
   * **이 카드 파일**(설계가 MC 뇌 데이터를 본 적 없는 상태에서 쓰였다는 기록)
4. **해시와 시점.**
   * 각 파일의 SHA-256 해시와 git commit 해시를 manifest 하나에 모은다.
   * manifest(해시만, 데이터 없음)를 외부 시점 기록이 남는 곳에 올린다. 예: OSF 사전 등록(비공개 embargo), Zenodo 기록, 공개 timestamp 서비스.
   * 같은 manifest를 분석에 관여하지 않는 사람(Coordinator 또는 연구실 동료)에게 보내 보관하게 한다.
5. **실행 순서.**
   * RQ-10 봉인은 P1, P2, RQ-08 2단계가 MC의 정서 관련 영역 반응을 분석하기 **전에** 끝낸다.
   * 지킬 수 없으면 RQ-10 선택 분석자를 그 분석들과 분리한다(정보 차단).
6. **검증 실행.**
   * 검증 스크립트는 시작할 때 manifest 해시와 대조하고, 불일치하면 멈춘다.
   * 출력은 사전 등록 통계로만 제한한다. 사후 분석은 별도 파일에 "탐색"으로 표시한다.
7. **변경 기록.** 봉인 뒤 바꾼 모든 것을 날짜와 이유와 함께 `deviations.md`에 적고 결과 보고에 첨부한다.

### 8.6 통계와 검증 전략 요약
* 일반화 수준:
  * D6a의 Horikawa 보류 피험자: 새 클립 + 새 피험자(같은 코호트)
  * D6a의 MC: 새 클립 + 새 피험자 + 새 코호트(scanner, TR, 블록 구조 다름)
  * D6b: 새 코호트에서 같은 클립
* 피험자 일반화는 prevalence, 클립 일반화는 bootstrap으로 추론한다.
* MC 6명은 같은 순서를 공유하므로, 코호트 안 순서 효과를 피험자 간 독립성으로 세지 않는다. run 안 위치를 공변량으로 둔다. 두 코호트 사이 순서는 사실상 독립이다(Spearman -0.03).

### 8.7 RQ-08과의 연결
* 공유 자원: 캡션 embedding, V-JEPA 2 feature, 두 코호트 재처리.
* 실행 순서: RQ-10 봉인 → RQ-08 2단계 MC 판.
* 판 C이면 RQ-10과 RQ-08 2단계를 "엇갈림 클립에서의 정서 대 내용 판별" 하나의 탐색 분석으로 합치고, 결론은 RQ-08 카드의 해석 경계를 따른다.

## 9. Competing Explanations

| 대안 해석 | 이를 가르는 분석 |
|---|---|
| E가 고른 클립이 이긴 것은 정서가 아니라 저수준 속성(길이, 반복 재생 횟수, 움직임, 밝기) 때문이다 | 길이와 반복 횟수 구간으로 짝을 맞춘 엇갈림 집합. 저수준 선택기 baseline. nuisance를 잔차화한 뒤 선택한 판과 비교 |
| 승패가 정서 대 내용의 차이가 아니라 두 encoder의 품질(신뢰도) 차이를 반영한다. 정서 평정은 9~17명 집계라 잡음이 크고, 잡음이 큰 모델의 극단 예측은 더 크게 평균으로 돌아간다 | Δ_obs를 각 모델의 held-out 정확도로 줄인 Δ_E, Δ_V와 비교한다(7절). 학습 fold 안 정확도를 함께 보고한다. **V 승리를 "정서 우위가 측정 오차로 생겼다"는 근거로 읽는 것은 E의 held-out 정확도가 V와 비슷할 때만 허용한다.** E가 덜 정확한데도 E 쪽에 가까우면 강한 증거로 본다 |
| 규범 평정이 사실상 장면 의미를 압축한 것이라 E가 "더 나은 의미 모델"일 뿐이다 | V에 캡션 embedding을 포함한다. 엇갈림 클립의 캡션 의미 범주 분포를 비교한다. RQ-08(캡션으로 설명하고 남는 정서) 결과와 영역별로 대조한다 |
| 정서 영역이 아니라 전반적 각성이나 현저성이 반응을 올린다 | 영역 x 선택 표적 특이성 행렬. 억제 선택(하위 q%)도 함께 검증한다. 시각 대조 영역에서 V가 이기는지 본다 |
| MC에서 실패한 것은 모델이 틀려서가 아니라 코호트 차이(scanner, TR, 반복 재생, 전처리) 때문이다 | D6a의 Horikawa 보류 피험자 결과와 비교한다. D6b(관찰 기반 선택)도 실패하면 코호트 간 재현성 자체의 한계로 해석한다. 같은 규칙으로 다시 계산한 블록 반응과 원 방식 블록 반응을 비교한다 |
| 분석자 노출로 선택이 검증 데이터에 맞춰졌다 | 0절 확인과 8.5절 봉인. 무작위 seed 기준선이 우연 수준인지 확인한다 |
| 시선 차이(자유 시청)가 영역 반응을 만든다 | 측정 불가. V에 시각 현저성 feature를 넣는 것으로 일부만 줄인다. 한계로 명시 |
| 반복과 친숙도 효과 | 11회 이상 노출된 72개 시험 클립을 선택과 검증에서 뺀다. S1(예비 노출)을 뺀 판을 함께 보고한다 |

## 10. Potential Findings

1. **정서 영역에서 Δ_obs가 Δ_E 쪽에 가깝고, 시각 대조에서는 Δ_V 쪽에 가깝다.**
   * 정서 영역 반응 차이의 일부는 시각-의미 feature로 계산되지 않는 정서 평정 공변으로 미리 예측되고, 그 예측이 사람과 코호트를 넘어 일반화된다.
   * 라벨이 규범 평정이므로 결론은 "자극의 규범 정서 속성"까지다. 참가자 경험에 대한 결론이 아니다.
2. **정서 영역에서도 Δ_V 쪽에 가깝거나 차이가 없고(동등성 확인), 시각 대조는 정상.**
   * E의 held-out 정확도가 V와 비슷할 때만, 정서 평정이 정서 영역 반응을 미리 고르는 데 시각-의미 feature보다 나은 정보를 주지 않는다고 결론낸다.
   * E가 덜 정확하면 "라벨 잡음 때문에 판정할 수 없음"으로 보고한다.
3. **Horikawa 보류 피험자에서는 E 쪽, MC에서는 V 쪽이거나 차이 없음.** 정서 영역 선택이 코호트 특이적이다(scanner, 블록 구조, 순서, 전처리). S축(일반화)에 대한 결과다.
4. **D6b(관찰 기반 선택)부터 MC에서 실패.** 정서 영역을 움직이는 클립 자체가 코호트를 넘어 잘 재현되지 않는다. Westlin 2025의 개인 특이성 보고(arXiv:2507.00320)와 같은 방향의 결과다.
5. **TRIBE 팔이 E만큼 맞는다.** 관문을 통과한 피질 영역에서는 자극만으로 계산한 in-silico 뇌도 정서 영역을 움직이는 클립을 고를 수 있다. TRIBE 팔이 E보다 크게 못하면 in-silico 선택의 한계를 보여 준다.
6. **양성 대조(시각 영역)도 실패하거나 검출력 시뮬레이션이 기준 미달.** 이 설계의 검출력이 부족하다. 정서 영역 결과를 해석하지 않는다(반증으로 세지 않음).
7. **D6a 선택이 D6b 참조값보다 잘 맞는다.** 모델이 관찰 평균보다 잡음을 덜 탄 예측을 냈다는 뜻이다. 모델이 "관찰을 넘는 진실"을 안다는 뜻으로 읽지 않는다. 반대로 D6a가 D6b보다 크게 못하면, 모델이 관찰 반응의 재현 가능한 부분을 놓친다는 뜻이다.

**이론과의 연결(검토 X6 반영):** 위 결과는 기본정서 이론과 구성주의 이론이 모두 수용할 수 있다. 정서 평정이 장면 의미와 함께 운반된다는 결과는 두 이론 모두 예측한다. 그래서 이 카드의 결과로 **두 이론을 가를 수 없다.** 결과는 "정서 영역 반응을 미리 고르는 데 어떤 자극 기술이 더 쓸모 있는가"라는 측정 수준의 결론으로만 쓴다.

## 11. Scientific Contribution

* **정서 대 의미 내용 문제:** 정서 관련 영역의 반응을 "장면 내용만 보는 모델"과 "정서 평정"이 각각 얼마나 미리 예측하는지를, 두 예측이 엇갈리는 영상에서 사전 등록된 전향 예측으로 판정한다. 이 문제는 Horikawa 2020의 정서 모델 우위 주장(doi:10.1016/j.isci.2020.101060)과 그에 대한 측정 오차 비판(doi:10.1371/journal.pone.0152719)에 걸쳐 있다.
* **정서 영역 '선택성' 주장의 검정 방식:** 범주 선택 영역에서 쓰던 고처리량 선택성 검정(Ratan Murty 2021)과 엇갈림 판정(Golan 2020)을 정서 영역에 적용한다. 정서 이론(기본정서 대 구성주의)을 가르는 결과는 아니다(10절 끝).
* **방법론:** 이미 수집된 같은 자극의 두 코호트에서 봉인 절차로 "미리 맞히기" 검증을 흉내 내는 틀을 정서 연구에 제공한다. 새 fMRI 검증(R3)보다 약하다는 점을 명시한 채로다.

## 12. Limitations & Risks

* **새로움이 작다.** 같은 논리가 언어망, 범주 영역, amygdala 생성 자극에서 새 fMRI로 검증되었다. 남는 부분은 엇갈림 판정 하나다(감사 판정). 판 C이면 더 작아진다.
* **봉인 가능 여부가 미확인이다.** 0절 확인 전에는 MC 결과의 확증 지위를 정할 수 없다.
* **이미 수집된 검증 데이터.** 봉인을 지켜도 Tuckute 2024의 새 fMRI 검증보다 약하다.
* **표본.** 학습 5명, 검증 6명이다. 코호트 안 피험자들은 같은 순서를 공유한다. 모집단 평균이 아니라 prevalence만 추론한다.
* **엇갈림 집합 크기.** 정서 평정과 시각-의미 feature(특히 캡션)가 공선적이면 두 모델이 서로 다른 클립을 고르는 경우가 적다. Pilot에서 집합 크기가 하한(영역당 한쪽 15개 이상, 사전 등록 때 확정)에 못 미치면 주 분석을 할 수 없다.
* **라벨.** 규범 평정(별도 MTurk 평정자)이고 비디오당 9~17명 집계라 잡음이 있다. 참가자 본인 경험, 생리, 시선이 없다. 캡션은 [Human 작성, AI 교정]이며 교정 전 원문은 확인할 수 없다.
* **전처리 차이.** 두 코호트의 공개 전처리 방식이 다르고, 사용자 MC 보유본의 파이프라인은 미확인이다. 연속 시계열이 없으면 raw에서 다시 처리해야 한다.
* **피질하.** Horikawa TE 43 ms에서 amygdala 신호가 약할 수 있다. 신뢰도나 검출력이 기준 미달이면 확증 분석에서 뺀다. TRIBE 팔은 피질만 가능하다.
* **TRIBE v2.** 무음 짧은 클립 시퀀스는 학습 분포 밖이다. RQ-51 관문을 통과한 parcel에서만 쓴다. 라이선스는 비상업(CC BY-NC 4.0)이다.
* **클립 ID 대응과 블록 구조 차이.** 두 코호트의 반복 재생 기준(8 s 대 10 s)이 달라 같은 클립의 노출량이 다르다.
* **모델 라이선스와 계산 자원**은 미확인이다.
* **overlap:** EmoBrain(구 EmoViS 범위 포함)의 "정서 대 시각-의미 모델 비교"와 겹친다.

## 13. Pilot Experiment

**Horikawa 2020 안에서만 하는 D6a(MC 반응을 열지 않음).** 0절 확인 결과와 관계없이 바로 할 수 있다.
* **절차:**
  * 5-fold 클립 cross-fitting과 피험자 1명 보류 순환(5회)으로 E, V 선택을 만든다.
  * 보류 Horikawa 피험자에서 Δ_obs, Δ_E, Δ_V를 계산한다.
  * 같은 순환으로 Horikawa 내부 관찰 기반 참조값(SESOI의 근거)을 계산한다.
* **계산량:** V-JEPA 2 feature 추출은 GPU 1장으로 수 시간 이내로 추정한다(미확인). 캡션 embedding은 가볍고, ridge와 순열 검정은 CPU로 충분하다.
* **이 Pilot에서 정하는 것:**
  * 영역별 엇갈림 집합 크기
  * 시각 대조 영역에서 V 쪽 결과의 재현
  * SESOI(Horikawa 내부 관찰 기반 참조값의 절반, 하한 0.05 z)
  * q% 값
* **MC 시험 72개로 하는 검출력 시뮬레이션(8.1절):** 클립 정체를 쓰지 않는 신뢰도만 쓴다.
* **의사결정 기준:**
  * 계속: 정서 영역 2개 이상에서 엇갈림 집합이 하한 이상이고, 시각 대조 영역에서 V 쪽 결과가 5회 순환 중 3회 이상 나오며, 검출력 시뮬레이션이 기준을 넘는 정서 영역이 1개 이상이다. 그러면 0절 판에 따라 봉인(8.5절) 후 MC 검증으로 간다.
  * 수정: 집합이 작으면 q%를 키우거나, 클립 단위 대신 RSA 쌍 단위 엇갈림 선택(FA-P2 방식)으로 바꾼다.
  * 중단: 시각 대조가 실패하거나 모든 정서 영역의 검출력이 기준 미달이면 중단하고, RQ-08과 RQ-03의 결과를 먼저 기다린다.

## 반영하지 않은 지적

1. **"선택 풀을 72개 반복 클립으로 줄여 ceiling 대비로 평가"** (adversarial-reviewer EF-P6 응답 수정 2의 함의).
   * 반영하지 않았다. 72개는 엇갈림 선택을 하기에 너무 적다. 또 이 72개는 11회 이상 노출되어 반복과 친숙도 효과가 섞인다(MC Methods). 원 분석도 학습 자료에서 72개가 든 두 run을 뺐다.
   * 대신 72개는 영역 신뢰도와 검출력 계산에만 쓰고, 검증은 1회 노출인 학습 세션 2,108개 반응으로 한다. 같은 응답의 "정서 수준별 ceiling 따로 보고"는 반영했다(8.1절).
   * 결론 범위에 주는 영향: 결과를 반복 기반 ceiling 대비 비율로 말할 수 없고, 원 반응 크기와 신뢰도를 함께 보고하는 데 그친다.
2. **"RQ-10은 R3-internal 후보"** (`rq_landscape.md` 1절 1번).
   * 반영하지 않았다. 검증 반응은 선택 이전에 이미 수집되었고, 선택이 자극 제시를 바꾸지 않았으므로 자극 조작 실험(R3)이 아니다.
   * 이 카드는 evidence-level을 **R0(사전 등록된 전향 예측)** 으로 둔다. 봉인이 깨지면 일반 R0 상관 분석이다.
3. **FA-P2의 "의미는 가깝고 정서는 다른 클립 쌍을 실측 RSA로 판정"을 주 분석으로 쓰는 것.**
   * 반영하지 않았다. 그 설계는 쌍 수준 RSA로 정서 대 의미를 가르는 질문이라 RQ-08과 RQ-13의 범위와 겹친다.
   * 이 카드에서는 Pilot 수정 경로(13절)의 대안 선택 방식으로만 남겼다.

## Safeguards 점검

### CLAUDE.md 6절 구분

| 항목 | 이 카드의 처리 |
|---|---|
| Experienced vs portrayed emotion | 라벨은 별도 평정자가 자기 느낌을 보고한 규범 평정이다. 참가자 경험이 아니다. 결론은 "자극의 규범 정서 속성"으로 한정한다 |
| Human vs model-generated annotation | E는 인간 규범 평정이다. V의 캡션은 [Human 작성, AI 교정]이다. VLM 팔만 AI 추정이며 보조로 따로 표기한다 |
| 본인 보고 vs 규범 평정 | 본인 보고 없음. 규범 평정만 쓴다 |
| Emotion vs visual/semantic representation | 주 산출물 자체가 이 구분이다(E 대 V 엇갈림 판정). 캡션 embedding과 영상 feature를 V에 포함한다 |
| Encoding accuracy vs explanatory adequacy | 전체 예측 정확도가 아니라 두 모델이 엇갈리는 클립에서 관측이 어느 예측에 가까운지로 판정한다. 모델 신뢰도 차이를 보정한다 |
| Decodability vs representation vs causality | 선택 성공은 "정서 평정이 영역 반응을 미리 예측한다"까지다. 영역이 정서를 만든다는 인과 결론은 내지 않는다 |
| In-silico vs observed | TRIBE 팔의 선택은 in-silico, 검증 반응은 관찰이다. 따로 보고한다 |
| Shared representation vs dataset-specific confound | D6a의 같은 코호트 보류 피험자 결과와 MC 결과를 나눠 보고한다. 순서, scanner, 블록 구조, 전처리 차이를 공변량과 해석 단서로 둔다 |
| Exploratory vs confirmatory | 봉인된 사전 등록 분석만 확증으로 본다. 노출이 확인된 경우(판 C)와 그 밖의 분석은 탐색으로 표시한다 |

### 방법론 점검

| 항목 | 처리 |
|---|---|
| HRF 지연, 시간 자기상관 | 두 코호트에 같은 4 s 이동과 블록 평균 규칙을 적용한다(연속 시계열이 없으면 raw 재처리). 직전 블록 유형(평가 블록)과 run 안 위치를 공변량으로 둔다 |
| Stimulus / movie / subject leakage | 클립 5-fold cross-fitting, 내용 중복과 같은 원본 의심 클립은 같은 fold, 학습과 검증 피험자 분리, MC 학습 자료 2,108개 고정(시험 72개 제외), 두 코호트 피험자 비중복(사용자 확인, 원문 미기재) |
| Repeated stimulus confound | 11회 이상 노출된 72개 시험 클립은 선택과 검증에서 제외한다. S1(예비 노출) 제외 판을 보고한다. 반복 재생 횟수는 공변량이다 |
| Inter-rater agreement, label noise | 규범 평정은 비디오당 9~17명 집계라 잡음이 있다. 잡음은 E에 불리하게 작용하므로 Δ_E 축소 보정과 결과 2 해석 조건을 둔다 |
| 시각-의미-정서 공선성 | 엇갈림 집합으로 공선 구간을 피한다. 집합이 너무 작으면 주 분석을 하지 않는다(Pilot 기준) |
| 시공간 해상도 | 블록 수준(8~10 s 이상) 반응만 쓴다. 클립 안 동역학은 다루지 않는다 |
| ROI 선택과 순환 추론 | 표적 영역은 해부학 기준으로 미리 정하고, Horikawa 결과로 고르지 않는다. 선택과 검증 데이터가 분리되어 있다 |
| 다중비교 | 미리 정한 영역에 대해 Holm 보정을 한다 |
| 데이터 접근, checkpoint 라이선스 | 데이터는 사용자 보유. TRIBE v2는 CC BY-NC 4.0. V-JEPA 2 가중치, 문장 embedding, VLM 라이선스는 미확인 |
| 사전학습 오염 | EmoNet 사용 금지. V-JEPA 2와 VLM이 Cowen & Keltner 클립을 학습했는지는 미확인이므로 provenance 등록부에 적는다. TRIBE v2의 fMRI 학습 데이터에 두 코호트는 없다(arXiv:2605.04326 5.7절) |
| 데이터셋 간 주석 비호환 | 두 코호트가 같은 클립과 같은 규범 평정을 쓰므로 해당 없음 |
