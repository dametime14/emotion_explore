## 1. Core Research Question

* **(a) 한 줄 질문:** 떠올린 정서는 원래 장면의 흔적일까, 줄거리를 바탕으로 다시 만든 것일까?
* **(b) 검증 가능한 세부 질문:** Mind captioning 참가자 6명이 정서 단어 없는 단서 문장을 읽고 눈을 감은 채 떠올린 72개 클립의 뇌 패턴을 원 클립 영상, 단서 문장의 회귀 추정, 단서 문장만으로 생성한 영상(Wan) 세 가지 encoding 예측으로 부분상관 분해했을 때, 같은 영상 모형 층에서 정의한 정서 부분공간의 원 클립 고유 몫(지각 양성 대조로 정규화한 일화 고유 지수)은 차원을 맞춘 의미 부분공간의 그것보다 작은가(schema 쪽 치우침), 큰가(NEVER식 보존), 아니면 회복 시뮬레이션으로 미리 정한 판정 불가 구역 안에 드는가?

이 질문은 정서 **경험**이 아니라 회상 패턴에 담긴 **정서 관련 정보**(별도 평정자의 규범 정서 평정과 공변하는 정보)의 형식을 묻는다. 참가자가 회상 중 정서를 다시 느꼈는지는 이 자료로 답할 수 없다(본인 정서 보고 없음).

## 2. Scientific Motivation

* **이미 알려진 것.** 회상은 지각의 복사가 아니다. 영화 회상 패턴은 지각 패턴과 체계적으로 다르게 바뀌고 그 바뀜이 사람 사이에 공유된다(Chen 2017). 기억 반응은 시각피질에서 지각과 다른 공간 튜닝을 보인다(Favila 2022). 심상 때 저수준 시각 영역의 부호가 지각과 다른 것은 상위 표상을 고정한 생성 feedback으로 설명된다(Breedlove 2020). 이론 쪽에서는 Spens & Burgess(2024)가 기억의 예측 가능한 개념 요소는 신피질 생성 모형(schema)으로, 고유한 감각 요소는 해마로 재구성된다고 정식화했다.
* **비어 있는 것.** 무엇이 schema로 다시 만들어지고 무엇이 흔적으로 남는가를 **내용 종류별로** 잰 연구가 없다. 특히 정서가 어느 쪽인지는 정서 이론의 오래된 대립과 바로 이어진다.
  * LeDoux & Brown(2017)의 고차 이론(HOTEC)은 정서 경험을 인지적 schema가 조립하는 고차 표상으로 본다. 이 관점에서는 떠올린 정서도 지식으로 다시 조립된다고 예측하는 것이 자연스럽다.
  * NEVER 모형(Bowen 2018)은 부정 정서가 부호화 때 감각 세부를 더 남기고 인출 때 그 세부를 더 충실히 되살린다고 본다.
  * 최근 자연 영상 회상 연구(Curko 2026)는 정서가가 덜 세부적인(추상적) 사건 표상과 묶이고, 부정 정서가가 지각 세부와 내측두 하위망의 관계를 키우지 않았다고 보고했다. NEVER와 엇갈리는 정황이지만 schema와 흔적을 직접 나누지는 않았다.
* **왜 지금 가능한가.** 공개 텍스트 조건 비디오 생성 모델(Wan, arXiv:2503.20314)은 "단서 문장만 아는 사람이 상상할 법한 영상"을 구체적으로 계산해 준다. 이것을 schema 재구성의 계산 대리로 쓰면, 회상 패턴 중 단서만으로 예측되는 부분과 그 클립을 실제로 본 경험에만 맞는 부분을 측정 수준에서 나눌 수 있다. 같은 일을 단서 문장에서 특징을 회귀로 추정하는 방법(c)으로도 해서 생성기 고유 편향을 견제한다.
* **왜 정서가 시험대인가.** 정서 배제 캡션도 사건을 기술하므로 정서를 함축한다(reviewer_notes 5절 RQ-08 전제 판정 "유지, 해석 한정"). 따라서 schema 쪽 예측도 정서 정보를 일부 운반한다. 질문은 "정서가 있느냐"가 아니라 "정서 정보가 의미 정보보다 더 schema 쪽이냐"이다.

## 3. Origin of the Idea

* **조합 ID:** matrix.csv LIT-47. Axis W(Internally Generated Experience) + L(Generative & Counterfactual Methods) + N(Brain-like Computation) + H(Encoding) + P(Causality & Scientific Inference) + I(AI Model Families). 외부 분야: Memory and Mental Imagery(기억의 생성 모형), Generative AI(텍스트 조건 비디오 생성). 본 에이전트의 외부 분야 Artificial Consciousness and Metacognition에서는 vividness를 메타인지 보고로 다루는 관점과 고차 이론을 가져왔다.
* **두 에이전트의 독립 수렴(Round 4):**
  * **ET-R4-4(emotion-theory):** Spens & Burgess의 생성 기억 모형과 캡션 기반 "의미 gist" 재생성을 붙여 LeDoux & Brown(schema) 대 NEVER(흔적)를 계산 형태로 쓴 제안. 원안은 캡션 embedding 사상(1차)과 text-to-image 재생성(2차), 원 클립 고유 정서 잔차의 회상 decoding, 정서 단어를 허용한 MLLM 캡션을 둘째 gist로 쓰는 대조를 담았다.
  * **FA-R4-1(frontier-ai):** 텍스트 조건 비디오 생성(Wan)의 "상상"을 schema 기준선으로 쓰는 제안. 세 기대 패턴((a) 실제 지각 패턴, (b) 생성 영상 예측, (c) 회귀 schema 예측), 일화 고유 지수 = 유사도(a) - max(유사도(b), 유사도(c)), vividness 서수 혼합모형, 예측 A(schema 우세)와 B(NEVER), "(b)와 (c)가 크게 다르면 해석 보류" 규칙을 담았다.
* **앞선 연결:** ET-P6, VD-P6(회상 정서 재활성), VD-P4(생성기의 정서 중립화 round-trip), adversarial-reviewer의 회상 교란 지적, reviewer_notes 4.4절(회상 절차 원문 확인).
* **이 카드에서 바뀐 것:**
  1. 감사(prior_overlap_audit)의 좁히기를 따랐다. "회상은 재구성인가"는 묻지 않고, 정서 부분공간이 의미 부분공간보다 schema 쪽에 더 가까운가만 묻는다.
  2. 세 예측원을 모두 같은 encoder의 예측으로 맞췄다. FA 원안의 (a) 실제 지각 패턴은 잡음이 있는 관찰값이라 잡음 없는 모형 예측(b, c)과 신뢰도가 달라 비교가 기운다. 실제 지각 패턴은 정규화와 민감도 분석에만 쓴다(아래 "반영하지 않은 지적" 1번에 의견 차이 기록).
  3. Breedlove(2020)를 근거로 정서 부분공간의 비교 상대를 저수준 시각이 아니라 같은 층의 의미 부분공간으로 바꿨다. FA 원안의 예측 A("정서 지수 < 저수준 시각 지수")는 위계 수준 차이만으로도 나올 수 있다.
  4. ET-R4-4의 정서 허용 캡션 대조는 보조 분석으로 남겼다.

## 5. Novelty

* **감사 판정: partially.** 회상 표상이 지각의 복제가 아니라 재구성된다는 핵심은 Chen 2017, Favila 2022가 이미 보였고, Mind captioning 원 논문도 지각 학습 decoder가 회상으로 일반화됨을 보였다.
* **이번 검색에서 추가로 좁혀진 부분:**
  * 지각 학습 encoding model을 회상 fMRI에 적용해 특정 내용의 재활성을 재는 방법은 Lee Masson 2024에 있다.
  * 심상을 생성 네트워크의 feedback으로 설명하는 계산 틀은 Breedlove 2020에 있다. 다만 이론적 계층 생성 네트워크로 튜닝 차이를 예측한 것이고, 생성 모델의 표본을 예측원으로 쓰지 않았다(저자는 AI 생성 표본을 심상과 같다고 보지 않는다고 명시).
  * 정서가와 지각 세부가 회상에서 다른 하위망에 해리된다는 결과는 Curko 2026에 있다. 다만 schema와 흔적을 예측원 수준에서 나누지 않았다.
* **남는 새 부분(감사 문구 그대로):** cue로 생성한 영상의 encoding 예측을 재구성 가설의 계산 대리로 쓰고, 정서 부분공간과 시각 부분공간에서 원 클립 예측과 재구성 예측의 상대 근접성을 비교한다. 이 카드는 비교 상대를 같은 층의 의미 부분공간으로 맞춰 이 부분을 더 좁힌다.
* **새롭다고 주장하지 않는 것:** 회상이 재구성이라는 것, 회상에 정서 정보가 있다는 것(Kim 2025, 상상 유도 정서의 교차 분류 Saarimäki 2016, doi:10.1093/cercor/bhv086), 지각 encoding의 회상 일반화, DMN 하위망 해리.

## 7. Proposed Computational Framework

* **Pretrained model**(공개 모형 먼저. 신경망을 새로 학습하지 않는다)
  * 영상 표상: V-JEPA 2(arXiv:2506.09985). 저장소 LICENSE는 MIT, 일부 파일 Apache 2.0(얕은 복제로 확인, 2026-11-12). checkpoint 가중치 조건은 **미확인**. 주 분석은 후기 층, 민감도 분석은 중간 층과 초기 층.
  * 저수준 시각: motion energy(Du 2023과 같은 Gabor 방식, doi:10.1016/j.isci.2023.107571). Breedlove식 저수준 차이를 재현하는 파이프라인 점검용.
  * 문장 encoder: RQ-08과 같은 묶음(Mind captioning이 쓴 DeBERTa 계열 포함). 라이선스 **미확인**.
  * 생성기: Wan2.1-T2V-1.3B(주. README 기준 8.19 GB VRAM, RTX 4090에서 5 s 480P 약 4분), Wan2.2-TI2V-5B(보조. README 기준 24 GB GPU에서 실행). 둘 다 같은 회사 계열이라 생성기 편향 점검으로는 약하다. 다른 계열 공개 생성기를 하나 더 두는 것이 바람직하나 후보의 식별자와 라이선스는 이번에 확인하지 않았다.
  * 정서 허용 캡션(보조 schema): 공개 VLM이 원 클립을 보고 정서 단어를 허용해 쓴 설명. [AI-est]. 모형은 RQ-17(AI 라벨 대체 가능성 판정) 뒤에 정한다.
  * **쓰지 않는 모형:** EmoNet(같은 C&K 프레임으로 학습, 누수).
* **Input representation**
  * 원 클립과 생성 영상을 같은 해상도와 프레임률로 다시 표본화하고, 실험처럼 10 s 이상이 되도록 반복 재생한 블록 단위로 V-JEPA 2 표상을 평균한다. Wan 출력은 약 5 s라 원 클립 길이와 다르다(긴 클립에서 불일치).
  * 단서 문장: 영어판을 생성기 입력으로 쓴다(Wan의 일본어 처리 성능 **미확인**). 참가자는 영어와 일본어를 함께 봤다.
  * 부분공간 정의(학습 클립 2,108개에서만 학습):
    * E(정서): V-JEPA 2 층 표상에서 규범 정서 34범주를 예측하는 ridge(규제를 건 선형 회귀) 사상의 34차원 출력. 생성 영상에 적용한 E 값은 [AI-est, C&K 좌표]이다.
    * S(의미): 같은 층에서 캡션 embedding(20개 평균)을 예측하는 사상을 34차원으로 줄인 것. 대안 S'는 73개 의미 개념 평정을 예측하는 사상.
    * E⊥S: E에서 S로 설명되는 부분을 뺀 잔차 방향(RQ-08의 기술 잔차 생각을 회상으로 옮김).
    * R(무작위): 같은 층의 무작위 34차원 사영 100개(같은 차원의 matched null).
    * ME(저수준): motion energy 공간.
  * 회귀 schema (c): 학습 클립 캡션의 문장 embedding에서 E, S, R 좌표를 예측하는 ridge(시험 72클립의 캡션은 학습에서 제외). 시험 클립의 단서 문장 하나를 넣어 예측값을 얻는다.
* **Output / target representation**
  * 회상 패턴: 심상 블록의 voxel 반응. 지각 자료와 같은 HRF shift(원 논문 값 확인 필요)를 적용한 뒤 창의 앞과 끝을 잘라 단서 읽기와 재시청 반응을 줄인다(자르기 0, 2, 4 s를 민감도로). 주 분석은 클립별 5회 평균, vividness 분석은 단일 시행.
  * 지각 시험 패턴(5회 평균): 양성 대조와 상한.
  * 모든 패턴은 같은 조건 안에서 클립 사이 평균을 빼(중심화) 눈 감음 같은 공통 성분을 없앤다.
* **Training or adaptation strategy**
  * 모든 pretrained 모형은 고정(특징 추출만).
  * 피험자별로 부분공간마다 따로 encoding model(ridge)을 학습하고, 보조로 banded ridge(부분공간별 규제 강도)를 함께 맞춘다. nested CV(하이퍼파라미터 선택과 평가를 겹치지 않게 나눈 교차검증), fold는 근접 중복 군집과 run 단위로 묶는다.
  * 층과 하이퍼파라미터는 Horikawa 2020에서 미리 고른다(회상 자료를 보지 않고).
  * 생성: 단서당 시드 8개(주), 단서가 아닌 같은 클립 캡션 4개 x 시드 2개(캡션 사이 신뢰도와 단서 특이성 점검), Wan2.2 단서당 시드 4개.
* **Relevant brain regions / networks**(국재화 자료, atlas, 지각 자료로만 정의. 회상 결과로 고르지 않는다)
  * 조기 시각 V1~V3(저수준 위계 대조), 고차 시각(LOC, MT+, 복측 측두), IPS0/1(Breedlove의 고정 위치 후보)
  * DMN 하위망: 배내측(dmPFC 포함), 내측두(해마, 해마곁), core 중심선(Curko 2026의 구분)
  * vmPFC, amygdala: 신호 품질 점검 뒤 탐색적
  * 주 voxel 묶음: 지각 시험 반복 신뢰도와 지각 encoding 정확도로 고른 피질 voxel 전체
* **Loss function or statistical objective**
  * encoding: 부분공간별 ridge 제곱 오차.
  * 클립 i, 부분공간 X에서 회상 패턴을 세 예측 패턴 [a, b, c]에 함께 회귀해 부분상관 r(a|b,c), r(b|a,c), r(c|a,b)를 구한다.
  * 일화 고유 지수 ES_X = r(a|b,c) - max(r(b|a,c), r(c|a,b)). FA-R4-1의 정의를 단순 유사도에서 부분상관으로 바꾼 것이다.
  * 정규화: 같은 계산을 지각 시험 패턴에 적용한 ES_X(지각)을 상한으로 보고, 남은 흔적 비율 = ES_X / ES_X(지각).
  * 주 대비: Δ = 남은 흔적 비율(E) - 남은 흔적 비율(S). R 100개의 분포를 같은 차원 null로 함께 보고한다.
  * 판정 불가 구역: 회복 시뮬레이션에서 "E와 S의 흔적:schema 비율이 같다"를 심은 자료로 얻은 Δ의 95% 구간. 실제 Δ의 신뢰구간이 이 구간과 겹치면 판정하지 않는다. 클립의 절반 이상에서 VIF(분산 팽창 계수)가 10을 넘는 부분공간은 그 자체로 판정 불가로 둔다.
  * vividness: 누적 로짓 혼합모형(순서형 평정용 회귀에 피험자와 클립의 무작위 효과를 더한 모형). vividness ~ ES_E(시행) + ES_S(시행) + 회상 차수 + (1|피험자) + (1|클립).
* **Interpretability method**
  * ROI별 고유 분산 막대(a, b, c의 고유 몫과 공유 몫), product measure(doi:10.1016/j.neuroimage.2022.119728).
  * 클립별 산점도: 생성 정서 충실도(E(b)와 E(a)의 일치) 대 ES_E.
  * 생성 영상 내부 열람(배포하지 않음)으로 실패 생성과 내용 회피를 표시.

## 8. Proposed Analyses

### 0단계 (전제 확인과 관문. 주 대비 Δ는 보지 않는다)

* **0a 자료 대응:** events 파일에서 심상 블록 시각, 단서 문장 ID, 블록 길이, 회상 차수를 확인한다. 원 클립과 캡션의 ID 대응을 RQ-08 0단계와 함께 확인한다.
* **0b 원 결과 재현(V11):** 지각 학습 decoder로 회상 클립을 식별하는 Mind captioning 결과 일부를 같은 자료로 먼저 회복한다.
* **0c 회상 신뢰도:** 5회 회상을 둘로 나눈 두 평균의 일치도(split-half 신뢰도)를 ROI별로 잰다. 0과 구분되지 않는 ROI는 주 분석에서 빼고 기술만 한다(signal-feasibility 관문).
* **0d 생성 영상 감사:** (i) 원 클립과의 E, S 거리(생성 충실도), (ii) 정서 중립화: E(b)의 크기가 E(a)보다 체계적으로 작은지, 범주별로(공포, 성적 욕망, 혐오 등) 따로, (iii) 사전학습 오염 의심: 생성 영상이 자기 원 클립과 다른 클립보다 비정상적으로 가까운 이상치, (iv) 실패 생성(엉뚱한 장면, 빈 화면).
* **0e 공선성 점검:** 클립별 a, b, c 예측 사이 상관과 VIF를 부분공간별로 계산한다(모형 안 계산이라 뇌 자료가 필요 없다).
* **0f 회복 시뮬레이션(V5):** 실측 회상 잡음(5회 회상 사이 잔차와 위상 무작위화 잡음) 위에 알려진 흔적:schema 비율을 심고 ES와 Δ가 되찾아지는지 본다. 여기서 판정 불가 구역과 검정력을 정한다.

### 1단계 (주 분석, 결과 열람 전 고정)

* ES_X를 X ∈ {E, S, E⊥S, R 100개, ME}에서 계산하고 주 대비 Δ(E 대 S)를 본다.
* **양성 대조:** 지각 시험 패턴에서 모든 부분공간의 ES_X(지각) > 0. 실패하면 질문 자체를 이 도구로 검정할 수 없다.
* **null:** (i) 클립 섞기(회상 차수 묶음 안에서 클립 라벨 순열 1,000회), (ii) 단서 섞기(다른 클립의 생성 영상과 회귀 예측을 넣음).
* **신뢰도 맞춤의 두 판:** 단일 표본 판(시드 하나씩, 회귀 schema는 학습 클립 bootstrap 하나씩으로 지수를 구해 평균)과 평균 판(시드 평균, 회귀 평균). 둘의 결론이 다르면 판정 불가로 둔다. 평균한 예측은 원형(prototype)이 되어 잡음 많은 회상과 상관이 높게 나오기 쉬우므로 schema 쪽으로 기울 수 있다.
* **통계:** 피험자마다 클립 bootstrap(클립을 복원 추출해 반복 계산) 95% 신뢰구간. 6명은 모집단 평균 추론에 부족하므로 유병률 추론(doi:10.7554/eLife.62461)으로 "효과가 있는 사람의 비율"을 보고한다. ROI x 부분공간 비교는 FDR(거짓 발견 비율) 보정. 사전 지정 주 검정은 주 voxel 묶음의 Δ 하나다.

### 2단계 (보조, 결론과 분리)

* **NEVER 검정:** 클립별 Δ ~ 규범 부정 정서가 + 규범 각성. 같은 회귀를 ES_S에도 돌려, 정서가 효과가 정서 부분공간에만 있는지(정서 특이) 모든 내용에 있는지(기억성 같은 일반 효과) 가른다.
* **회상 차수 효과(1~5회):** ES가 회차에 따라 바뀌는지. Curko 2026 Discussion 여덟째 단락의 미래 과제(반복 인출에 따른 feature별 변형)와 이어지지만 재시청 누적과 교란되어 있다.
* **vividness:** 위 혼합모형. 재시청 뒤 비교 평정이고 3~4점에 몰려 탐색적으로만 해석한다.
* **정서 허용 캡션 schema (c'):** 정서 언어가 들어간 설명이 정서 부분공간 회상을 더 잘 예측하면 회상 정서가 언어화된 개념 지식을 따른다는 해석과 맞는다(ET-R4-4 대조). [AI-est]
* **저수준 점검:** ME 부분공간에서 ES가 고차 부분공간보다 낮게 나오는지(Breedlove 재현). 나오지 않으면 파이프라인 민감도를 의심한다.
* **FA 원안 판:** (a)를 실제 지각 시험 패턴으로 바꾼 판을 민감도로 보고한다.
* **ablation:** (b) 제거, (c) 제거, Wan2.2로 교체, 창 자르기 0/2/4 s, 층(초기, 중간, 후기), 부분공간 차원(16, 34, 64), S2 제외(준비 구간 해독이 우연 이상이었던 피험자).

### 반증 조건 (Falsifiability)

| 결과 | 해석 |
|---|---|
| F1: 지각 양성 대조에서 E 또는 S의 ES(지각)가 0과 구분되지 않음 | 도구가 부분공간을 구분하지 못한다. 이 자료로 질문 검정 불가 |
| F2: 모든 부분공간의 ES가 클립 섞기 null과 구분되지 않고 r(b|a,c), r(c|a,b)도 null 수준 | 이 SNR에서 회상의 클립 고유 정보가 보이지 않는다. 일화 성분 주장을 철회하되 schema 지지로도 읽지 않는다 |
| F3: Δ의 신뢰구간이 판정 불가 구역과 겹침 | 결론 보류. 공선성을 깨는 새 실험(R3) 제안 |
| F4: (b)와 (c)가 부분공간별 schema 기여 순위에서 엇갈리고 그 차이가 시드 변동보다 큼 | schema 기준선이 불안정하다(FA 규칙). 해석 보류 |
| 예측 A(schema 치우침) 불지지 | Δ > 0이 판정 불가 구역 밖에 있고 6명 중 5명 이상에서 같은 방향 |
| 예측 B(NEVER) 불지지 | 부정 정서가와 ES_E 기울기의 신뢰구간이 0을 포함하거나 음수, 또는 같은 기울기가 ES_S에도 같은 크기로 있음(정서 특이가 아님) |

설계가 흔적 쪽으로 기운다는 점(사전 연습, 매 회상 뒤 재시청, 최대 11회 이상 노출)을 미리 적어 둔다. 그래서 "흔적 우세" 결과는 약한 증거이고, 이 조건에서도 "정서가 schema 쪽"으로 나오면 강한 증거다.

## 9. Competing Explanations

| 대안 설명 | 어느 쪽으로 기울이나 | 가르는 분석 |
|---|---|---|
| 1. 단서 읽기 반응이 HRF 지연으로 심상 구간 앞부분에 섞임 | schema 쪽(b, c와 문장 내용 공유) | 창 앞부분 자르기 민감도, 준비 블록을 따로 모형화(FIR: 사건 뒤 시점별 반응을 따로 추정하는 회귀), 준비 구간 패턴에 같은 분석을 돌려 (c) 쪽으로 기우는지 확인(이 구간은 schema 쪽이 정상), S2 제외 |
| 2. 재시청 반응이 창 끝에 섞임 | 흔적 쪽(원 영상) | 창 끝부분 자르기, 재시청 블록을 따로 모형화 |
| 3. 눈 감음으로 인한 기저 이동 | 모든 클립에 공통 | 조건 안 클립 간 중심화. 긴 클립은 심상 블록도 길어 블록 길이를 nuisance로 넣음 |
| 4. 예측원마다 신뢰도가 다름(조정자 지적) | 평균된 예측(시드 평균, 회귀 조건부 평균)이 원형이라 schema 쪽 | 단일 표본 판과 평균 판, 지각 양성 대조로 정규화, 회복 시뮬레이션, 세 예측원 모두 같은 encoder 예측으로 통일 |
| 5. 단서 = 캡션이라 세 예측이 공선적(reviewer) | 분해 불안정 | 부분상관, VIF 관문, 사전 판정 불가 구역, 비단서 캡션 생성으로 단서 특이성 점검 |
| 6. 생성기의 정서 중립화와 내용 회피(VD-P4) | (b)의 정서 성분이 약해 정서가 흔적처럼 보임 | 0d 감사, 생성 충실도로 층화, 중립화가 심한 클립 제외 민감도, 생성이 없는 (c)와의 일치 요구 |
| 7. 위계 수준 차이(Breedlove의 고정) | 저수준은 원래 원 클립에서 멀어 상대적으로 정서가 흔적처럼 보임 | E와 S를 같은 층에서 같은 차원으로 정의, ME는 대조로만 |
| 8. 정서 정보가 곧 의미 내용 | E와 S가 같은 정보를 재서 Δ가 0 근처 | E와 S의 겹침 측정, E⊥S 잔차 부분공간으로 반복 |
| 9. 반복 노출과 사전 연습 | 흔적 쪽 | 회상 차수 효과, 결론 범위를 "익힌 클립의 단서 심상"으로 한정 |
| 10. 사전학습 오염(Wan, V-JEPA 2가 같은 인터넷 영상을 학습) | (b)가 (a)를 복제해 공선성 증가 | 0d 이상치 점검, 이상치 클립 제외 민감도. 학습 목록이 공개되지 않아 직접 확인 불가 |
| 11. 기억성(memorability)이 정서가와 공변 | 부정 클립에서 모든 내용이 흔적 쪽 | NEVER 검정에서 ES_S를 대조로 |
| 12. 참가자가 회상 중 정서를 실제로 다시 느낌(재경험) 대 정서 정보의 재표상 | 구분 불가 | 본인 정서 보고와 생리 신호가 없어 **관찰 자료로 구분할 수 없다**. 해석을 정보 수준으로 한정 |
| 13. 지각 encoding의 weak vision 가정이 틀림(회상 부호가 지각과 다름, Favila 2022, Breedlove 2020) | 세 예측 모두 틀리고 부분공간마다 다르게 틀릴 수 있음 | 상대 비교와 지각 정규화로 부분 완화. 심상 전용 encoder는 자료 부족으로 미반영 |

## 10. Potential Findings

| 결과 | 과학적 의미 |
|---|---|
| A: Δ < 0, 판정 불가 구역 밖(정서가 의미보다 schema 쪽) | 떠올린 정서 정보는 단서가 주는 일반 지식으로 대부분 예측된다. LeDoux & Brown의 schema 조립, Spens & Burgess의 "예측 가능한 요소" 범주에 정서가 든다는 해석, Curko 2026과 맞는다. 흔적에 유리한 설계에서 나온 결과라 강한 증거 |
| B: Δ > 0, 그리고 부정 정서가에서 더 크며 ES_S에는 그런 기울기가 없음 | 정서 정보가 의미 내용보다 클립 고유 흔적으로 더 남는다. NEVER와 맞는다. 다만 재시청과 연습이 흔적을 키웠을 수 있어 일반 일화기억으로 넓히려면 지연 회상 실험이 필요 |
| C: 두 부분공간 모두 ES > null이지만 Δ가 0 근처(판정 가능 범위 안에서 동등) | 정서는 기억 형식에서 특별하지 않고 사건 의미와 같은 비율로 흔적과 schema를 섞는다. RQ-08이 "기술을 넘는 정서 신호 없음"으로 나오는 경우와 일관 |
| D: 판정 불가 | 공선성이나 SNR 한계. 공선성을 깨는 새 실험(R3)을 제안: 내용과 무관한 중립 단서(Curko 2026처럼 단어 단서나 임의 번호), 정서 함축을 통제한 단서, 하루 이상 지연 회상 |
| E: (b)와 (c)가 엇갈림 | 텍스트 조건 비디오 생성 prior가 텍스트 회귀 prior와 다르다. 생성 영상은 schema의 대리로 쓰기 어렵다는 AI 쪽 결과(Shirakawa 2025의 경고와 같은 방향) |
| F: 모든 지수가 null | 회상 패턴의 부분공간 분해가 3T, 6명 SNR로는 불가능. 신호 관문(0c)에서 미리 걸러질 가능성이 큼 |

## 11. Scientific Contribution

* **정서 이론:** 고차 이론(LeDoux & Brown 2017)과 NEVER(Bowen 2018)는 떠올린 정서의 형식에 대해 반대 방향을 예측하지만, 둘을 같은 자료, 같은 지표로 맞댄 측정이 없었다. 이 질문은 두 예측을 Δ와 정서가 기울기라는 두 수치로 바꾼다. 결과가 어느 쪽이든 "정서는 기억에서 의미 내용과 다른 형식으로 저장되는가"에 직접 답한다.
* **기억 이론:** Spens & Burgess의 "예측 가능한 요소 대 고유 요소" 구분을 정서라는 내용 종류에 처음 적용한다. Curko 2026의 네트워크 수준 해리(정서가 대 지각 세부)를 예측원 수준 분해로 보완한다.
* **방법:** "단서만으로 만든 생성 기준선"은 정서 외의 모든 회상, 심상 재활성 연구에 재사용할 수 있는 대조다. 회상 패턴 중 세계 모형이 단서에서 예측할 수 있는 부분과 일화 고유 부분을 나눈다.
* **측정(Axis Q):** 신뢰도가 다른 예측원을 비교할 때 단일 표본 판과 평균 판, 양성 대조 정규화, 사전 판정 불가 구역을 쓰는 절차를 보인다. 모형 예측원끼리 비교하는 다른 질문에 그대로 옮길 수 있다.
* **한정:** 증거 수준은 R0(관찰 상관)에 R1(모형 안 계산) 요소가 더해진 것이다. 생성 영상 예측이 회상과 가깝다는 결과는 "뇌가 생성 모델처럼 재구성한다"는 인과 증거가 아니다. 정서 정보의 형식에 관한 것이지 정서 경험에 관한 것이 아니다.
* **RQ-08과의 관계:** RQ-08은 지각에서 기술을 넘는 정서 신호가 있는지 묻고, RQ-44는 같은 캡션으로 회상 쪽에서 정서 정보가 기술(schema)을 넘는지 묻는다. 두 결과를 함께 보면 정서 정보가 지각과 회상에서 같은 형식인지 알 수 있다.

## 12. Limitations & Risks

* **자료:**
  * 회상 자료가 Mind captioning 6명 하나뿐이다. 다른 코호트 재현(S2)이 불가능하다.
  * 단서가 캡션 자체라 공선성이 설계에 박혀 있다.
  * 사전 연습, 매 회상 뒤 재시청, 최대 11회 이상 노출 때문에 "오래된 일화기억"이 아니라 "익힌 클립의 단서 심상"에 가깝다.
  * vividness는 재시청 뒤 비교 평정이고 3~4점에 몰린다.
  * 본인 정서 보고, 생리 신호, 시선 추적이 없다.
  * 참가자(일본어 모국어)와 규범 평정자(미국 영어 사용자)의 언어, 문화가 다르다.
  * 학습 순서가 6명 모두 같아 순서 관련 표류가 피험자 사이에 공유된다.
* **모형:**
  * 생성기의 정서 중립화, 내용 회피, 학습 자료 오염은 직접 확인할 수 없고 간접 점검만 한다.
  * Wan 출력은 약 5 s라 긴 클립과 길이가 맞지 않는다. 일본어 단서 처리 성능은 미확인이라 영어판만 넣는다.
  * 생성 모델 표본은 사람의 심상이 아니다(Breedlove 2020 저자 명시). "schema 대리"는 생성 prior의 대리일 뿐이다.
  * 생성 영상의 정서 좌표는 V-JEPA 2에서 규범 평정으로 사상한 AI 추정이다. 사람이 생성 영상을 평정한 자료가 없어 V9 alt-test(AI 라벨이 사람 평정을 대신할 수 있는지 보는 검정)를 못 했다.
* **통계:**
  * 회상 SNR이 낮아 부분상관이 불안정할 수 있다. 판정 불가 구역이 넓게 나올 수 있다(reviewer 지적).
  * 6명이라 모집단 평균 추론은 하지 않고 유병률만 말한다.
  * 2단계 분석은 많고 탐색적이다.
* **이론적 해석:** E 부분공간은 "영상에서 시각적으로 추론 가능한 규범 정서"의 방향이다. 내부 정서 상태의 방향이 아니다. Δ가 0 근처면 정서와 의미가 같은 형식이라는 뜻일 수도, E와 S가 같은 정보를 잰다는 뜻일 수도 있어 E⊥S 결과와 함께 읽어야 한다.
* **계산 자원(가정):** GPU 종류와 수량은 **미확인**이다. GPU 1~4장을 가정한다.
  * 생성 1,440개: Wan2.1 1,152개 x 약 4분 = 약 77 GPU시간(README의 RTX 4090 기준). Wan2.2 288개는 실행 시간이 README에 없어 개당 10분으로 가정하면 약 48 GPU시간.
  * 합계 약 125 GPU시간이다. 4장이면 약 1.3일, 1장이면 약 5일이 걸린다.
  * 특징 추출과 ridge 학습은 그에 비해 작다.
* **라이선스와 윤리:**
  * Wan2.1, Wan2.2는 Apache 2.0이다(README에 이용 제한 문구 있음). V-JEPA 2 코드는 MIT다. 두 모형 모두 가중치 배포 페이지 조건은 미확인이다.
  * 원 클립 프레임은 재배포하지 않는다.
  * 폭력, 성적 내용 클립의 단서로 생성한 영상은 내부 분석에만 쓴다.

## 13. Pilot Experiment

* **기반:** Pilot P1(RQ-08)이 만드는 캡션 encoding, V-JEPA 2 특징, Mind captioning 지각 encoding model을 그대로 쓴다. 추가 비용은 생성과 관문 점검뿐이다.
* **최소 판:** 6명 모두(encoding은 가벼움), 72개 단서 x Wan2.1-1.3B 시드 2개 = 144개 생성(약 10 GPU시간).
* **수행 단계:** 0a, 0c, 0d, 0e, 0f만 수행하고 **주 대비 Δ는 보지 않는다**(사전 등록 보존).
* **진행 기준(모두 충족해야 본 분석):**
  1. 회상 split-half 신뢰도가 적어도 한 ROI 묶음에서 6명 중 4명 이상 0보다 크다.
  2. E와 S 부분공간에서 클립 중앙값 VIF가 10 미만이다.
  3. 회복 시뮬레이션에서 흔적 비율 차이 0.2를 80% 이상 검정력으로 구분한다. 0.2는 사전 지정값이며, 이 값의 근거가 되는 선행 효과 크기는 없다.
  4. 생성 정서 충실도(E(b)와 E(a)의 일치)가 클립 섞기 null보다 크다. 충족하지 못하면 (b)를 빼고 (c)만으로 진행하며, 그 경우 감사가 인정한 새 부분(생성 영상 예측)이 사라짐을 명시한다.
* **중단 기준:** 1번이나 3번이 실패하면 이 자료로는 본 분석을 하지 않고 R3 새 실험 설계(10절 D)로 넘긴다.

## Safeguards 점검

| 항목 | 이 질문에서의 처리 |
|---|---|
| 참가자 경험 vs 자극에 묘사된 정서 | 목표는 별도 평정자의 felt 규범 평정이 정의한 방향. 참가자 경험도 묘사 정서도 아니다 |
| 정서 인식 질문 vs 정서 경험 질문 | 이 질문은 회상 패턴에 담긴 클립의 정서 관련 정보를 다룬다(인식 쪽에 가까움). 회상 중 정서 재경험은 본인 보고가 없어 다루지 않는다(9절 12번) |
| 인간 평정 vs 모델 생성 평정 | 원 클립의 정서 좌표는 인간 규범 평정으로 학습한 사상, 생성 영상에 적용한 정서 좌표와 정서 허용 캡션은 [AI-est]로 분리 표기 |
| 본인 보고 vs 규범 평정 | 정서는 규범 평정만. vividness와 정확도는 본인 보고지만 대상이 심상의 질이다 |
| 정서 표상 vs 시각, 의미 내용 표상 | 이 질문의 핵심 대비. 같은 층, 같은 차원의 E 대 S, E⊥S, 무작위 R |
| encoding 정확도 vs 설명적 적절성 | 생성 예측이 회상과 가까워도 "재구성의 계산 대리와 공변"까지만 말한다 |
| decodability vs 표상 vs 인과 | R0 관찰 분석. 인과 주장 없음 |
| in-silico vs 관찰 | 세 예측원은 in-silico, 회상과 지각 패턴은 관찰. 예측 패턴을 뇌 자료로 취급하지 않는다 |
| 공유 표상 vs 데이터셋 특이 교란 | 한 자료, 같은 학습 순서, 일본어 화자, 반복 노출. 결론 범위를 "익힌 클립의 단서 심상"으로 한정 |
| 탐색 vs 확인 | 주 대비 Δ 하나만 사전 지정 확인 검정. 2단계는 탐색 |
| HRF 지연과 시간 자기상관 | 단서 읽기와 재시청 혼입을 창 자르기와 블록별 모형화로 다룸. fold는 run 단위 |
| 자극, 영상, 피험자 단위 누수 | 시험 72클립은 encoder 학습(마지막 2개 학습 run 제외)과 회귀 schema 학습(시험 클립 캡션 제외)에서 완전히 뺌. 근접 중복 군집 fold |
| 반복 자극 교란 | 11회 이상 노출과 연습. 회상 차수 효과 분석, 해석 한정 |
| 평정자 일치와 라벨 잡음 | 규범 평정의 범주별 일치도 미확인. 캡션 사이 신뢰도는 비단서 캡션 생성으로 점검 |
| 시각-의미-정서 공선성 | 세 예측원 공선성(VIF 관문), E와 S 공선성(E⊥S) |
| 시공간 해상도 | TR 1 s, 2 mm. 블록 단위 분석. 해마, vmPFC, amygdala는 신호 점검 후 탐색 |
| ROI 선택과 순환 추론 | ROI와 voxel은 국재화, atlas, 지각 자료로만 정의. 층과 하이퍼파라미터는 Horikawa 2020에서 선택 |
| 다중 비교 | 주 검정 1개 사전 지정, 나머지 ROI x 부분공간 FDR, 피험자 유병률 |
| 자료 접근, checkpoint 라이선스 | 자료 보유(사용자 확인). Wan Apache 2.0, V-JEPA 2 코드 MIT(저장소 확인). 가중치 페이지 조건과 문장 encoder 라이선스 미확인 |
| 사전학습 오염 | EmoNet 제외. Wan, V-JEPA 2의 C&K 영상 학습 가능성은 0d 이상치 점검으로 간접 확인 |
| 데이터셋 간 주석 비호환 | 주 분석은 한 자료. Horikawa는 층 선택에만 쓰고 라벨을 합치지 않음 |
| **label-provenance** | 정서 방향: 대상 felt, 주체 별도 평정자 규범(C&K, [Human-norm, felt]). 단서와 캡션: 별도 작업자의 시각 내용 기술(정서 배제 지시), 정서 라벨이 아님. 생성 영상의 정서 좌표와 정서 허용 캡션: [AI-est]. vividness: 본인 보고(심상의 질). 생성 영상 자체는 라벨이 아니라 자극 기술자 |
| **evidence-level** | 정서에 관한 결론은 R0. 생성 영상 예측은 R1(모형 안 계산). 지각 대 회상은 자료 안 과제 차이일 뿐 정서 조작이 아니라 수준을 올리지 않는다 |
| **insilico-vs-observed** | 혼합. 예측원은 in-silico, 대상 패턴은 관찰 |
| **G1** | 필요(원 클립 특징 추출과 encoder 학습). 보유(2,185클립, 무음). 생성 영상만 쓰는 부분은 불필요 |
| **signal-feasibility** | 3T, TR 1 s, 2 mm, MB 6, TE 30 ms, 생리 신호 없음. 원 논문은 단일 시행 회상에서도 의미 기술 생성이 가능했다고 보고(Discussion 12째 단락). 정서 부분공간의 회상 신뢰도는 미확인이라 0c 관문으로 판단. vmPFC 신호 소실 위험 |
| **minimum-validation (V1~V12)** | V1 경쟁 설명과 같은 차원 null(R 100개, 단서 섞기, 클립 섞기) ○. V2 원 값과 상한 병기(지각 5회 상한, 회상 split-half) ○. V3 의존 구조 보존 null(회상 차수 묶음 안 순열) ○. V4 예측원 신뢰도 민감도(두 판, 정규화) ○. V5 회복 시뮬레이션 ○. V6 시드, 생성기, bootstrap 안정성 ○. V7 누수 경로별 대응(시험 클립 제외, EmoNet 제외, 오염 점검, 분석자 노출: Mind captioning 회상 자료는 원 논문과 EmoMind가 이미 분석했으므로 결과 열람 전 사전 등록) ○. V8 일반화 수준 명시(유병률, 클립 bootstrap, 다른 코호트 없음) △. V9 AI 라벨 타당화(생성 영상 정서 좌표의 인간 대조 없음, 소규모 인간 평정 R2를 추가하면 충족) △. V10 결과 열람 전 고정 ○(계획). V11 원 결과 재현(0b) ○. V12 반증 해석 사전 기술(8절 표, 10절) ○ |
