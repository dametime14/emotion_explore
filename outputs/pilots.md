## 0. 세 Pilot의 공통 기반과 실행 순서

* **같은 데이터:** 세 Pilot 모두 Horikawa 2020과 Mind captioning(MC)을 쓴다.
  * Horikawa 2020: 공개 전처리본 figshare doi:10.6084/m9.figshare.11988351, raw OpenNeuro ds002425.
  * Mind captioning: 사용자 전처리본, raw OpenNeuro ds005191.
  * 두 데이터는 같은 C&K 클립 2,180개를 썼고, 클립은 모두 무음이다(사용자 확인).
* **공통 0단계(한 번만):**
  1. 두 코호트의 클립 ID 대응표를 만든다.
  2. MC 사용자 전처리의 세부를 확인한다. 공간, 시계열인지 블록 평균인지, 전역 신호 회귀 여부를 본다.
  3. 원본 영상 단위 근접 중복을 묶는다(지각 해시). 같은 원본에서 잘린 클립을 같은 fold에 넣어 누수를 막는다.
  4. 사전 등록 문서를 고정한다.
* **권장 순서:** P2의 V11 재현 → P1 → P3. 실제로는 병렬로 돌릴 수 있다.
  * P2의 재현 단계(Westlin 원 수치)는 CPU 몇 시간이면 되고, 데이터 처리 파이프라인을 검증하는 역할을 한다.
  * P1은 P2와 같은 전처리본을 쓴다.
  * P3는 모델 특징 추출이 대부분이라 P1, P2와 독립적이다.
* **분석자 노출 주의(RQ-10 카드에서 제기):**
  * 나중에 RQ-10(정서 모델이 고른 영상의 전향 검증)을 할 계획이면, 그 선택 목록을 Horikawa 자료만으로 먼저 만들어 봉인해야 한다. 봉인은 해시와 시점 기록으로 한다.
  * 봉인은 P1, P2가 MC 뇌 반응을 보기 전에 해야 한다. 아니면 선택 담당 분석자를 따로 둔다.
  * 봉인 자체는 Horikawa encoder 학습뿐이라 비용이 작다.

## P1. 장면을 말로 설명한 내용을 빼고 나도 뇌에 정서 신호가 남을까? (RQ-08 + RQ-13 관문)

| 항목 | 내용 |
|---|---|
| 목적 | Horikawa 2020의 "정서 범주 모형이 transmodal 영역을 가장 잘 설명한다"는 결론이 장면 기술 의미로 환원되는지를 보기 전에, 원 결과를 재현하고 측정 도구(캡션)의 신뢰도를 확인한다 |
| 첫 분석에 필요한 데이터와 파일 | (1) Horikawa figshare 전처리본(피험자 5명, 블록 수준 반응, native volume)과 features(34범주, 14차원 규범 평정, 73개 의미 항목, 시각 객체). (2) MC 정서 배제 인간 캡션 20개/클립(사용자 보유). (3) 원본 클립(motion energy 계산용, 사용자 보유). (4) 클립 ID 대응표. (5) RQ-13용 시각, 의미 embedding |
| Pretrained model, checkpoint, 라이선스 | 문장 encoder 3종 이상(DeBERTa-large, 문장 embedding 전용 모형 1개, 공개 LLM 1개의 중간층). 영상 encoder 1개. 모두 공개 checkpoint이고 **가중치 라이선스는 미확인**(Hugging Face 접속이 이 세션에서 막힘). motion energy는 모델이 아니라 Gabor 필터 계산. **EmoNet은 쓰지 않는다**(같은 C&K 프레임으로 학습되어 누수) |
| Evaluation metric | 영역별, voxel별 held-out 예측 정확도(교차검증 R²). banded ridge의 band별 고유 설명량(정서 band가 다른 band를 넣은 뒤 더하는 예측력). RQ-13은 정서 범주 쌍별 매칭률 |
| Noise ceiling | Horikawa는 반복 제시가 없어 피험자 간 예측력으로 대리한다. MC로 확장할 때는 테스트 72개 클립의 반복 제시로 계산한다 |
| Baseline | (a) **V11 재현 목표.** Horikawa 2020(정서 대 시각 대 의미 모형 비교)과 Du 2023(doi:10.1016/j.isci.2023.107571. 같은 자료에 정서, motion energy, 73개 의미 평정을 banded ridge로 넣어 평균 21% 피질 voxel 유의, TPJ 43~62%). (b) 73개 의미 항목 band. (c) 차원을 맞춘 무작위 feature null. (d) 양성 대조: 저수준 시각 feature의 고유 분산이 같은 절차로 검출되는지 |
| 예상 계산량 | 캡션 embedding 2,180 x 20문장은 GPU 1장으로 수 시간 이내(추정). banded ridge는 피험자당 수 시간(CPU 또는 GPU 1장, 추정). RQ-13 OT 매칭은 CPU 수 시간 |
| 예상 위험 | (1) 캡션 세트의 split-half 신뢰도가 낮으면 보정이 불안정하다. (2) 34차원 평정 대 고차원 embedding의 band 차원 비대칭. (3) MC 평가 블록에서 캡션이 제시된 클립에 읽기 반응이 섞일 수 있다. (4) 두 코호트 모두 자유 시청이라 시선 교란. (5) 정서와 내용이 거의 겹치는 정서 쌍이 많을 수 있다(RQ-13 결과) |
| 의사결정 기준 | **계속:** V11에서 Horikawa 2020과 Du 2023의 핵심 비교 순서가 재현되고, 양성 대조가 통과하고, 캡션 split-half 신뢰도가 사전 지정 기준(예: Spearman-Brown 보정 0.7)을 넘으면 MC로 확장한다. **수정:** 캡션 band로 바꿔도 결과가 73개 의미 band와 같으면 캡션의 정서 누출 감사부터 다시 본다. 재현이 실패하면 전처리와 feature 정의 차이를 먼저 찾는다. **중단 또는 결론 전환:** 측정 오차를 보정한 뒤 정서 고유 분산이 사전 지정 ROI 전부에서 null과 구분되지 않으면, "규범 정서 평정의 뇌 설명력은 언어 기술로 회복된다"를 결과로 보고한다(음성 결과도 결론이다). RQ-13에서 매칭률이 낮은 정서 쌍은 "이 데이터로 식별 불가"로 표시하고 그 쌍의 대비는 주장하지 않는다 |
| 실행 전 확인 | 문장 encoder와 영상 encoder 가중치 라이선스. MC 캡션 파일과 클립 ID 대응. GPU 종류 |

## P2. 뇌의 정서 '범주' 구조는 다른 사람, 다른 그룹에서도 다시 나타날까? (RQ-01, RQ-03 확장)

| 항목 | 내용 |
|---|---|
| 목적 | Horikawa 2020(범주가 가장 잘 설명)과 Westlin 2025(라벨 없이 찾은 군집은 사람마다 11~14개, 범주보다 스캔 세션과 맞음)가 갈린 지점을 두 독립 코호트에서 다시 본다. 먼저 원 수치를 재현하고 판정 가능성을 시뮬레이션으로 확인한다 |
| 첫 분석에 필요한 데이터와 파일 | (1) Horikawa figshare 전처리본과 세션 정보. (2) MC 사용자 전처리본과 세션 정보. (3) 34범주 규범 평정. 첫 세 분석은 raw 재전처리 없이 가능하다. 본 분석은 두 코호트 raw를 같은 파이프라인으로 재전처리한다(Horikawa 5명 x 약 61 run, MC 6명 x 약 60 run) |
| Pretrained model, checkpoint, 라이선스 | 핵심 분석에는 모델이 없다. 시선 추정 DeepMReye(doi:10.1038/s41593-021-00947-w, 코드 LGPLv3, pretrained 가중치 라이선스 미확인, 촬영 범위에 눈알이 들어 있는지 미확인). 시각 교란 feature는 C&K 정서 라벨로 학습하지 않은 이미지 모델(CLIP 계열, DINOv2, 가중치 라이선스 미확인). 분석 도구 fMRIPrep(Apache-2.0), nilearn(BSD-3), brainiak SRM(Apache-2.0) |
| Evaluation metric | (1) Westlin 재현: 사람별 최적 군집 수, 범주와 세션에 대한 NMI. (2) 코호트 간 피험자 쌍(30쌍)의 공유 성분 중 null을 넘어 재현되는 범위(신뢰 rank 대역). (3) 그 범위 안에서 범주 혼합, 연속 잠재, 개인 특이 군집 모형의 held-out 우도. (4) AMI는 보조 지표 |
| Noise ceiling | MC 테스트 72개 클립 x 5회 반복으로 피험자별 신뢰도를 계산한다. Horikawa는 반복이 없어 MC 기반 보정을 쓰되, 획득 조건(TR 2 s 대 1 s)이 달라 그대로 옮기지 않는다는 점을 표시한다 |
| Baseline | **V11 재현 목표:** Horikawa 2020(범주 > 차원), Du 2023, Westlin 2025(군집 11~14, 범주 NMI 0.014, 세션 NMI 0.19). 위상 무작위화와 자극 셔플 쌍 null. 34범주 비율 평정을 이산 라벨로 바꿀 때의 AMI 합성 상한(범주 생성, 연속 생성 두 경우) |
| 예상 계산량 | 첫 세 분석(Westlin 재현, 시간 대 내용 판별, AMI 상한)은 CPU 몇 시간. 본 분석 재전처리는 CPU 수일 규모(추정). DeepMReye와 feature 추출은 GPU 1장 |
| 예상 위험 | (1) MC 학습 세션 2,180개 클립의 순서가 6명 모두 같아, 코호트 간 쌍만 순서가 독립이다. (2) 피험자 쌍이 서로 독립이 아니다(각 피험자가 여러 쌍에 들어간다). (3) 두 코호트의 획득 조건과 전처리가 다르다(MC는 전역 신호 12개 회귀). (4) 자유 시청 시선이 공유 분산과 개인 분산 양쪽에 섞인다. (5) 5~6명 규모라 개인차 질문은 제한된다 |
| 의사결정 기준 | **계속:** Westlin 수치가 재현되면 본 분석으로 간다. MC 군집이 MC 세션과 맞으면 세션과 전역 성분 처리를 필수 요인으로 고정한다. Horikawa 세션 번호와 맞으면 클립 묶음의 내용 효과를 주 해석 후보로 올린다. **수정:** 범주 생성과 연속 생성의 AMI 분포가 겹치면 AMI를 주 지표에서 내리고 held-out 우도만 쓴다. **중단(결론 전환):** 회복 시뮬레이션에서 세 생성 모형을 구분할 수 없으면 본 비교를 하지 않고 "이 자료의 신호 대 잡음비로는 판정 불가, 필요한 SNR은 얼마"로 보고한다. 코호트 간 신뢰 성분이 null을 넘지 못하면 정서 구조는 이 해상도에서 식별할 수 없다고 보고한다 |
| RQ-03 확장 | 신뢰 성분이 확보되면 같은 파이프라인에서 시각 다양성과 정서 다양성을 따로 줄인 부분집합(2x2)을 만든다. 공유 성분 스펙트럼의 기울기가 어느 쪽 조작에 반응하는지 본다. 부분집합 크기에 따른 추정 편향은 시뮬레이션으로 보정한다. RQ-13 positivity 지도로 독립 조작이 가능한 범위를 먼저 확인한다 |
| 실행 전 확인 | MC 사용자 전처리 세부. 두 코호트 클립 대응표. 촬영 범위에 눈알이 포함되는지. 재전처리 계산 자원 |

## P3. AI의 정서를 잴 때, AI 속을 들여다보는 것과 AI에게 물어보는 것 중 무엇이 사람 뇌와 더 닮았을까? (RQ-15)

| 항목 | 내용 |
|---|---|
| 목적 | 같은 공개 VLM이 같은 클립을 한 번 처리할 때 두 값을 함께 얻는다. 하나는 답하기 직전의 내부 상태를 정서 방향에 투영한 값이고, 다른 하나는 모델이 내놓는 정서 평정이다. 두 측정이 실제로 다른지, 그 차이가 사람 뇌의 정서 관련 반응과 관계있는지 본다 |
| 첫 분석에 필요한 데이터와 파일 | (1) C&K 클립 2,180개(무음, 사용자 보유). (2) MC 지각 반응(테스트 72개 클립 x 5회 평균, 학습 2,180개). (3) Horikawa 블록 반응(재현). (4) 정서 방향 추출용 C&K와 독립인 텍스트 자료(34범주 이야기). 점검용 EmoSet 이미지(arXiv:2307.07961, 겹치는 범주만) |
| Pretrained model, checkpoint, 라이선스 | 주 모델 Qwen3-VL-8B(arXiv:2511.21631). 재현 모델 InternVL3.5-8B(arXiv:2508.18265). 대안 Qwen2.5-VL-7B(arXiv:2502.13923). 코드 라이선스는 Qwen 계열 Apache-2.0, InternVL MIT로 LICENSE 파일에서 확인되었다. **가중치 라이선스는 미확인**(모델 카드 접근 실패). 시각 통제용 V-JEPA 2(arXiv:2506.09985)는 가중치 라이선스 기술이 출처마다 엇갈린다(저장소 MIT 대 CC-BY-NC 4.0) |
| Evaluation metric | HCP360 parcel별 encoding에서 내부 투영 34차원과 출력 평정 34차원 각각의 고유 설명량. 같은 모델 null(무작위 방향, 비정서 개념 방향, 비정서 질문 출력)과의 차이. 두 특징의 상관(측정이 실제로 다른지) |
| Noise ceiling | MC 테스트 72개 클립 x 5회 반복으로 피험자별 상한을 구한다 |
| Baseline | 시각 전용 feature(V-JEPA 2 또는 CLIP image encoder). 정서 배제 인간 캡션 embedding(P1과 공유). C&K 규범 평정. 같은 모델의 비정서 내용 질문 출력 |
| 예상 계산량 | 오염 탐침(무작위 100클립)은 약 1일. 특징 추출은 2,180클립 x 프롬프트 1판 x 출력 표집 3회 x 중간층 3개. 카드 추정으로 pilot은 약 15~25 GPU 시간, 전체 설계는 약 150~200 GPU 시간(GPU 1~4장 가정, 실측 아님) |
| 예상 위험 | (1) **사전학습 오염.** C&K 클립과 범주 라벨이 공개 웹 지도에 있어 모델이 평정을 기억했을 수 있다. 오염 점검(기억 탐침, 변형 안정성, 라벨 없는 자극 비교, Min-K%)을 먼저 한다. (2) 내부 투영과 출력이 거의 같아(상관 0.9 이상) 두 측정이 구분되지 않을 수 있다. (3) VLM hidden state에 시각, 의미 내용이 섞인다. (4) "1차 상태 대 보고"라는 고차 이론(HOT) 해석은 가설로만 쓴다 |
| 의사결정 기준 | **계속:** 두 특징 중 하나 이상이 같은 모델 null을 넘는 고유 설명량을 MC 6명 중 4명 이상에서 보이고, 두 특징의 상관이 0.9 미만이면 본 연구로 간다. **수정:** 두 특징의 상관이 0.9 이상이면 출력 판(token 확률 기댓값)과 층을 바꿔 다시 본다. 오염 탐침에서 강한 기억 신호가 나오면 모델을 바꾸거나 "C&K 평정 너머" 분석 중심으로 설계를 바꾼다. **중단:** 시각 이중 통제 뒤 두 특징 모두 null과 구분되지 않으면 본 연구를 RQ-08(캡션 잔차)의 하위 분석으로 줄인다 |
| 실행 전 확인 | VLM 가중치 라이선스(연구 목적 사용 가능 여부). GPU 메모리(8B 모델 hidden state 추출에 24 GB 이상 권장, 추정). 정서 방향 추출용 텍스트 자료 |

## 왜 이 세 개인가

* **P1과 P2는 Horikawa 결론을 다시 볼 때 필요한 두 기둥이다.**
  * P1은 "의미로 환원되는가"를, P2는 "다른 사람과 그룹에서 재현되는가"를 본다.
  * 둘 다 원 결과 재현(V11)부터 시작해 실패 원인을 일찍 찾을 수 있다.
  * 다른 질문 여러 개의 공통 기반이 된다. RQ-03, 02, 07, 19는 P2를, RQ-09와 RQ-44는 P1을 쓴다.
* **P3는 AI를 단순 도구가 아니라 연구 대상으로 쓰는 질문 중 비용이 가장 작다.**
  * 새 fMRI 분석 없이 특징 추출만 더하면 기존 encoding 파이프라인에 들어간다.
  * 선행연구 감사에서 같은 설계를 찾지 못했다. 다만 감사도 놓친 선행이 카드 작성 중에 나온 사례(RQ-32)가 있어 확정은 아니다.
* **Emo-FilM 쪽 다음 후보는 RQ-32와 RQ-14다.**
  * RQ-32(흥분은 위치인가 속도인가)는 모델이 필요 없어 비용이 가장 낮다.
  * RQ-14(장면 의미역 구조)는 VidSitu 계열 checkpoint의 존재와 성능 확인이 먼저다.
