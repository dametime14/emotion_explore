# Research Axis Taxonomy (출발점)

아래 목록은 출발점이지 완결된 분류 체계가 아니다. 문헌을 탐색하면서 Axis와 Sub-axis를 계속 확장한다. 새로운 Axis를 발견하면 기존 분류에 무리하게 넣지 말고 독립 Axis로 추가한다.

각 Axis마다 다음을 찾는다.
* Sub-axis
* 기존 연구
* 주요 모델
* 미해결 문제
* 다른 Axis와 연결될 수 있는 지점

## 2. Axis 목록

### Axis A: Emotion & Affective Constructs
Discrete / Categorical Emotion, Dimensional Emotion, High-dimensional Emotion Space, Appraisal and Cognitive Evaluation, Emotion Semantics, Subjective Feeling, Emotional Intensity / Granularity, Ambivalence / Mixed Emotions, Aesthetic Emotion / Awe / Beauty, Social Emotion / Empathy, Emotion Regulation, Predictive / Anticipatory Emotion, Emotion vs Mood, Emotion Recognition vs Emotion Experience, Interoception and Bodily States

### Axis B: Perceptual & Stimulus Representation
Low-level Visual Features, Objects / Actions / Scenes, Motion / Optical Flow, Faces / Expressions / Body Language, Spatial / Temporal Context, Visual Semantics, Audio / Music / Speech Features, Multimodal Stimulus Representation, Sensory Congruence / Conflict, Perceptual Ambiguity, Naturalistic vs Controlled Stimuli

### Axis C: Context, Meaning & Narrative
Scene Context, Event Boundaries, Narrative Progression, Character Intentions, Social Relationships, Causal Understanding, Situation Models, Emotional Expectation, Surprise / Prediction Error, Contextual Reinterpretation, Perceived Meaning vs Experienced Emotion

### Axis D: Temporal Dynamics
Static vs Dynamic Representations, Emotion Onset / Peak / Offset, Emotional Transitions, Temporal Dependencies, Hysteresis / Emotional Inertia, Neural State Transitions, Recurrent / State-space Dynamics, Multi-timescale Integration, Temporal Prediction, Emotion Trajectories

### Axis E: Neural Targets
Amygdala and Subcortical Systems, Insula / Salience Network, vmPFC / OFC / ACC, Visual and Auditory Cortex, Default Mode Network, Social Cognition Networks, Distributed Cortical Representations, Subcortical-Cortical Interactions, Functional Connectivity, Dynamic Network Reconfiguration, Cortical Gradients

### Axis F: Brain Representation
Voxel-level Representations, ROI / Parcel-level Representations, Surface-based Representations, Functional Connectivity, Spatial Patterns, Distributed Population Codes, Shared Latent Representations, Subject-specific Representations, Neural Manifolds, Temporal Neural States

### Axis G: Decoding
Vision / Image / Video Decoding, Semantic Decoding, Emotion Category Decoding, Dimensional Affect Decoding, Appraisal Decoding, Context / Narrative Decoding, Neural-to-Text / Neural-to-Latent, Zero-shot / Few-shot Decoding, Cross-subject / Cross-dataset Decoding, Generative Reconstruction, Hierarchical / Structured Decoding

### Axis H: Encoding
Vision-to-Brain, Audio-to-Brain, Text / Semantics-to-Brain, Emotion Feature-to-Brain, Multimodal-to-Brain, Time-resolved Encoding, Brain Foundation Model Encoding, Brain Response Simulation, Shared vs Specialized Encoding Models, Individualized Brain Encoding

### Axis I: AI Model Families
CNN / Vision Transformer, CLIP / DINO / Vision-Language Models, VideoMAE / V-JEPA / Video Models, Audio / Music Foundation Models, LLM / Multimodal LLM, Brain Foundation Models, Diffusion / Generative Models, Recurrent / State-space Models, Graph Neural Networks, Brain-inspired / Neuromorphic Models, World Models

### Axis J: Learning Objectives
Supervised Learning, Self-Supervised Learning, Contrastive Learning, Masked Modeling, Generative Pretraining, Multitask Learning, Cross-modal Distillation, Representation Alignment, Transfer Learning, Domain Adaptation, Few-shot / Zero-shot Learning, Disentangled Representation Learning

### Axis K: Geometry & Mathematical Structure
Dimensionality, Representational Similarity, Linear vs Nonlinear Geometry, Manifold Learning, Topological Data Analysis, Information Geometry, Dynamical Attractors, Latent Trajectories, Shared / Private Subspaces, Optimal Transport, Distributional Representations

### Axis L: Generative & Counterfactual Methods
Brain-conditioned Generation, Image / Video / Audio Generation, Controlled Stimulus Editing, Latent Interventions, Counterfactual Representation Testing, Semantic vs Perceptual Manipulations, In-Silico Experiments, Generative Experimental Design

### Axis M: Multimodal Integration
Early / Late Fusion, Cross-attention, Shared Multimodal Embeddings, Modality-specific Representations, Audio-Visual Integration, Image / Video / Music Integration, Language-Perception Alignment, Modality Invariance, Cross-modal Transfer, Modality Interactions and Synergy

### Axis N: Brain-like Computation
Predictive Coding, Active Inference, Hierarchical Processing, Recurrent Computation, Biologically Constrained Learning, Neural Routing, Specialized Pathways, Neuromorphic Systems, Emotion as Computational Value / Salience

### Axis O: Individual & Population Variation
Individual-specific Emotion Representations, Functional Alignment, Hyperalignment / Shared Response Models, Subject-specific Latent Spaces, Trait-dependent Representation, Cross-subject Generalization, Universal vs Idiosyncratic Structure, Individual Differences in Emotion Experience

### Axis P: Causality & Scientific Inference
Confound Control, Causal Representation Learning, Computational Interventions, Mediation Analysis, Conditional Independence, Counterfactual Predictions, Natural Experiment Limitations, Model-based Hypothesis Generation, Observational vs Causal Interpretation

### Axis Q: Reliability & Measurement
Inter-rater Reliability, Neural Noise Ceilings, Label Uncertainty, Subjective vs Normative Labels, Reliability-adjusted Dimensionality, Psychometric Measurement Models, Hierarchical Bayesian Models, Measurement Invariance, Calibration / Uncertainty Estimation

### Axis R: Explainability & Mechanistic AI
Concept-based Interpretation, Representation Probing, Feature Attribution, Layerwise Brain Alignment, Sparse Concept Decomposition, Mechanistic Interpretability, Model Disagreement, Computational Specialization, Representation Steering

### Axis S: Generalization & Robustness
Within-dataset Generalization, Cross-stimulus Generalization, Cross-subject Generalization, Cross-dataset Transfer, Cross-modal Transfer, Out-of-distribution Generalization, Invariance / Equivariance, Domain Shift, Compositional Generalization

### Axis T: Scientific Discovery & Evaluation
Hypothesis Generation, Model Comparison, Falsifiable Predictions, Controlled Baselines, Ablation Studies, Benchmarking, Variance Partitioning, Model-to-Brain / Model-to-Behavior Evaluation, Replication and External Validation
